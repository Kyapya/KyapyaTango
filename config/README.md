`notion.json` contains non-secret database, property, tag, completion-status, and automatic-sync cutoff settings. Keep `NOTION_TOKEN` only in GitHub Actions secrets. Only the newest page for each word whose configured status property equals `complete_status` is synchronized; an older completed duplicate never replaces a newer in-progress page. `minimum_last_edited_time` applies only to full syncs; a manually requested word can still be synchronized regardless of its edit date, but it must still be complete.
