ENGLISH–JAPANESE EXTRA

access

主要語義 6更新 2026-10-04

発音記号

米・英: /ˈæk.ses/

  • 名詞・動詞とも2音節で、第1音節に強勢を置く。第1音節の母音は /æ/、第2音節は /e/。accesses は /ˈæk.ses.ɪz/、accessed は /ˈæk.sest/。excess「過剰」と綴り・発音を区別する。

コアイメージ

対象に届いて、入ったり使ったりできること。利用の機会・経路・実際の操作につながる。語義6は歴史的残存義で、「感情などが突然起こる」という語彙的意味はこの現代の核から導けないため、個別に参照する。
対象に届いて利用できる機会→ 「利用・接近の機会や権利」（語義1）
対象に届いて利用する行為→ 「利用する、情報を取り出す」（語義2）
対象に届いて入るための経路→ 「入るための道、到達手段」（語義3）
対象に届く移動や内部への到達→ 「場所に入る、たどり着く」（語義4）
対象に届いて行う個々の処理→ 「データへのアクセス操作」（語義5）

語源

  • 名詞はフランス語・ラテン語に由来し、ラテン語 accessus「接近、入口、発作」は accēdere「近づく」から生まれた。ad-「～へ」と cēdere「進む、退く」から成る。現代の動詞は名詞から作られた。同じ cēdere にさかのぼる語には proceed「進む」と recede「後退する」がある。

語形成

accessible形容詞。「近づける、利用できる、理解しやすい」。誰にとって利用・理解できるかを示すときは accessible to someone。単独でも使え、accessible by car は交通手段、accessible via 〈経路〉は到達経路を示す。
inaccessible形容詞。「近づけない、利用できない」。技術的制約・立地・費用など理由は文脈で決まる。
accessibility名詞。「利用しやすさ、到達しやすさ」。障害の有無などにかかわらず利用できるようにする文脈でも使う。
accessroad: 複合名詞。「施設などへの進入路」。中心となる名詞は road なので a road、roads のように数えられる。
openaccess: 名詞・名詞修飾表現。学術出版などで「無料で読める公開方式」。具体的な再利用条件は個々のライセンスによる。

語義 1

【名詞・不可算】利用・接近の機会や権利

頻度 8/10
一般、仕事、教育、医療、情報技術、公共政策。

情報・サービス・場所などを利用したり、人に会って話したりできること。その機会・権利・許可・実際の利用可能性を指し、どれが問題になるかは文脈で決まる。必ずしも法律上の権利や正式な許可だけを意味しない。

文法パターン8
  • have access to 〈対象〉
  • gain/get access to 〈対象〉
  • give/grant someone access to 〈対象〉
  • provide access to 〈対象〉
  • deny someone access to 〈対象〉
  • access for 〈利用者〉
  • equal/free/unlimited access to 〈対象〉
  • internet access
コロケーション・構文例8

have access to 〈対象〉

用途情報やサービスを利用できる状態。

例All students have access to the online library.

訳すべての学生がオンライン図書館を利用できる。

gain access to 〈対象〉

用途新たに利用できるようになる。

例Members gain access to the archive after completing registration.

訳会員は登録を済ませると、その資料庫を利用できるようになる。

grant someone access to 〈対象〉

用途人に利用・閲覧の許可を与える。

例The manager granted the auditors access to the financial records.

訳管理者は監査担当者に会計記録の閲覧を許可した。

deny someone access to 〈対象〉

用途接近・利用を認めない。

例The guards denied reporters access to the meeting room.

訳警備員は記者たちの会議室への立ち入りを認めなかった。

equal access to 〈対象〉

用途利用機会の平等。

例The program aims to give rural communities equal access to education.

訳その事業は、地方の地域社会にも平等な教育機会を提供することを目指している。

access for 〈利用者〉

用途誰が利用できるかを示す。

例The subscription includes access for up to five users.

訳その定期契約では、最大5人まで利用できます。

internet access

用途インターネットを利用できる環境。

例Internet access is included in the room rate.

訳インターネットの利用料金は宿泊費に含まれています。

have direct access to someone

用途間に人を挟まず、特定の人物と接触できる。

例The project leader has direct access to the chief executive.

訳そのプロジェクトの責任者は、最高経営責任者と直接連絡を取れる。

語法・注意1
  • この意味は通常不可算で、have an access to ではなく have access to とする。to は前置詞で、対象を続ける。名詞は access to the files、動詞は access the files とし、動詞の access to the files は通常誤り。free access は「無料の利用」または「制限のない利用」なので文脈を確認する。親子の面会を扱う文脈では access to one's children が「子に会う機会・権利」を表すことがあるが、監護権そのものを意味せず、制度の名称や内容は地域による。Access denied. はシステム表示でも使う「アクセス拒否」。
類義語3

admission

頻度 7/10

違い入場・入学など、受け入れられることが中心。access は継続的な利用や情報の閲覧にも使う。

例Admission to the exhibition is free on Sundays.

訳日曜日はその展覧会に無料で入場できます。

entry

頻度 7/10

違い中へ入ることに焦点がある。access は実際に入ったかどうかとは別に、利用できる状態も表す。

例Entry to the laboratory is restricted to authorized staff.

訳研究室への立ち入りは、許可された職員に限られています。

use

頻度 8/10

違いhave the use of のような形で利用権を表せる。access は利用に至る機会や条件に重点を置く。

例Guests have the use of a shared kitchen.

訳宿泊客は共用キッチンを利用できます。

語義 2

【動詞・他動詞】利用する、情報を取り出す

頻度 8/10
情報技術では一般的。サービス・資源については仕事・行政などの説明でよく使う。

情報を開く・取り出す、システムに接続する、サービスや資源を利用すること。また、それらを利用できるようになること。ファイルの閲覧から、必要な支援や資金の利用まで使える。

文法パターン6
  • access 〈information/data/files〉
  • access the internet
  • access one's account
  • access 〈services/support/funds〉
  • access something via/from 〈手段・端末〉
  • be accessed by 〈利用者〉
コロケーション・構文例7

access 〈information/data〉

用途必要な情報を取得・閲覧する。

例Researchers can access the data without downloading the entire archive.

訳研究者は資料全体をダウンロードせずに、そのデータを閲覧できる。

access one's account

用途アカウントに入って内容や機能を使う。

例I can't access my account because I've forgotten my password.

訳パスワードを忘れたため、アカウントにアクセスできません。

access the internet

用途インターネットに接続して使う。

例Visitors can access the internet through the library's Wi-Fi network.

訳来館者は図書館のWi-Fiを使ってインターネットを利用できる。

access something from 〈端末〉

用途利用に使う端末を示す。

例You can access the shared files from any computer in the office.

訳オフィス内のどのコンピューターからでも共有ファイルにアクセスできます。

access 〈services/support〉

用途必要なサービスや支援を利用する。

例The helpline helps families access local support services.

訳その相談窓口は、家族が地域の支援サービスを利用できるよう手助けしている。

access one's funds

用途自分の資金を引き出すなどして利用する。

例Customers can access their funds through the mobile app.

訳顧客はモバイルアプリを通じて、自分の資金を引き出すなどして利用できる。

be accessed by 〈利用者〉

用途誰がファイルやサービスを使えるかを受動態で示す。

例These records can be accessed only by authorized staff.

訳これらの記録を閲覧できるのは、許可された職員だけです。

語法・注意1
  • 目的語を直接続ける。他動詞なので access to information ではなく access information。名詞を使うなら gain access to information とする。受動態も普通に使う。accessed、accessing は通常の活用形で、「利用しやすい」は accessible。新たに利用可能になることに限らず、すでに使えるファイルを開いたりサービスを利用したりする場合にも使う。接続・閲覧・利用のどこまでを指すかは、対象と文脈による。一般的な相手への「連絡する」を access someone で置き換えず、contact someone や have access to someone を使い分ける。
類義語3

retrieve

頻度 6/10

違い取り出して手元に得ることを強調する。access は画面上で閲覧したり、システムを使ったりするだけでも成立する。

例The program retrieves the latest figures from the database.

訳そのプログラムはデータベースから最新の数値を取り出す。

use

頻度 10/10

違いuse は、道具で作業するなど、何かを目的のために使う行為を広く表す。access は、情報を開く・システムに接続するなどして利用先に到達し、利用できることや利用する行為に焦点を置く。

例You can use this app to edit photos.

訳このアプリで写真を編集できます。

obtain

頻度 7/10

違い入手という結果を表す。access は所有せずに閲覧・利用できる場合にも使う。

例We obtained a copy of the report from the local office.

訳私たちは現地の事務所から報告書の写しを入手した。

語義 3

【名詞・通常不可算】入るための道、到達手段

頻度 6/10
一般、案内、不動産、交通、施設設計。

場所に入ったり近づいたりするための経路・手段。単に許可があるかではなく、どこを通るか、何で行けるかという物理的な到達のしやすさを表す。

文法パターン8
  • access to 〈場所〉
  • access via/through 〈経路〉
  • access by 〈交通手段〉
  • wheelchair access
  • an access road
  • an access route
  • an access point
  • the only access to 〈場所〉
コロケーション・構文例5

access to 〈場所〉

用途目的地へ通じる物理的な経路。

例A narrow path provides access to the beach below the cliffs.

訳狭い小道を通って、崖の下の浜辺に出られる。

access through 〈経路〉

用途建物のどこから入れるかを示す。

例Access to the courtyard is through a passage beside the shop.

訳中庭へは、店の横の通路から入ります。

access by 〈交通手段〉

用途利用できる交通手段。

例Access by car is difficult because the final stretch is unpaved.

訳最後の区間が舗装されていないため、車では行きにくい。

wheelchair access

用途車椅子で出入りできる経路や設備。

例The new ramp provides wheelchair access to the main entrance.

訳新しいスロープができて、車椅子で正面玄関まで行けるようになった。

an access road

用途施設などへ通じる進入路。

例A fallen tree has blocked the access road to the campsite.

訳倒木でキャンプ場への進入路が塞がれている。

語法・注意1
  • 通常は access を不可算として使い、a way in、an entrance などとは数え方が違う。特定の経路なら the only access のように the を付けられる。an access road、an access route、an access point は複合名詞で、冠詞 an はそれぞれの中心名詞 road・route・point に対応する。access 自体を数えているわけではない。交通案内の easy access は「行きやすい」という意味で、インターネットへの接続だけを指す語ではない。
類義語2

entrance

頻度 8/10

違い可算名詞で、戸口・門などの具体的な入口に焦点を置く。access はそこへ至る道や手段全体も表す。

例The entrance to the museum is on the north side.

訳博物館の入口は北側にある。

approach

頻度 5/10

違い目的地へ近づく区間に重点がある。access は入れることや目的地に届く手段まで含む。

例Floodwater covered the southern approach to the bridge.

訳洪水で、橋へ南側から通じる道が水に浸かった。

語義 4

【動詞・他動詞】場所に入る、たどり着く

頻度 6/10
案内、不動産、技術・作業説明。日常会話の get to や get into より説明的。

入口・通路・交通手段などを使って、場所にたどり着いたり、中へ入ったりすること。機器の内部など、作業対象に手が届くようにする場合にも使う。

文法パターン5
  • access 〈場所・内部〉
  • access something via/through 〈経路〉
  • be accessed from 〈出発側の場所〉
  • be accessed by 〈交通手段〉
  • be easily accessed
コロケーション・構文例4

access 〈場所・内部〉

用途場所にたどり着く、中へ入る、または対象に手が届いて作業できるようにする。

例Remove the cover to access the battery compartment.

訳カバーを外すと電池収納部に手が届きます。

access 〈場所〉 via 〈経路〉

用途どの経路を通って入るかを示す。

例Visitors access the garden via a gate behind the museum.

訳来館者は博物館の裏の門から庭園に入ります。

be accessed from 〈場所〉

用途どこから入れるかを受動態で示す。

例The roof terrace is accessed from the third-floor corridor.

訳屋上テラスへは3階の廊下から出られます。

be accessed by 〈交通手段〉

用途目的地までの移動手段。

例The island can be accessed only by boat.

訳その島へは船でしか行けません。

語法・注意1
  • 場所を直接目的語に取る。access to the roof を動詞句のつもりで使わず、access the roof または get access to the roof とする。受動態は案内文でよく使う。via・through・from・by は経路や手段を補う前置詞で、access と固定の句動詞を作るわけではない。
類義語3

reach

頻度 9/10

違いreach は到着・到達そのものが中心。access は、場所へ行く・入る、対象に手を届かせるための経路や手段を意識させるが、常に内部へ入ることを意味するわけではない。

例We reached the village just before sunset.

訳私たちは日没の直前に村に着いた。

enter

頻度 8/10

違い内外の境界を越えることに焦点がある。access は場所まで行けることや機器内部に手が届くことにも使う。

例Please enter the building through the side door.

訳横のドアから建物にお入りください。

get to

頻度 9/10

違い会話で自然な表現。access より広く、所要時間や移動の話にも使う。

例How do we get to the station from here?

訳ここから駅へはどう行けばよいですか。

語義 5

【名詞・可算または不可算】データへのアクセス操作

頻度 4/10
コンピューター、プログラミング、性能分析。

コンピューターが記憶領域やデータなどを読み出し・書き込みのために参照すること。また、その個々の操作。利用する権限ではなく、実行される処理自体を指す。

文法パターン5
  • memory access
  • disk access
  • a memory access
  • 〈数〉 memory accesses
  • access time
コロケーション・構文例3

memory access

用途メモリーを参照する処理全般。

例This optimization reduces the time spent on memory access.

訳この最適化により、メモリーへのアクセスにかかる時間が短くなる。

〈数〉 memory accesses

用途個々のアクセス操作を数える。

例Each iteration requires two memory accesses.

訳反復処理1回につき、メモリーへのアクセスが2回必要になる。

access time

用途データにアクセスするのにかかる時間。

例Faster storage can reduce average access time.

訳より高速な記憶装置を使うと、平均アクセス時間を短縮できる。

語法・注意1
  • 処理一般は不可算、個々の回数を数えるときは an access、accesses が使える。この専門的な可算用法を、語義1の have access to に広げない。a memory access は可算だが、access time の access は名詞を修飾している。
語義 6

【名詞・可算】感情などの急な高まり、発作

頻度 2/10
文学的、古風。病気については特に古い表現。

怒りなどの感情が急に強く起こること。古い文章では病気の発作にも使われる。現代の一般的な「アクセス」とは別に覚える文学的・古風な用法。

文法パターン2
  • an access of 〈rage/anger〉
  • in an access of 〈感情〉
コロケーション・構文例2

an access of rage

用途怒りが突然込み上げる場面の文学的な描写。

例An access of rage left him unable to speak.

訳怒りが急に込み上げて、彼は言葉を失った。

in an access of anger

用途突然の怒りに駆られた行動。

例In an access of anger, she tore the letter into pieces.

訳急に怒りがこみ上げ、彼女は手紙を細かく引き裂いた。

語法・注意1
  • この意味では an access of とし、利用・接近を表す access to と区別する。日常会話では a fit of anger や a burst of anger が分かりやすい。現代の病状を説明する際に、一般的な attack や episode の代わりとして積極的に使う語ではない。
類義語2

fit

頻度 6/10

違いa fit of anger の形は access of anger より一般的。病気の意味もあるが、何の fit かで解釈が変わる。

例In a fit of anger, he threw his notes into the bin.

訳かっとなって、彼はメモをごみ箱に投げ込んだ。

burst

頻度 7/10

違い短時間に一気に現れる感じを強調し、喜び・笑い・活動にも広く使う。

例The joke produced a burst of laughter.

訳その冗談に、どっと笑いが起こった。

該当する語義・用例がありません。
