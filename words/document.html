ENGLISH–JAPANESE EXTRA

document

主要語義 4更新 2026-10-13

発音記号

名詞は米: /ˈdɑːkjumənt/｜英: /ˈdɒkjumənt/。動詞は米: /ˈdɑːkjument/｜英: /ˈdɒkjument/。どちらも3音節で、第1音節に主強勢を置く。米英差は第1音節の母音 /ɑː/ と /ɒ/。品詞による違いは第3音節の母音で、名詞は /ə/、動詞は /e/ となる。

  • 動詞の documented は語尾に /ɪd/ が加わる。名詞の複数形と動詞の三人称単数形 documents の語尾はいずれも /s/。名詞と動詞で主強勢が移る record とは違い、語末だけに強勢を移して読まない。

コアイメージ

「情報を、後から参照・確認できる形にする」が共通核。情報を載せた一まとまりが名詞、記録を残したり根拠を示したりする行為が動詞になる。

  • 情報を参照できる形にした文書 → 「文書・書類」（語義1）
  • 情報を参照できる電子的な文書 → 「文書ファイル」（語義2）
  • 情報を参照できる形に残す行為 → 「記録する・記録に残す」（語義3）
  • 情報を確認できる根拠を添える行為 → 「資料で裏付ける」（語義4）

語源

  • 中英語後期に古フランス語を経て入り、ラテン語 documentum「教訓・証拠」にさかのぼる。もとになった docere は「教える」の意。中世ラテン語では文書による指示や公的書類も表した。doctor「医師・博士」と doctrine「教義」も docere を共有する同根語で、現代の document から作られた語ではない。

語形成

documentation必要書類・説明資料をまとめて捉える不可算名詞。また、記録を残す行為。個々の文書を数える documents と区別する。
documentary形容詞では「文書の・記録に基づく」、名詞では「ドキュメンタリー作品」。documentary evidence は文書による証拠。
well-documented十分に記録・裏付けのある。a well-documented case のように名詞前ではハイフンを使う。The case is well documented. のような叙述形では通常ハイフンを付けない。

語義 1

【名詞・可算】文書・書類

頻度 9/10
一般・業務・行政・学術。

情報・指示・事実などを記した文書。業務上の書類や公的文書が典型だが、私的な記録にも使い、紙にも電子媒体にも及ぶ。1文書が1ページとは限らず、名称だけで正式性や法的効力が決まるわけではない。

文法パターン6
  • a document on 〈話題〉＝ある話題についての文書
  • submit a document＝文書を提出する
  • sign a document＝文書に署名する
  • supporting documents＝根拠や申請内容を補う書類
  • a copy of a document＝文書の写し
  • according to the document＝その文書によると
コロケーション・構文例6

a document on 〈話題〉

用途文書が何について書かれているかを示す。

例The committee published a document on energy use.

訳委員会はエネルギー使用についての文書を公表した。

submit the required documents

用途求められている書類を提出する。

例Applicants can submit the required documents online.

訳申請者は必要書類をオンラインで提出できる。

sign a document

用途文書への署名を述べる。

例Read the document carefully before signing it.

訳署名する前に、その文書をよく読んでください。

supporting documents

用途主たる申請や説明を補強する資料を指す。

例Please attach supporting documents to your application.

訳申請書に裏付けとなる書類を添付してください。

a copy of a document

用途原本と写しを区別する。

例We keep a copy of every document we send.

訳私たちは送付するすべての文書の写しを保管している。

according to the document

用途情報源を文書に置く。

例According to the document, the site will remain open.

訳その文書によると、その施設は引き続き営業する。

語法・注意1
  • 個別の文書は a document・two documents と数える。documentation は資料一式をひとまとめにしたり記録作業を指したりするので、単なる複数形の代用ではない。document は載っている情報を、page はページという単位を意識した語。a ten-page document は10ページからなる1文書。a document on safety の on は話題を示し、information in the document の in は文書内の記載を示す。
類義語3

record

頻度 9/10

定義後から参照できるように残された事実や出来事の記録。

違いdocument は情報を載せた文書というまとまり、record は事実を保存した記録としての働きが中心。記録は文章以外でもよい。

例The records show when the repairs were completed.

訳記録には修理がいつ完了したかが示されている。

paperwork

頻度 8/10

定義手続きに必要な書類、またはその作成・処理。

違い不可算で、個々の文書より事務処理に必要な書類全体を指す。煩雑さを感じる文脈でもよく使う。

例The paperwork is ready for your signature.

訳署名してもらう書類は準備できている。

report

頻度 9/10

定義調査・出来事・状況などをまとめて伝える報告書。

違い報告という目的を表す。document は報告書以外に申請書・契約書・私的文書も含む。

例The report explains why the project was delayed.

訳その報告書はプロジェクトが遅れた理由を説明している。

語義 2

【名詞・可算】文書ファイル

頻度 9/10
一般・コンピューター操作。

ワープロなどで作成・編集・保存する電子的な文書。文字を中心とし、画像や表を含むこともある。業務上の正式書類でなく、白紙の新規文書や個人の下書きでもよい。

文法パターン5
  • create a new document＝新しい文書を作成する
  • save a document as 〈形式・ファイル名〉＝指定の形式・名前で文書を保存する
  • edit a document＝文書を編集する
  • share a document with someone＝人と文書を共有する
  • an attached document＝添付された文書
コロケーション・構文例4

create a new document

用途編集を始める文書を用意する。

例Create a new document and enter a title.

訳新しい文書を作成し、タイトルを入力してください。

save a document as a PDF

用途保存するファイル形式を指定する。

例I saved the document as a PDF.

訳私はその文書をPDFとして保存した。

edit a shared document

用途共有中の文書の内容を変更する。

例Several people can edit the shared document at the same time.

訳複数の人がその共有文書を同時に編集できる。

share a document with someone

用途文書を利用できる相手を示す。

例She shared the document with her team.

訳彼女はその文書を自分のチームと共有した。

語法・注意1
  • file は画像・音声・プログラムなども含む広い保存単位。document は通常、読んだり編集したりする文書として扱うファイルを指す。open・close は文書を画面上で開く・閉じることで、close だけでは保存を意味しない。document の拡張子やアプリを1種類に限定しない。
類義語2

file

頻度 9/10

定義コンピューターに名前を付けて保存するデータのまとまり。

違い文書も file だが、写真や音楽などのファイルがすべて document になるわけではない。

例This file contains the meeting notes.

訳このファイルには会議のメモが入っている。

text file

頻度 6/10

定義文字データを保存したファイル。

違い通常、文書の見た目を整える情報より文字データ自体に焦点を置く。document は画像や複雑な書式を含められる。

例Save the list in a text file.

訳そのリストをテキストファイルに保存してください。

語義 3

【動詞・他動詞】記録する・記録に残す

頻度 8/10
一般・報道・研究・業務。

出来事・活動・手順・変化などを、文章・写真・映像その他の資料として後から確認できる形に残す。人が意図して記録する場合のほか、書物や写真が事実を記録として伝えている場合にも使う。

文法パターン5
  • document something＝物事を記録に残す
  • document how 〈主語＋動詞〉＝どのように行われるかを記録する
  • document something in 〈媒体〉＝媒体に物事を記録する
  • document something with 〈記録手段〉＝手段を使って物事を記録する
  • be documented in 〈資料〉＝資料に記録されている
コロケーション・構文例5

document the changes

用途変化を後から追えるようにする。

例The photographs document the changes in the neighborhood.

訳それらの写真は、その地域の変化を記録している。

document how 〈主語＋動詞〉

用途過程や仕組みを記録の内容にする。

例The report documents how the team solved the problem.

訳その報告書には、チームがどのように問題を解決したかが記録されている。

document a process in writing

用途作業手順を文章として残す。

例We need to document the approval process in writing.

訳承認の手順を文書にしておく必要がある。

document something with photographs

用途記録に使う手段を示す。

例They documented the damage with photographs.

訳彼らは被害の状況を写真で記録した。

be documented in 〈資料〉

用途情報が記録されている場所を示す。

例The repairs are documented in the maintenance log.

訳修理内容は保守記録に記載されている。

語法・注意1
  • 目的語は「記録する対象」。document about the incident のように、記録対象を about で導く必要はなく、document the incident とする。単に文書ファイルを作る create a document とは一致しない。写真や映像による記録にも document を使う。record は短い数値の記入や音の収録にも広く使い、document は経過や内容を資料として残す点を意識させやすいが、詳しさの最低基準があるわけではない。documented はこの動詞の過去分詞で、documented procedures は記録・文書化された手順。
類義語3

record

頻度 9/10

定義情報や出来事を保存・記録する。

違い記入・録音・録画などを広く表す。document は参照できる資料として内容を残すことを強調しやすい。

例Please record the date of each inspection.

訳各点検の日付を記録してください。

chronicle

頻度 5/10

定義出来事の推移を順を追って記録する。

違い歴史や人生など時間的な流れを描くことが中心。document には年代順という条件はない。

例The book chronicles her years at sea.

訳その本は彼女が海で過ごした年月を順を追って記録している。

log

頻度 7/10

定義出来事や数値を記録簿・システムに書き留める。

違い一定形式で継続的に記録する業務的な用法が多い。document は写真・説明文などを含む。

例The system logs every failed login attempt.

訳そのシステムは失敗したログイン試行をすべて記録する。

語義 4

【動詞・他動詞】資料で裏付ける

頻度 6/10
学術・調査・論証。

主張・研究結果・説明などに証拠資料や出典を添え、根拠を示す。記録を作る行為に重点を置く語義3に対し、ここでは主張とその根拠の関係に重点がある。

文法パターン4
  • document a claim＝主張を資料で裏付ける
  • document something with 〈根拠資料〉＝根拠資料で内容を裏付ける
  • be documented by 〈証拠〉＝証拠によって裏付けられている
  • a well-documented 〈主張・研究〉＝十分な根拠資料を備えた主張・研究
コロケーション・構文例3

document a claim with 〈根拠資料〉

用途主張を支える資料を示す。

例The historian documented the claim with letters from the archive.

訳その歴史家は保存資料に含まれる書簡でその主張を裏付けた。

document the findings

用途調査結果に検証可能な根拠を付ける。

例The researchers carefully documented their findings with original data.

訳研究者たちは元のデータを用いて、調査結果の根拠を丁寧に示した。

be documented by 〈証拠〉

用途主張される事実を支える資料を述べる。

例Her ownership of the house is documented by the original deed.

訳彼女がその家の所有者であることは、元の権利証書によって裏付けられている。

語法・注意1
  • with は裏付けに使う資料を導く。document a claim は「主張が存在したことを記録する」とも読めるため、この語義を明確にするときは with citations・with original data などを添える。documented と書かれていても、その資料が完全に正しく結論が確定したとまでは言わない。well-documented は「十分に記録された」と「十分な根拠のある」の両方になり、対象から判断する。
類義語3

substantiate

頻度 6/10

定義証拠によって主張などを裏付ける。

違いdocument より証拠が主張を支えること自体に重点があり、文書の提示には限らない。

例Can you substantiate that allegation?

訳その申し立てを証拠で裏付けられますか。

corroborate

頻度 6/10

定義別の証拠や証言によって説明を補強する。

違いすでにある説明との一致・独立した裏付けに焦点がある。document は最初から根拠資料を示す場合にも使う。

例The footage corroborates her account of the accident.

訳その映像は事故についての彼女の説明を裏付けている。

support

頻度 9/10

定義主張や結論の根拠となる。

違い根拠を示す広い語で、document のように資料を備えることを特に表さない。

例The survey results support our conclusion.

訳調査結果は私たちの結論を裏付けている。

該当する語義・用例がありません。
