valid

主要語義 4更新 2026-10-03

発音記号

米・英: /ˈvæl.ɪd/

  • 2音節で、第1音節に強勢を置く。第1音節の母音は /æ/、第2音節は短い /ɪ/。語末は /d/ で、母音を付け足さない。

コアイメージ

「判断の基準を満たし、認められる」という共通核がある。基準は、使用上の規則、理由の確かさ、入力条件、推論の成立条件によって変わる。
使用の基準を満たして認められること→ 「有効な、正式に認められる」（語義1）
理由の基準を満たして認められること→ 「妥当な、もっともな」（語義2）
入力の基準を満たして認められること→ 「入力条件を満たす、有効な」（語義3）
推論の基準を満たして認められること→ 「論理的に妥当な」（語義4）

語源

  • フランス語 valide またはラテン語 validus「強い、効力のある」に由来し、さらに valēre「強い、健全である」にさかのぼる。現在の「効力がある」「根拠がしっかりしている」につながる。同じ valēre に由来する語には value「価値」と valiant「勇敢な」がある。

語形成

validity（名詞）「有効性、妥当性」。the validity of a ticket「切符の有効性」、the validity of a claim「主張の妥当性」。第2音節に強勢が移る。
validate（他動詞）「有効性・妥当性を確認する、有効にする」。検証と有効化のどちらかは目的語や文脈で決まる。
validation（名詞）「検証、確認、有効化」。data validation「データの検証」。
invalid（形容詞）「無効な、妥当でない」。/ɪnˈvæl.ɪd/ と第2音節に強勢を置く。「病弱な人」を指す同綴りの名詞 /ˈɪn.və.lɪd/ とは発音・意味が異なる。

語義 1

【形容詞】有効な、正式に認められる

頻度 8/10
一般、旅行、事務、法律。

切符・証明書・契約などが、適用される規則や条件を満たし、使用できる、または効力を持つこと。単に本物であることだけでなく、期限・対象・場所などの条件も関係する。

文法パターン7
  • a valid 〈ticket/passport/contract〉
  • be/remain valid
  • be valid for 〈期間/用途〉
  • be valid until 〈期限〉
  • be valid from 〈開始時点〉
  • be valid in 〈地域〉
  • be valid on 〈交通機関・サービス〉
コロケーション・構文例6

a valid 〈passport/ticket〉

用途使用条件を満たす証明書や切符。

例You need a valid passport to complete the application.

訳申請を完了するには有効なパスポートが必要です。

be valid for 〈期間〉

用途有効期間の長さ。

例This pass is valid for three days from the date of first use.

訳このパスは最初に使用した日から3日間有効です。

be valid until 〈期限〉

用途有効期限。

例The voucher is valid until the end of November.

訳この引換券は11月末まで有効です。

be valid for 〈用途〉

用途利用できる目的や対象。

例The discount is valid for online purchases only.

訳この割引はオンラインでの購入にのみ適用されます。

be valid in 〈地域〉

用途効力が認められる地域。

例This permit is valid in all three districts.

訳この許可証は3地区すべてで有効です。

be valid on 〈交通機関・サービス〉

用途切符などを利用できる交通機関。

例The ticket is valid on local buses but not on express services.

訳この切符は路線バスで使えますが、急行便では使えません。

語法・注意1
  • 名詞の前と be などの後で使う。有効・無効の区別では普通 very valid とはせず、still valid「まだ有効な」、no longer valid「もはや有効でない」とする。for は期間の長さや用途、until は終点を示す。a valid contract は「有効な契約」だが、何をもって有効とするかは法制度や契約内容による。
類義語3

good

頻度 7/10

違いこの意味では日常的な言い方。good for two journeys のように使用回数にも使い、valid より意味の広い語。

例The coupon is good for one free drink.

訳このクーポンで飲み物を1杯無料でもらえます。

effective

頻度 7/10

違い効力が生じていることに重点がある。valid は成立・使用条件を満たすことを表し、発効日だけの問題ではない。

例The new agreement becomes effective on Monday.

訳新しい協定は月曜日に発効する。

legitimate

頻度 6/10

違い権利・請求・手段などの正当性に焦点がある。切符の有効期限を述べる valid の通常の代わりにはしない。

例The company has a legitimate claim to the name.

訳その会社にはその名称を使用する正当な権利がある。

反意語2

invalid

頻度 7/10

違い有効・無効という同じ軸上の反対。期限切れ以外の理由でも invalid になる。

例The ticket is invalid without a date.

訳日付のない切符は無効です。

expired

頻度 7/10

違い時間の経過による有効性の喪失を表す。invalid より理由が限定される。

例I accidentally brought an expired passport.

訳うっかり期限切れのパスポートを持ってきてしまった。

語義 2

【形容詞】妥当な、もっともな

頻度 8/10
一般、議論、仕事、学術。

理由・主張・疑問などが筋の通った根拠を持ち、考慮に値すること。方法や判断について、その目的・状況に照らして適切だという意味にもなる。

文法パターン5
  • a valid 〈reason/point/argument/concern〉
  • a valid reason for 〈名詞/-ing〉
  • be/seem valid
  • equally/perfectly valid
  • a valid 〈method/comparison〉
コロケーション・構文例5

a valid reason for 〈名詞/-ing〉

用途行動や判断を正当化する理由。

例She had a valid reason for asking for more time.

訳彼女が時間の延長を求めたのにはもっともな理由があった。

make a valid point

用途議論で筋の通った点を指摘する。

例You make a valid point about the cost of repairs.

訳修理費についてのご指摘はもっともです。

a valid 〈concern/objection〉

用途無視できない懸念や異論。

例The residents raised valid concerns about traffic noise.

訳住民たちは交通騒音についてもっともな懸念を示した。

an equally valid 〈approach/method〉

用途別の方法にも妥当性があると認める。

例There may be an equally valid approach to solving this problem.

訳この問題の解決には、同じくらい妥当な別の方法があるかもしれない。

a valid comparison

用途比較に意味があると述べる。

例We need data from the same period to make a valid comparison.

訳妥当な比較をするには同じ期間のデータが必要です。

語法・注意1
  • 限定・叙述の両方で使い、perfectly valid「まったくもっともな」、more valid「より妥当な」などの程度表現も可能。a valid argument は日常的には「筋の通った議論」だが、論理学では語義4の厳密な意味になる。Your feelings are valid.「そう感じるのも無理はないよ」のような言い方は、感情を否定せず受け止めるもので、相手の判断や行動すべてが正しいと認める意味ではない。
類義語4

reasonable

頻度 8/10

違い極端でなく納得できることに重点がある。valid は理由や判断に認めるだけの根拠があることを強調する。

例It is reasonable to ask how the money will be spent.

訳そのお金がどう使われるのかを尋ねるのは当然だ。

sound

頻度 7/10

違い信頼できる根拠や考え方を強調する。日常語の sound は論理学の専門義とは区別する。

例The decision was based on sound evidence.

訳その決定は確かな証拠に基づいていた。

justified

頻度 7/10

違い判断・行動・感情が正当化されることに重点がある。valid は疑問や方法そのものの妥当性にも使う。

例Her concern about the deadline was justified.

訳締め切りについての彼女の心配には理由があった。

cogent

頻度 4/10

違い主に議論や説明に使う硬い語。単に妥当という以上に、相手を納得させる力を強調する。

例He gave a cogent explanation of the delay.

訳彼は遅延について筋の通った説得力のある説明をした。

反意語2

unfounded

頻度 6/10

違い根拠があるかどうかという軸で反対になる。証明されていないことだけで直ちに unfounded とは限らない。

例The accusation proved to be unfounded.

訳その非難には根拠がないと分かった。

unreasonable

頻度 7/10

違い妥当性の程度上の反対。特に要求や期待が過大な場合にも使う。

例It is unreasonable to expect an answer within five minutes.

訳5分以内の返答を求めるのは無理がある。

語義 3

【形容詞】入力条件を満たす、有効な

頻度 6/10
コンピューター、ウェブフォーム、データ処理。

データ・値・入力内容などが、形式・範囲・認証といったシステムの条件を満たしていること。何が条件なのかは処理によって異なる。

文法パターン4
  • a valid 〈value/input/password〉
  • a valid email address
  • be valid
  • valid 〈JSON/XML〉
コロケーション・構文例4

a valid 〈value/input〉

用途プログラムが受け付ける値や入力。

例Zero is a valid value for this field.

訳この欄には0を入力できます。

a valid email address

用途メールアドレスの入力を求める。

例Please enter a valid email address.

訳有効なメールアドレスを入力してください。

a valid password

用途認証条件を満たすパスワード。

例Access requires a valid password.

訳アクセスには有効なパスワードが必要です。

valid JSON

用途指定形式に従うデータ。

例The server rejected the response because it was not valid JSON.

訳応答が正しいJSON形式になっていなかったため、サーバーは受け付けなかった。

語法・注意1
  • 限定・叙述の両方で使う。通常は条件を満たすか否かの区別なので very valid とはしない。a valid email address が形式の正しさだけを指す場合、実在や受信可能性まで確認済みとは限らない。valid JSON も、内容が事実として正しいことを保証する表現ではない。
類義語2

acceptable

頻度 6/10

違い技術用語としての valid より広く、入力以外の許容範囲にも使う。

例Only positive integers are acceptable inputs.

訳入力できるのは正の整数だけです。

well-formed

頻度 4/10

違い構文の整い方に焦点がある。特にXMLでは well-formed と valid は同じ条件ではなく、valid は追加の定義への適合も問題にする。

例The document is well-formed XML.

訳その文書はXMLの構文規則に従っている。

反意語1

invalid

頻度 6/10

違い同じシステム条件についての直接の反対。形式不備・範囲外・認証失敗など理由はさまざま。

例The form displays an error for invalid dates.

訳そのフォームは無効な日付に対してエラーを表示する。

語義 4

【形容詞】論理的に妥当な

頻度 4/10
論理学、哲学、数学。

演繹的な議論・推論で、すべての前提が真なら結論も必ず真となる関係が成立していること。前提が現実に真であるかどうかとは別の性質。

文法パターン3
  • a valid 〈argument/inference/deduction〉
  • be logically valid
  • a valid argument form
コロケーション・構文例3

a valid argument

用途前提と結論の論理的なつながり。

例An argument can be valid even if one of its premises is false.

訳前提の一つが偽でも、議論が論理的に妥当であることはある。

a valid inference

用途前提から結論へ進む推論。

例The conclusion follows by a valid inference from the two premises.

訳その結論は二つの前提から妥当な推論によって導かれる。

be logically valid

用途日常的な説得力と区別して論理的妥当性を述べる。

例The deduction is logically valid, but we still need to check the assumptions.

訳その演繹は論理的に妥当だが、仮定が正しいかはなお確認する必要がある。

語法・注意1
  • 限定・叙述の両方で使い、厳密な定義では程度を付けず、valid か invalid かを判定する。true は通常、命題・前提・結論の真偽を述べる語。valid と true を同じ意味にしない。sound argument「健全な議論」は、妥当であることに加えて前提がすべて真であることを必要とする。
反意語1

invalid

頻度 4/10

違い論理的妥当性についての直接の反対。結論がたまたま真でも、推論自体は invalid であり得る。

例The argument is invalid because the conclusion does not follow from the premises.

訳結論が前提から導かれないため、その議論は妥当ではない。

該当する語義・用例がありません。
