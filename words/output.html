ENGLISH–JAPANESE EXTRA

output

主要語義 8更新 2026-10-11

発音記号

米・英: /ˈaʊt.pʊt/。名詞・動詞とも2音節で、第1音節に主強勢を置く。第1音節の母音は二重母音 /aʊ/、第2音節は短い /ʊ/。outputs の語尾は /ts/。outputted は /ˈaʊt.pʊt.ɪd/、outputting は /ˈaʊt.pʊt.ɪŋ/ で、いずれも3音節になる。

コアイメージ

核は「人・機械・仕組みの働きによって生み出される、または外へ送り出されるもの」。その量や内容、それを送り出す場所・動作を区別する。

  • 外へ生み出されるものの量 → 「生産量・産出量」（語義1）
  • 外へ生み出される仕事の成果 → 「作品群・成果物」（語義2）
  • 外へ生み出される情報とその提示 → 「出力データ・出力処理」（語義3）
  • 外へ生み出されるエネルギーや信号 → 「出力・発生量」（語義4）
  • 外へ生み出されるものの出口 → 「出力端子・出力口」（語義5）
  • 外へ生み出される情報を送る行為 → 「出力する」（語義6）
  • 外へ生み出される情報が出る動き → 「出力される」（語義7）
  • 臓器・身体の系から送り出される物質の量 → 「拍出量・排出量」（語義8）

語源

  • out「外へ」と put「置く・出す」の組合せ。「生み出して外へ出されるもの」という形成が、生産物・出力の理解を助ける。同じ put を含む input「入力」、throughput「一定時間内の処理量」が比較に役立つが、output は put out という句動詞とは別の1語である。

語形成

outputs名詞の可算用法の複数形、または動詞の三人称単数現在。
outputted動詞の過去形・過去分詞。原形と同じ output も過去形・過去分詞として用いる。
outputting現在分詞・動名詞。末尾の t を重ねる。
output device出力装置。画面やプリンターなど、処理結果を外部へ提示する装置。
input/output入出力。ITでは I/O とも略す。
high-output高出力の、または生産量の多い。名詞の前で用いる複合形容詞。

語義 1

【名詞・不可算中心、可算用法もある】生産量・産出量

頻度 8/10
一般・経済・生産管理

人・工場・産業・国などが生み出す物やサービスの量。一定期間の量を論じることが多いが、期間の明示は必須ではない。廃棄物や排出物の量にも使うため、価値のある製品だけを指すとは限らない。

文法パターン5
  • the output of 〈生産主体〉＝その生産主体の産出量
  • output from 〈生産場所〉＝その場所からの産出量
  • increase output by 〈割合〉＝産出量をその割合だけ増やす
  • an output of 〈数量〉＝その数量の産出量
  • output per 〈単位〉＝その単位当たりの産出量
コロケーション・構文例5

the output of 〈工場・産業〉

用途生産主体を of で示す。

例The output of the factory fell last month.

訳その工場の生産量は先月減少した。

output from 〈生産場所〉

用途生産量の供給元や場所を示す。

例Output from the two plants accounts for half of our sales volume.

訳その2工場の生産量が、当社の販売数量の半分を占めている。

increase output by 〈割合〉

用途増加分を by で示す。

例The new line increased output by 15 percent.

訳新しい生産ラインによって、生産量が15パーセント増えた。

an output of 〈数量〉

用途数量を伴って1つの生産実績を表す。

例The workshop has a daily output of 200 chairs.

訳その作業場の1日の生産量は椅子200脚である。

output per worker

用途労働者1人当たりの量を比較する。

例Output per worker rose after the training program.

訳研修プログラムの後、労働者1人当たりの生産量が増えた。

語法・注意1
  • 通常は不可算として Output is rising.「生産量は増えている」のように使う。ただし an output of 200 units や、部門別・種類別の量を区別する outputs も成立する。production は生産の過程と量の両方を表せるので「過程だけ」としない。capacity は生産可能な能力・上限、actual output は実際の量。productivity は投入した時間・人員・資源などに対する生産性であり、総生産量が増えたことだけでは生産性向上は保証されない。
類義語3

production

頻度 8/10

定義製造や生産、またはその量。

違いoutput は生み出された量に焦点を置きやすい。production は生産する活動も明確に表せる。

例Annual production reached 8,000 vehicles.

訳年間生産量は8,000台に達した。

yield

頻度 7/10

定義作物・工程などから得られる収量。

違いoutput より、投入物や土地などから得られる収穫・回収量に焦点がある。

例The new process increased the yield of usable material.

訳新しい工程によって、使用可能な材料の収量が増えた。

throughput

頻度 5/10

定義一定時間内に工程や設備を通して処理する量。

違いoutput は産出側の量、throughput は工程を通過・処理する量に焦点がある。処理対象がすべて製品になるとは限らない。

例The sorting system has a throughput of 500 parcels an hour.

訳その仕分けシステムの処理量は1時間当たり荷物500個である。

語義 2

【名詞・不可算中心、成果を区別すると可算】作品群・成果物

頻度 7/10
一般・文化・研究・業務

人や組織が制作・執筆・活動によって生み出した作品や成果をまとめていう。芸術作品、著作、放送内容、プロジェクトの直接の成果物などを指し、評価が高いことや望んだ効果を得たことまでは意味しない。

文法パターン4
  • someone's creative output＝その人が生み出した創作作品
  • the output of 〈活動〉＝その活動から生じた成果物
  • research outputs＝個別の研究成果物
  • the entire output of 〈作家〉＝その作家の全作品
コロケーション・構文例4

someone's creative output

用途創作された作品を集合的に捉える。

例The archive documents her creative output over forty years.

訳その資料館は、彼女が40年にわたって生み出した創作作品を記録している。

the output of 〈プロジェクト〉

用途活動が直接生み出す成果物を指す。

例The main output of the project is a public database.

訳そのプロジェクトの主な成果物は公開データベースである。

research outputs

用途論文など、区別できる研究成果を複数形で表す。

例The report lists the department's research outputs.

訳その報告書には、その学科の研究成果物が列挙されている。

the entire output of 〈作家〉

用途生涯や期間全体の作品群を示す。

例The exhibition covers the entire output of the photographer.

訳その展覧会では、その写真家の全作品を取り上げている。

語法・注意1
  • creative output は「創造力」という能力そのものではなく、実際に生み出された作品やその総体。個々の成果を区別する業務・研究の文脈では outputs が使われる。project outputs「直接生じた成果物」と project outcomes「その活動がもたらした効果・変化」は区別できるが、文書によって分類方法は異なる。output だけで質・成功・社会的効果まで断定しない。
類義語3

work

頻度 9/10

定義人が制作した作品、または作品の総体。

違いoutput は活動から生み出された成果全体という見方をする。work は個々の作品にも、集合的な作品にも使える。

例Her early work explores urban life.

訳彼女の初期の作品は都市生活を探究している。

product

頻度 8/10

定義活動や過程が生み出したもの。

違いoutput は量や集合としての成果にも使う。product は1つの成果や製品として捉えやすい。

例The documentary is the product of years of research.

訳そのドキュメンタリーは、長年の調査の成果である。

deliverable

頻度 5/10

定義業務で提出・納品することになっている成果物。

違いoutput は生じたもの全般。deliverable は提出・納品対象として定められた成果物に焦点がある。

例The final report is a key deliverable.

訳最終報告書は主要な提出成果物である。

語義 3

【名詞・不可算中心、結果を区別すると可算】出力データ・出力処理

頻度 8/10
IT・電子機器

コンピューターやプログラムなどが処理して外部へ示す情報・画像・結果、またはそれを表示・送信する処理。画面表示や印刷だけでなく、ファイルや別の処理への受け渡しも含む。

文法パターン5
  • output from 〈プログラム〉＝そのプログラムからの出力
  • save the output to 〈ファイル〉＝出力をそのファイルに保存する
  • standard output＝標準出力
  • an output file＝出力ファイル
  • compare the outputs of 〈複数の処理〉＝複数の処理の出力結果を比較する
コロケーション・構文例5

output from 〈プログラム〉

用途どの処理が結果を生んだかを示す。

例The output from the program contains three error messages.

訳そのプログラムの出力には、エラーメッセージが3件含まれている。

save the output to 〈ファイル〉

用途結果の保存先を示す。

例Save the output to a text file.

訳出力をテキストファイルに保存してください。

standard output

用途プログラムの通常の出力先を指す専門表現。

例The command writes the list to standard output.

訳そのコマンドは一覧を標準出力に書き出す。

an output file

用途結果を格納するファイルを名詞句で表す。

例The output file contains the converted images.

訳出力ファイルには、変換済みの画像が入っている。

compare the outputs of 〈複数の処理〉

用途別々に得られた結果を数えて区別する。

例We compared the outputs of the two models.

訳私たちは2つのモデルの出力結果を比較した。

語法・注意1
  • 名詞では the output「出力結果」、動詞では output the results「結果を出力する」と語順が違う。output file の output は後続名詞を修飾する名詞的用法で、語義6の動詞ではない。standard output は標準化された出力経路の名称で、常に画面そのものを意味するわけではない。個別の結果・信号・モデルの応答を区別すれば outputs も使える。
類義語2

result

頻度 9/10

定義計算・処理などで得られた結果。

違いoutput はシステムが外部へ示す形や経路にも着目する。result は得られた内容を表し、表示・送信の有無は問わない。

例The calculation produced an unexpected result.

訳その計算から予想外の結果が得られた。

printout

頻度 6/10

定義コンピューターから紙に印刷されたもの。

違いoutput は画面・データ・ファイルも含む。printout は紙への印刷結果に限定される。

例Please attach a printout of the results.

訳結果を印刷したものを添付してください。

反意語1

input

頻度 8/10

定義コンピューターや処理系に入れるデータ。

違い同じ情報の流れで、output が外へ出る側、input が中へ入る側を表す方向の対立。

例The program checks the input before processing it.

訳そのプログラムは、処理する前に入力データを確認する。

語義 4

【名詞・不可算、数量を示す単数形もある】出力・発生量

頻度 7/10
工学・電気・エネルギー

装置・エンジン・回路などが生み出し、送り出す電力・熱・仕事・信号など。また、その大きさ。数値の単位は対象によって異なり、output 自体がワットだけを指定するわけではない。

文法パターン4
  • a power output of 〈数値・単位〉＝その値の出力
  • the heat output of 〈装置〉＝その装置の発熱量
  • maximum output＝最大出力
  • the output voltage＝出力電圧
コロケーション・構文例4

a power output of 〈数値・単位〉

用途電力や動力の大きさを示す。

例The generator has a power output of 5 kilowatts.

訳その発電機の出力は5キロワットである。

the heat output of 〈装置〉

用途熱として放出される量を述べる。

例We measured the heat output of the heater.

訳私たちはその暖房器具の発熱量を測定した。

maximum output

用途装置が出せる最大の出力を表す。

例The amplifier was tested at maximum output.

訳その増幅器は最大出力で試験された。

the output voltage

用途回路から取り出される電圧を表す。

例The output voltage remains stable under load.

訳負荷がかかっていても、出力電圧は安定している。

語法・注意1
  • 名詞の output が表す量は、power output「電力・動力の出力」、output voltage「出力電圧」などの組合せで特定する。a high output や an output of 5 kilowatts は自然。output を常に「エネルギー」と訳すと、電圧・電流・仕事率との区別を失う。出力の大きさを示す語義であり、語義5の物理的な端子とは別。
類義語1

power

頻度 8/10

定義単位時間当たりに生み出す、または使うエネルギーに関わる出力・動力。

違いoutput は電圧・信号なども含む広い語。power は工学では仕事率という量を表す。

例The motor delivers more power at this speed.

訳そのモーターは、この回転速度ではより大きな出力を発揮する。

反意語1

input

頻度 6/10

定義装置や回路へ入る電力・信号など。

違い同じ装置の境界に対して、入る側と出る側という方向の対立。

例The input voltage must not exceed the specified limit.

訳入力電圧は指定された上限を超えてはいけない。

語義 5

【名詞・可算】出力端子・出力口

頻度 6/10
電気・音響・映像機器

機器から電気信号・音声などを取り出し、別の機器へ送るための接続箇所。信号の量や処理結果ではなく、機器側の接続口を指す。

文法パターン4
  • an audio output＝音声出力端子
  • connect 〈機器〉 to the output＝機器を出力端子につなぐ
  • the output on 〈機器〉＝その機器にある出力端子
  • two outputs＝2つの出力端子
コロケーション・構文例4

an audio output

用途端子の用途を音声に限定する。

例The monitor has an audio output on the back.

訳そのモニターの背面には音声出力端子がある。

connect 〈機器〉 to the output

用途出力側の端子への接続を表す。

例Connect the recorder to the output marked LINE OUT.

訳LINE OUTと表示された出力端子に録音機をつないでください。

the output on 〈機器〉

用途どの機器の接続口かを示す。

例The output on this camera requires an adapter.

訳このカメラの出力端子には、アダプターが必要である。

two outputs

用途物理的な端子を数える。

例The interface has two outputs for external speakers.

訳そのインターフェースには、外部スピーカー用の出力端子が2つある。

語法・注意1
  • この意味は可算なので an output、several outputs が使える。The output is low. は通常「出力が低い」という語義4の説明、The output is on the back. は「出力端子が背面にある」という位置の説明になる。output と input を機器の接続口として取り違えない。
類義語2

output terminal

頻度 4/10

定義信号・電力を外部へ取り出す端子。

違いoutput だけでも端子を指せるが、output terminal は接続箇所という意味を明示する。

例Check the voltage at the output terminal.

訳出力端子の電圧を確認してください。

output port

頻度 4/10

定義信号やデータを送り出すためのポート。

違いoutput より、規格に従う接続口・インターフェースであることを明示する。

例The display is connected to the output port.

訳ディスプレーは出力ポートにつながっている。

反意語1

input

頻度 6/10

定義外部から信号などを受け入れる端子。

違い接続口を信号が入る方向で捉えた反対語。

例Connect the cable to the microphone input.

訳ケーブルをマイク入力端子につないでください。

語義 6

【動詞・他動詞】出力する

頻度 6/10
IT・電子機器・技術文書

コンピューター・電子機器などが情報・画像・信号を外部へ出す。また、人が機器を使ってそれを出力させる。目的語は出す情報や信号で、出力先は to、形式は as や in で添えられる。

文法パターン4
  • output 〈データ〉＝データを出力する
  • output 〈データ〉 to 〈出力先〉＝データをその先へ出力する
  • output 〈結果〉 as 〈形式〉＝結果をその形式で出力する
  • be output to 〈出力先〉＝その先へ出力される
コロケーション・構文例4

output 〈データ〉

用途機器やプログラムが情報を出す。

例The sensor outputs a digital signal.

訳そのセンサーはデジタル信号を出力する。

output 〈データ〉 to 〈出力先〉

用途情報と送り先を区別する。

例The program outputs the results to a separate file.

訳そのプログラムは、結果を別のファイルに出力する。

output 〈結果〉 as 〈形式〉

用途出力結果の形式を指定する。

例You can output the chart as an image.

訳そのグラフを画像として出力できる。

be output to 〈出力先〉

用途データを主語にした受動態を使う。

例The summary was output to the screen.

訳その要約は画面に出力された。

語法・注意1
  • 過去形・過去分詞は output と outputted の両方、現在分詞は outputting。outputed、outputing は避ける。名詞句 the output of the program と動詞句 output the results を区別する。受動態の The image was output to the screen. では image は出力される対象。語義7の The image outputs correctly. は be を置かない自動詞構文である。outputted data のような修飾は出力済みであることを示す分詞用法で、独立した評価的な形容詞義はない。
類義語3

produce

頻度 8/10

定義結果やデータを生み出す。

違いoutput は機器・処理系の外へ出す側面を強調する。produce は生じさせること全般で、出力先を必ずしも意識しない。

例The model produces a confidence score.

訳そのモデルは信頼度スコアを生成する。

export

頻度 7/10

定義データを別のファイル形式やシステムで使えるように書き出す。

違いoutput よりも、データを外部利用に向けて取り出す機能を指す。

例Export the contacts as a CSV file.

訳連絡先をCSVファイルとして書き出してください。

print

頻度 8/10

定義文字・画像を紙に印刷する、またはプログラムで文字列を出す。

違いoutput は情報や出力媒体を広く取る。print は印刷に加え、プログラミングでは文字列を表示する意味で使う。

例The script prints a warning message.

訳そのスクリプトは警告メッセージを表示する。

反意語1

input

頻度 7/10

定義データを機器やシステムに入れる。

違い情報の流れの方向が反対。output は外へ出し、input は中へ入れる。

例Input the reference number before continuing.

訳続行する前に、参照番号を入力してください。

語義 7

【動詞・自動詞】出力される

頻度 3/10
IT・映像処理などの技術的用法

画像・データなどが機器から出力される。技術的な説明で、情報自体を主語にし、どこへ・どのように出るかを述べる用法。通常の受動態とは構文が異なる。

文法パターン2
  • 〈画像・データ〉 + output to 〈機器〉＝画像・データがその機器へ出力される
  • 〈画像・データ〉 + output correctly＝画像・データが正しく出力される
コロケーション・構文例2

〈画像〉 + output to 〈表示装置〉

用途主語が出力される対象になる自動詞用法。

例The image outputs to an external monitor.

訳その画像は外部モニターへ出力される。

〈データ〉 + output correctly

用途出力結果の状態を副詞で示す。

例The images output correctly in both formats.

訳画像はどちらの形式でも正しく出力される。

語法・注意1
  • この用法は技術的で、一般の説明では The image is output to an external monitor. という受動態にしてもよい。自動詞の image は出力される情報、語義6の The program outputs an image. の program は情報を出す側である。すべての名詞主語でこの交替が同じ自然さになるわけではなく、人が「出力される」と言いたい場面へ広げない。
語義 8

【名詞・不可算中心】拍出量・排出量

頻度 4/10
医療・生理学

臓器や身体の系が送り出す血液・尿などの量。特に cardiac output は心臓が1分間に送り出す血液量、urine output は尿の排出量を表す。何の量かと測定期間を文脈で特定する。

文法パターン3
  • cardiac output＝心拍出量
  • urine output＝尿量
  • monitor 〈身体由来物質〉 output＝その物質の排出量を監視する
コロケーション・構文例2

cardiac output

用途心臓の血液を送り出す量を表す。

例The study measured changes in cardiac output during exercise.

訳その研究では、運動中の心拍出量の変化を測定した。

urine output

用途尿の排出量を表す。

例The nurse recorded the patient's urine output overnight.

訳看護師は、その患者の夜間の尿量を記録した。

語法・注意1
  • cardiac output を「心臓からの出力」という機器的な表現で済ませず、「心拍出量」と読む。尿量は測定した期間とともに解釈する。値の大小だけで特定の病気や治療を意味する語ではない。一般の生産量と共通する「出る量」の意味だが、対象と単位は生理学的に定まる。
該当する語義・用例がありません。
