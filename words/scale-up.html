ENGLISH–JAPANESE EXTRA

scale up

主要語義 6更新 2026-10-25

発音記号

構成語の音は米・英: scale /skeɪl/、up /ʌp/。続けた構成音は /skeɪl ʌp/ の2音節で、第1音節の母音は /eɪ/、第2音節は /ʌ/。これは構成語に基づく表示であり、句全体の文中強勢を固定するものではない。

  • 名詞 scale-up の米語発音をIPAで示すと /ˈskeɪlˌʌp/。第1音節に主強勢、第2音節に副強勢がある。動詞句と名詞の語としての強勢を区別する。

コアイメージ

対象の規模・寸法・処理能力などを、より大きな段階へ進めること。拡大する動作だけでなく、その過程や拡大段階の企業を指す名詞にもつながるが、成功・採算性・持続可能性を必ず含むわけではない。

  • 規模を大きくする事業の操作 → 「規模や量を拡大する」（語義1）
  • 規模を大きくする寸法の調整 → 「寸法や縮尺を大きくする」（語義2）
  • 規模を大きくする既存機器の増強 → 「既存機器の処理能力を増強する」（語義3）
  • 規模を大きくする企業の活動 → 「事業などを拡大する」（語義4）
  • 規模を大きくする実施の過程 → 「規模拡大・拡大実施」（語義5）
  • 規模を急速に大きくする企業 → 「急成長段階の企業」（語義6）

語源

  • 大きさ・目盛りによる調整に関係する scale は、ラテン語 scālae「はしご」に結び付く系列。魚のうろこなどを表す別系列の同綴り語とは区別する。up はこの句で、程度・規模を大きくする方向を表す。構成語の来歴や関連する scale down の記録を、scale up という句の確定した初出年代と取り違えない。

語形成

scales up／scaled up／scaling upscale の部分を活用する。scales /skeɪlz/ と scaled /skeɪld/ は1音節、scaling /ˈskeɪlɪŋ/ は2音節で第1音節に主強勢がある。
scale-up拡大の過程などを表す名詞。企業を指す名詞用法では複数形 scale-ups を取る。企業の文脈では scaleup／scaleups の綴りも見られる。
scaled-up model／scale-up process前者は過去分詞による修飾、後者は名詞による修飾として捉えられる。この形だけから独立した形容詞義を作らない。

語義 1

【句動詞・他動詞】規模や量を拡大する

頻度 6/10
事業、生産、計画の拡大、技術的な能力調整など。

生産、活動、計画、処理能力などの規模や量を大きくする。

文法パターン5
  • scale up 〈名詞目的語〉
  • scale 〈名詞目的語〉 up
  • scale it up
  • be scaled up
  • a system + scale itself up。拡大対象を目的語にする。
コロケーション・構文例5

scale up production

用途生産規模を大きくすることを述べる。

例The manufacturer scaled up production after demand increased.

訳需要が増えた後、その製造会社は生産規模を拡大した。

scale the programme up（scale up の目的語中置）

用途名詞目的語を scale と up の間に置く。

例They scaled the programme up to serve more communities.

訳彼らは、より多くの地域にサービスを届けるため、事業を拡大した。

scale it up（scale up の代名詞中置）

用途既に述べた計画を代名詞で受ける。

例The pilot worked well, but we still need to find a way to scale it up.

訳試験実施はうまくいったが、規模を拡大する方法はまだ見つける必要がある。

be scaled up（scale up の受動態）

用途拡大される活動を主語にする。

例The operation was scaled up, but costs rose faster than revenue.

訳事業は拡大されたが、費用は売上より速く増えた。

scale itself up（scale up の再帰構文）

用途システムが自動的に能力を増やすことを述べる。

例The system can scale itself up when demand rises.

訳そのシステムは、需要が増えると自動的に処理能力を増やせる。

語法・注意1
  • 代名詞は scale と up の間に置き、scale up it としない。拡大したことと成功したことは別で、採算悪化や負担増とも両立する。自動調整の再帰構文があっても、人の自信を高めるという専用慣用句の証拠にはならない。
反意語1

scale down

頻度 5/10

定義規模や量を小さくする。

違い同じ規模調整の軸で方向が対になる。事業の開始・終了、成功・失敗という別の軸とは区別する。

例The company scaled down the project to control costs.

訳会社は費用を抑えるため、計画の規模を縮小した。

語義 2

【句動詞・他動詞】寸法や縮尺を大きくする

頻度 4/10
設計、模型、図面、表示など。

図、模型、設計などを、元のものに対応する大きな寸法へ調整する。縮尺を変更する場合には比例関係が重要になる。

文法パターン4
  • scale up a design
  • scale a model up
  • scale something up to 〈拡大後の寸法〉
  • scale something up by 〈増加量〉。
コロケーション・構文例3

scale up a design

用途小型の設計を大きな実物向けに調整することを述べる。

例The engineers scaled up the design after testing a small model.

訳技術者たちは、小さな模型を試験した後、設計を大きな寸法へ調整した。

scale something up to a larger size（scale up の構文）

用途to 以下で拡大後の寸法を示す。

例The diagram was scaled up to twice its original width.

訳その図は、元の2倍の幅に拡大された。

scale something up by a percentage（scale up の構文）

用途by 以下で寸法をどれだけ増やすかを述べる。

例Scale the image's width up by twenty percent.

訳画像の幅を20パーセント大きくしてください。

語法・注意1
  • to twice は元の2倍の寸法にすること、by twenty percent は元の寸法から20パーセント増やすこと。幅と面積など、異なる量を混同しない。事業を拡大する一般用法まで、必ず全要素の比率をそのまま保つ意味に限定しない。
反意語1

scale down

頻度 4/10

定義図や模型を小さい寸法へ調整する。

違い元のものに対応するサイズ調整で逆方向になる。物理寸法の調整と、活動を全廃することは別である。

例She scaled the drawing down to fit the page.

訳彼女はページに収まるよう、図を縮小した。

語義 3

【句動詞・他動詞】既存機器の処理能力を増強する

頻度 4/10
クラウドやシステム構成で、垂直方向と水平方向の増強を区別する文脈。

コンピューティングで、既存の機器・インスタンスなどに割り当てるCPUやメモリ等を増やし、一台・一インスタンス側の能力を高める。

文法パターン3
  • scale up a server
  • scale up an instance
  • a server + be scaled up。増強対象の機器・インスタンスを目的語または受動文の主語にする。
コロケーション・構文例2

scale up a server

用途既存サーバーの能力を増やすことを述べる。

例We scaled up the server by allocating more memory to it.

訳私たちは、そのサーバーにより多くのメモリを割り当てて、処理能力を増強した。

be scaled up（scale up の受動態）

用途台数追加とは異なる増強を受動構文で述べる。

例The instance was scaled up rather than replaced with several smaller instances.

訳複数の小さなインスタンスへの置換ではなく、既存インスタンスの処理能力を増強する措置が取られた。

語法・注意1
  • この垂直方向という限定は、システム構成の対比をしている文脈に適用する。一台側の能力を高めるために、より大きなインスタンスや機器へ切り替える場合もあり、同じ物理機器を必ず維持するという意味ではない。他分野の scale up や、広い意味での自動的な能力増加にまで一律に当てはめない。医療・社会事業などの普及では、horizontal scale-up が地域への複製・展開を指す使い方もある。
類義語1

scale out

頻度 3/10

定義台数・インスタンス数などを増やして処理能力を増やす。

違いこのシステム構成の文脈では、scale up が既存側の能力増強、scale out が並列の台数などを増やす方法を示す。一般英語全体の固定的な対立とはしない。

例The service scaled out by adding more instances.

訳そのサービスはインスタンスを追加し、台数を増やして処理能力を高めた。

語義 4

【句動詞・自動詞】事業などを拡大する

頻度 5/10
企業の成長、事業運営。

企業や組織が、事業・活動の規模を大きくする。拡大対象が文脈上分かる場合に、直接目的語なしで用いる。

文法パターン3
  • a company + scale up
  • a business + be scaling up
  • we + scale up。活動を拡大する企業などを主語にする。
コロケーション・構文例2

a company + scale up

用途企業自体を主語として成長・事業拡大を述べる。

例The company is scaling up, but it still faces cash-flow problems.

訳その会社は事業を拡大しているが、依然として資金繰りの問題を抱えている。

we + scale up

用途文脈上の活動を目的語なしで拡大すると述べる。

例We need stronger management systems before we scale up.

訳事業を拡大する前に、より強固な管理の仕組みが必要だ。

語法・注意1
  • 自動詞として使っても、拡大が自然に起こり経営判断が介在しない、という意味にはならない。新規企業だけに限定されず、既存の企業や組織の拡大にも使う。
語義 5

【名詞・不可算】scale-up：規模拡大・拡大実施

頻度 3/10
技術、製造、研究、事業や施策の普及など。

小さな規模や試験実施から、より大きな規模・広い範囲での実施へ進む過程。ここでは、その過程を捉える不可算用法を扱う。

文法パターン3
  • prepare for scale-up
  • successful scale-up
  • the scale-up of a programme。過程としての名詞と、語義6の企業を数える名詞を区別する。
コロケーション・構文例2

prepare for scale-up（scale up の名詞形）

用途試験実施後の規模拡大に備えることを述べる。

例The team prepared for scale-up after the pilot succeeded.

訳試験実施が成功した後、チームは規模拡大に備えた。

successful scale-up（scale up の名詞形）

用途拡大がうまく進むための条件を述べる。

例Successful scale-up may require changes to the original programme.

訳規模拡大を成功させるには、元の事業を変更する必要があるかもしれない。

語法・注意1
  • 寸法や数学の文脈で一定比率の増大を指す名詞定義もあるが、事業・施策の拡大では内容を調整しながら広げる場合もある。ここで示す不可算用法だけを、名詞の全ての文脈へ一般化しない。scale-up process の scale-up は名詞による修飾であり、独立形容詞だと決めない。
語義 6

【名詞・可算】scale-up：急成長段階の企業

頻度 3/10
起業、成長企業、事業支援。scaleup の綴りも見られる。

初期の試行段階を越え、確かめられた事業モデルを基に、繰り返し展開できる形で急速に規模を拡大している企業。

文法パターン4
  • a scale-up
  • scale-ups
  • a scaleup
  • scaleups。企業を一社、二社と数える名詞。
コロケーション・構文例2

a scale-up（scale up に対応する企業名詞）

用途一社の急成長段階の企業を指す。

例The fund supports a scale-up that is entering new markets.

訳そのファンドは、新市場へ進出している急成長段階の企業を支援している。

scale-ups（scale up に対応する企業名詞の複数形）

用途複数の急成長段階の企業を指す。

例Several scale-ups joined the programme to improve their management systems.

訳複数の急成長段階の企業が、管理体制を改善するためその事業支援プログラムに参加した。

語法・注意1
  • scale-up という企業分類に用いる成長率・年数・従業員数などの基準は、機関や制度によって異なり得る。一つの数値条件を英単語全体の唯一の定義にしない。成長段階であることは、必ず黒字で安定していることや、今後も成長する保証を意味しない。
類義語1

startup

頻度 6/10

定義新しく設立された企業、特に新しい事業を試みる企業。

違い初期の立上げ・探索段階に焦点を置きやすい。scale-up は事業モデルを基に急速に拡大する段階を捉え、単純な同義語として置き換えるのではなく、企業の段階を比較する語である。ただし企業の実態は連続的で、両ラベルの境界を全機関が同じように区切るとは限らない。

例The startup is still testing whether customers will pay for its service.

訳その新興企業は、顧客がサービスに料金を払うかどうかを、まだ検証している。

該当する語義・用例がありません。
