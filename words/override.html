override

主要語義 14更新 2026-10-19

発音記号

動詞：米: /ˌoʊvərˈraɪd/｜英: /ˌəʊvəˈraɪd/

  • 名詞：米: /ˈoʊvərˌraɪd/｜英: /ˈəʊvəˌraɪd/
  • どちらも3音節。動詞は第3音節が主強勢、第1音節が第二強勢。名詞では第1音節が主強勢、第3音節が第二強勢となる代表形を示す。米英差は第1音節の /oʊ/ と /əʊ/、第2音節の /vər/ と /və/ で、米では r を発音する。
  • overrode の第3音節は米 /roʊd/、英 /rəʊd/。overridden の後半は /ˈrɪdən/。形容詞 overriding は動詞と同様に ride の部分が主強勢。

コアイメージ

大部分に共通するのは、既存の相手・働きの上に立って、それを越えたり抑えたりすること。語義9・10・14は制度的専門義で、配下の売上から生じる報酬や資源の収益権という語彙的意味をこの核から自然には導けないため、個別に参照する。語義12は歴史的残存義で、馬を乗りすぎて疲弊させる意味がこの核から導けないため、個別に参照する。

  • 上に立つ力としての、決定・意向の排除 → 「権限・強い力で覆す・無視して押し切る」（語義1）
  • 上に立つ力としての、判断材料の優先 → 「優先する・他の要素を抑える」（語義2）
  • 上に立つ入力としての、制御・設定の変更 → 「自動制御・設定に優先して操作する」（語義3）
  • 上に立つ実装としての、継承メソッドの再定義 → 「継承したメソッドをオーバーライドする」（語義4）
  • 上に立つ働きとしての、優先・取消しの行為 → 「優先操作・決定を覆す行為」（語義5）
  • 上に立つ働きとしての、優先操作機構 → 「優先操作装置・手動切替機構」（語義6）
  • 上に立つ重要性としての、最優先事項 → 「最優先の・他に勝る」（語義7）
  • 上に立つ物体としての、物理的な重なり → 「上に乗り重なる・覆って進む」（語義8）
  • 上に立つ効力としての、登記外の権利 → 「登記簿に現れなくても権原を拘束する」（語義11）
  • 上に立つ移動としての、騎乗による突破 → 「騎乗して乗り越える・踏み越える」（語義13）

語源

  • 古英語の「馬などに乗って上を越える」に相当する語にさかのぼり、over と ride の系列から成る。乗り越える物理的な意味と、他の力・判断を押しのける意味がある。ride、rider、riding は同じ系列。すべての専門用語の制度的内容を「乗り越える」だけから推定しない。

語形成

overrides／overrode／overridden／overriding三人称単数現在／過去形／過去分詞／現在分詞。overrided は不可。
overrides名詞 override の複数形でもある。名詞と動詞で強勢が異なる。
overriding形容詞として「最優先の・決定的な」が定着している。語義7を参照。物理的な重なりの現在分詞とも区別する。
overriddenan overridden decision、be overridden by のような分詞・受動形。単独で別の心理的評価を表す形ではない。

語義 1

【動詞：他動詞】権限・強い力で覆す・無視して押し切る

頻度 6/10
一般・組織・法律・政治。

決定・拒否・規則・意向などを、より強い権限や力によって退け、その効力・支配を及ばなくする。正当に権限を行使する場合も、他人の権利を不当に無視する場合もあり、正当性は語自体では決まらない。

文法パターン3
  • override a decision/a veto＝決定・拒否権を覆す
  • override someone’s wishes＝意向を無視して押し切る
  • be overridden by 〈権限・判断〉＝それによって覆される。
コロケーション・構文例5

override a decision

用途上位の判断で決定を覆す。

例The director overrode the committee’s decision to postpone the launch.

訳責任者は発売を延期するという委員会の決定を覆した。

override a veto

用途政治上の拒否権を覆す。

例Both houses voted by the required majority to override the president’s veto.

訳両院は必要な多数で、大統領の拒否権を覆すことを可決した。

override someone’s wishes

用途本人の意向に反して押し切る。

例The committee overrode the residents’ wishes and approved the plan.

訳委員会は住民の意向を押し切って計画を承認した。

be overridden by 〈上位規則〉（override の過去分詞）

用途規範の優先関係を受動で示す。

例The local rule was overridden by a higher-level requirement.

訳その地域の規則は上位の要件によって適用が退けられた。

override someone’s rights

用途権利を軽視して行動することを批判する。

例Convenience does not justify overriding employees’ rights.

訳便利だからといって従業員の権利を無視してよいことにはならない。

語法・注意1
  • 米連邦議会による通常の大統領拒否権の override は両院で必要な3分の2の賛成を要する。この制度の数字を他国・地方自治体に一般化しない。override は法律の repeal「廃止」や裁判の appeal「上訴」そのものではなく、個別制度の手続きは別に確認する。人に対して override someone とも言えるが、その人の判断・意向を押し切る意味になる。

語義 2

【動詞：他動詞】優先する・他の要素を抑える

頻度 6/10
一般・論説・意思決定。

ある理由・感情・必要性などが、他の考慮事項より強く働き、判断を左右する。正式な取消しの権限がなくても使う。

文法パターン2
  • 〈理由・感情〉 + override + 〈判断・配慮〉＝その働きに優先する
  • let something override something＝ある要素を他より優先させる。
コロケーション・構文例4

override other considerations

用途優先順位を示す。

例Safety overrides all other considerations in this procedure.

訳この手順では安全がほかのあらゆる考慮事項に優先する。

let 〈感情〉 override one’s judgment

用途感情による判断への影響を示す。

例Do not let anger override your judgment.

訳怒りで判断を狂わせないようにしなさい。

〈必要性〉 + override + 〈好み〉

用途個人の選好と必要条件を対比する。

例The need for accessibility overrode the designer’s preference for stairs.

訳利用しやすさの必要性が、階段を好む設計者の意向に優先した。

be overridden by 〈強い要因〉（override の過去分詞）

用途弱い側を主語にする。

例His doubts were overridden by his desire to help.

訳彼は疑念よりも、助けたいという思いが勝った。

語法・注意1
  • outweigh は比較上の重みが大きいこと、override は他の要素の働きを押しのけることに焦点がある。「より大きい」だけなら exceed、outweigh などを選ぶ。
類義語3

outweigh

頻度 7/10

定義重要性・影響力で上回る。

違い必ずしも他の要素を無効にしない。

例The benefits outweigh the inconvenience.

訳利益は不便さを上回る。

take precedence over

頻度 6/10

定義優先順位が上である。

違い押し切る力より、優先関係を中立的に示す。

例Public safety takes precedence over convenience.

訳公共の安全は利便性に優先する。

dominate

頻度 7/10

定義他の要素を抑えて大きな影響を及ぼす。

違い継続する支配にも使い、明確な比較項の取消しは不要。

例Fear dominated the discussion.

訳恐れが議論を支配していた。

語義 3

【動詞：他動詞】自動制御・設定に優先して操作する

頻度 6/10
機械・制御・ソフトウェア設定。

通常の自動制御・既定設定・既存の指示を一時的または選択的に適用させず、別の入力や操作を優先させる。装置を破壊したり、元の設定を永久に消したりすることは必須でない。

文法パターン4
  • override an automatic control＝自動制御に優先して操作する
  • override the default settings＝既定設定を上書きする
  • manually override something＝手動で優先操作する
  • override something with something＝別の設定などを優先させる。
コロケーション・構文例4

manually override the controls

用途手動操作を優先する。

例The technician manually overrode the automatic controls during the test.

訳技術者は試験中、自動制御に優先して手動操作を行った。

override the default settings

用途既定値より個別設定を優先する。

例Users can override the default settings for each project.

訳利用者はプロジェクトごとに既定設定を変更できる。

override something with 〈設定〉

用途何を代わりに適用するか示す。

例The command-line option overrides the saved value with a temporary setting.

訳そのコマンドラインオプションは、保存値に代えて一時的な設定を優先適用する。

be overridden by 〈操作員〉（override の過去分詞）

用途優先操作を行う人を示す。

例The scheduled command can be overridden by an authorized operator.

訳予定された指令は、権限のある操作員が優先操作によって変更できる。

語法・注意1
  • override と overwrite は区別する。overwrite a file はファイルの内容を書き換えること、override a setting は別の指定を優先させること。手動の場合が多いが、上位の自動指示が下位設定を override することもある。安全装置の解除を単語の標準用途として推奨する表現ではない。
類義語2

bypass

頻度 5/10

定義通常通る制御・処理を迂回する。

違い経路・機構を通らないことが中心で、代わりの命令を優先するとは限らない。

例The test mode bypasses the normal startup sequence.

訳試験モードは通常の起動手順を迂回する。

supersede

頻度 5/10

定義新しいものが既存のものより優先して置き換わる。

違い装置操作に限らない形式的な語。

例The new configuration supersedes the previous one.

訳新しい設定が以前の設定に取って代わる。

語義 4

【動詞：他動詞】継承したメソッドをオーバーライドする

頻度 4/10
プログラミング。具体的な適合条件は言語による。

オブジェクト指向言語などで、継承元にあるメソッドに対して派生側の実装を定義し、対応する呼出しでその実装を使うようにする。

文法パターン3
  • override a method＝メソッドをオーバーライドする
  • override a superclass method＝親クラスのメソッドを再定義する
  • be overridden in a subclass＝派生クラスで再定義される。
コロケーション・構文例4

override a method

用途継承した実装を置き換える。

例The subclass overrides the method to return a localized message.

訳そのサブクラスはメソッドをオーバーライドし、言語に合わせたメッセージを返す。

override a superclass method

用途継承元を明示する。

例This Java class overrides the superclass method without changing its parameter list.

訳このJavaクラスは引数リストを変えずに親クラスのメソッドをオーバーライドする。

be overridden in a subclass（override の過去分詞）

用途定義の場所を示す。

例The instance method is overridden in the subclass.

訳そのインスタンスメソッドはサブクラスでオーバーライドされている。

override an inherited implementation

用途実装上の変更を示す。

例We override the inherited implementation to add validation.

訳私たちは検証処理を加えるため、継承した実装をオーバーライドする。

語法・注意1
  • Javaではインスタンスメソッドの override と、同名の static メソッドの hide は別。overload は同名でも引数の異なるメソッドを用意すること。親のソースを物理的に書き換える意味ではない。戻り値・アクセス権・例外などの制約を、単に同名なら成立すると説明しない。
語義 5

【名詞：可算】優先操作・決定を覆す行為

頻度 5/10
制御・計算機・政治・組織運営。

自動制御・既定の判断に優先する操作、または決定・拒否権などを覆す行為やその試み。対象を of や前置修飾で示す。

文法パターン4
  • an override of something＝それを覆す行為
  • a veto override＝拒否権を覆すこと
  • a manual override＝手動による優先操作
  • a method override＝メソッドの再定義。
コロケーション・構文例4

an override of the veto

用途政治行為を名詞で述べる。

例The legislators failed to secure an override of the veto.

訳議員たちは拒否権を覆すための賛成を確保できなかった。

a manual override

用途優先操作という出来事を指す。

例The log records every manual override of the schedule.

訳ログには予定に対する手動の優先操作がすべて記録される。

a method override

用途再定義の実例を数える。

例The reviewer checked each method override for compatibility.

訳レビュー担当者は各メソッドの再定義について互換性を確認した。

an override request

用途通常の判断に例外を求める。

例The system sends an override request to the manager.

訳システムは通常の判断を変更する承認依頼を管理者に送る。

語法・注意1
  • 可算で an override、複数 overrides。a failed override は覆そうとしたが成功しなかった場合を指し、名詞だけで成功を断定しない。manual override は操作にも装置（語義6）にもなり、ログに記録するのは操作、switch の位置を述べるのは装置。
類義語1

reversal

頻度 6/10

定義決定・方針の逆転。

違い覆った結果を示しやすく、優先権限や制御入力を必須にしない。

例The announcement marked a reversal of the earlier decision.

訳その発表は以前の決定が覆されたことを示した。

語義 6

【名詞：可算】優先操作装置・手動切替機構

頻度 4/10
機械・制御。

通常の自動制御に代えて別の操作を有効にする装置・機能。操作そのものではなく、それを可能にする仕組みを指す。

文法パターン3
  • a manual override＝手動優先機構
  • an emergency override＝非常時の優先操作機構
  • be fitted with an override＝優先機構を備える。
コロケーション・構文例2

a manual override

用途機構としての名詞用法を示す。

例The valve has a manual override beside the motor housing.

訳その弁にはモーターのケースの脇に手動優先機構が付いている。

be fitted with an override

用途装備を説明する。

例The automatic door is fitted with an emergency override.

訳その自動ドアには非常時の優先操作機構が備わっている。

語法・注意1
  • override button、override switch は、優先操作を行うボタン・スイッチ。すべての override が手動とは限らない。単なる電源スイッチやリセット機能と同一とはしない。
語義 7

【形容詞：overriding；主に限定】最優先の・他に勝る

頻度 6/10
一般・論説・仕事。

他の考慮事項より重要で、最終判断を左右する。動詞の現在分詞と同形だが、名詞の前で重要性を表す形容詞として定着している。

文法パターン3
  • an overriding concern/reason＝最優先の懸念・決定的な理由
  • the overriding priority＝最優先事項
  • be overriding＝最優先である。
コロケーション・構文例4

the overriding priority（override の形容詞形 overriding）

用途優先事項を一つ強く示す。

例Protecting the archives is our overriding priority.

訳記録資料を守ることが、私たちの最優先事項だ。

an overriding concern（override の形容詞形 overriding）

用途他の要素を上回る懸念を示す。

例Cost was an overriding concern throughout the negotiations.

訳交渉を通じて、費用が最も重要な懸念事項だった。

an overriding reason（override の形容詞形 overriding）

用途判断を決める理由を示す。

例There is no overriding reason to abandon the project.

訳その事業を断念する決定的な理由はない。

be overriding（override の形容詞形 overriding）

用途やや硬い叙述用法を示す。

例In this decision, the need for confidentiality was overriding.

訳この決定では、機密保持の必要性が何よりも優先された。

語法・注意1
  • 名詞の前での使用が中心。叙述用法は可能だが、日常的な become/get overriding の連鎖を定型として覚えない。意味が強く、通常 more overriding のような比較より more important とする。an overriding concern は形容詞、a rule overriding local policy は目的語を伴う分詞節。 overarching は「個々の事項を包含する全体的な」という対照表現で、最優先という意味とは一致しない。

decisive

語義 8

【動詞：他動詞】上に乗り重なる・覆って進む

頻度 2/10
物理的描写・地質・医学。

ある物が別の物の上へ進み、覆ったり重なったりする。地質ではプレートや氷、医学ではずれた骨片などに使われる。

文法パターン3
  • 〈上側の物〉 + override + 〈下側の物〉＝その上に乗り重なる
  • be overridden by something＝その下側となる
  • override each other＝互いに重なる。
コロケーション・構文例3

〈plate〉 + override + 〈plate〉

用途沈み込む側との上下関係を述べる。

例In the diagram, the upper plate overrides the subducting plate.

訳図では、上盤側のプレートが沈み込むプレートの上に乗り重なっている。

〈ice〉 + override + 〈地形〉

用途氷が覆って進む物理描写。

例The advancing ice overrode the low ridge.

訳前進する氷が低い尾根を覆って乗り越えた。

〈bone fragments〉 + override + each other

用途骨片の重なりを示す。

例The X-ray showed that the bone fragments overrode each other.

訳X線画像では、骨片同士が重なっていることが分かった。

語法・注意1
  • 医学の overriding は骨片の長軸方向の重なりと短縮を指すことがあり、単なる角度のずれと同一ではない。地質の overriding plate は上側で、subducting plate は下へ沈む側。これらを「最重要のプレート」と形容詞の語義7で訳さない。具体的な病態・地質機構をこの語だけで決めない。
類義語1

overlap

頻度 7/10

定義一部が重なり合う。

違い静的な配置にも広く使い、上へ乗り越える動きは必須でない。

例The two fragments overlap along the shaft.

訳二つの骨片は骨幹に沿って重なっている。

語義 9

【名詞：可算】部下・代理人の売上に対する上乗せ手数料

頻度 2/10
主に米の販売・保険代理店などの報酬実務。

管理者や上位代理店などに、配下の営業担当者・代理人の売上を基に支払われる手数料。本人自身の販売だけに対する通常の手数料とは区別される。

文法パターン2
  • an override on sales＝売上に対する上乗せ手数料
  • an override commission＝上位者への歩合手数料。
コロケーション・構文例2

an override on 〈売上〉

用途どの売上から生じる報酬かを示す。

例The manager receives an override on the sales made by her team.

訳マネージャーはチームの売上に対する上乗せ手数料を受け取る。

an override commission

用途報酬の名称を明示する。

例The agreement sets out the override commission payable to the regional agent.

訳契約には地域代理店に支払う上乗せ手数料が定められている。

語法・注意1
  • 率・対象売上・支払条件は契約次第であり、override という語だけから特定の割合や違法性を推測しない。制度や販売形態の名称ではなく、報酬の種類。
類義語1

commission

頻度 7/10

定義売上などに応じて払われる手数料。

違い本人の直接販売への報酬も含む上位概念で、配下の売上に限定されない。

例The agent earns a commission on each sale.

訳代理人は販売ごとに手数料を得る。

語義 10

【名詞：可算】追加ロイヤルティ権益・オーバーライド

頻度 2/10
主に米の石油・ガス取引。専門的。

石油・ガスなどの資源開発でいう overriding royalty またはその権益。通常、作業権益から切り出され、生産の一部などを受け取る権利を指す。

文法パターン2
  • retain an override＝追加ロイヤルティ権益を留保する
  • an override on a lease＝リースに付随する追加ロイヤルティ権益。
コロケーション・構文例2

retain an override

用途権益を留保する取引を示す。

例The assignor retained an override when it transferred the oil and gas lease.

訳譲渡人は石油・ガスのリースを移転する際、追加ロイヤルティ権益を留保した。

an override + burden + a lease

用途追加ロイヤルティ権益がリースに負担を課すことを示す。

例The buyer asked whether an override burdened the lease.

訳買い手は、そのリースに追加ロイヤルティ権益の負担が付いているか尋ねた。

語法・注意1
  • 完全形は overriding royalty interest。開発・生産費用を負担しない権益として説明されるが、控除・存続期間・税務などの細部は契約と法域による。永久の鉱物所有権や、語義9の営業手数料と同一にしない。資料によって略称の使い方が異なるため、契約では定義条項を確認する。
語義 11

【形容詞：overriding；主に限定】登記簿に現れなくても権原を拘束する

頻度 2/10
法律・不動産登記。イングランド・ウェールズ。

イングランド・ウェールズの土地登記制度で、登記簿に記載されていなくても登録された権原や取得者を拘束する一定の権利・利益についていう。overriding interest という専門表現が中心。

文法パターン2
  • an overriding interest＝登記簿に現れなくても拘束力を持つ一定の権利
  • have overriding status＝その優越的な地位を持つ。
コロケーション・構文例2

an overriding interest（override の形容詞形 overriding）

用途制度上の専門表現を示す。

例The solicitor investigated whether the occupier had an overriding interest.

訳弁護士は占有者が登記に現れなくても対抗できる権利を持つか調べた。

have overriding status（override の形容詞形 overriding）

用途法的な地位を述べる。

例The interest had overriding status despite not appearing in the register.

訳その権利は登記簿に現れていなかったものの、優先的な拘束力を持っていた。

語法・注意1
  • 単に重要な利益という語義7ではない。どの権利が該当するかは初回登記・後の処分などで区別され、占有しているだけで常に成立するとはいえない。HM Land Registry の用語であり、他国の登記制度にそのまま当てはめない。
語義 12

【動詞：他動詞】馬を酷使して乗る

頻度 1/10
古め・乗馬の語彙。

馬などに長く、または激しく乗りすぎて疲弊させる。

文法パターン2
  • override a horse＝馬に乗りすぎて酷使する
  • be overridden＝乗られすぎて疲れる。
コロケーション・構文例1

override a horse

用途過度の騎乗を表す。

例The guide warned the riders not to override their horses on the long journey.

訳案内人は長旅で馬を酷使しすぎないよう騎手たちに注意した。

語法・注意1
  • 乗っている人が馬より優先されるという現代の制御義ではない。日常的には ride a horse too hard と言えば明確。override a rider と目的語を騎手にしない。
類義語1

overwork

頻度 5/10

定義働かせすぎて疲れさせる。

違い動物にも人にも使い、騎乗には限定しない。

例The farmer refused to overwork the tired animals.

訳農場主は疲れた動物を酷使しようとはしなかった。

語義 13

【動詞：他動詞】騎乗して乗り越える・踏み越える

頻度 1/10
古風・歴史的描写。

馬などに乗ったまま対象の上や向こう側へ進む。人や隊列を踏み越えて突破する古い戦闘描写などに使う。

文法パターン1
  • override 〈障害・隊列〉＝騎乗して踏み越える。
コロケーション・構文例1

override a line of defenders

用途騎兵の物理的な突破を示す。

例The cavalry overrode the thin line of defenders.

訳騎兵隊は手薄な防衛隊列を踏み越えて突破した。

語法・注意1
  • 現代の道路で車が人をひく場合は run over someone が普通で、override someone を一般的な交通事故表現にはしない。語義1の「意向を押し切る」と文脈を区別する。
類義語1

trample

頻度 4/10

定義踏みつける・踏みにじる。

違い騎乗の有無を問わない。

例The horses trampled the fallen fence.

訳馬たちは倒れた柵を踏みつけた。

語義 14

【動詞：他動詞】配下の売上から手数料を受け取る

頻度 1/10
米の販売報酬用語。辞書に収録されるが、名詞形の方が理解されやすい。

上位の販売代理人などが、配下の代理人の販売に基づく手数料を受け取る。名詞 override に対応する低頻度の業務用法。

文法パターン1
  • override 〈下位代理人〉＝その代理人の売上から手数料を受け取る。
コロケーション・構文例1

override a subagent

用途古めの専門的な動詞用法を示す。

例Under the arrangement, the regional agent overrode each subagent in the district, receiving a commission on each subagent’s sales.

訳その取り決めでは、地域代理人は地区内の各下位代理人について、その売上に応じた上乗せ手数料を受け取った。

語法・注意1
  • この用法は一般的な「代理人の判断を覆す」と紛らわしい。実務では receive an override on a subagent’s sales と明記する方が安全に意味を伝えられる。現代の出現頻度を広く確認できる資料は限られるため、一般語として頻用しない。
類義語1

earn a commission

頻度 5/10

定義販売などに応じた手数料を得る。

違いこちらは本人の直接販売の報酬も含む。override のこの用法は配下の販売に基づく上位者の取り分を表す。

例The supervisor earned a commission on sales made by her agents.

訳その監督者は、自分の配下の代理人たちの売上に応じた手数料を得た。

該当する語義・用例がありません。
