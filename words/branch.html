branch

主要語義 19更新 2026-10-12

発音記号

米: /bræntʃ/｜英: /brɑːntʃ/。1音節。第1音節の母音が、代表的な米音では /æ/、ここに示した英音では /ɑː/ となる。イギリス内にも /æ/ を使う地域がある。語末は /tʃ/ で、複数形・三人称単数現在形 branches は /ˈbræntʃɪz/（米）、/ˈbrɑːntʃɪz/（英）と1音節増える。過去形・過去分詞 branched は /bræntʃt/（米）、/brɑːntʃt/（英）で、-ed は /t/。

コアイメージ

幹や中心となるものから分かれて伸びる部分、またはそのように分かれること。物理的な枝や経路から、組織・知識・系統・処理の流れにも広がる。

  • 中心から分かれた各地の営業・活動拠点 → 「支店、支部、分館」（語義1）
  • 中心から分かれた植物の部分 → 「枝」（語義2）
  • 中心から分かれた組織の機能別部分 → 「部門、部局」（語義3）
  • 中心から分かれた知識の領域 → 「分野、部門」（語義4）
  • 中心から分かれた道や流れの部分 → 「分岐路、支流、支線」（語義5）
  • 中心から分かれた血筋や言語の流れ → 「系統、分家」（語義6）
  • 中心から分かれて経路を伸ばす変化 → 「枝分かれする、分岐する」（語義7）
  • 中心から分かれて活動を伸ばす変化 → 「新分野に進出する、活動を広げる」（語義8）
  • 中心から分かれた経路へ進む行為 → 「脇道に入る、進路を変える」（語義9）
  • 中心から分かれた末端と根本まで及ぶ程度 → 「徹底的に、根こそぎ」（語義10）
  • 中心から分かれた末端と根本まで及ぶ性質 → 「抜本的な、全面的な」（語義11）
  • 中心から分かれた部分を持つ構造 → 「枝のある、枝分かれした」（語義12）
  • 中心から分かれたプログラムの処理経路 → 「処理の分岐、分岐先」（語義13）
  • 中心から分かれたソフトウェア開発の流れ → 「開発ブランチ」（語義14）
  • 中心から分かれた処理経路へ進む動作 → 「処理が分岐する」（語義15）
  • 中心から分かれて新たな開発へ進む行為 → 「開発の流れを分ける、新しいブランチを作る」（語義16）
  • 中心から分かれた開発系列を作成する行為 → 「開発ブランチを作成する」（語義17）
  • 中心から分かれるように対象を分割する行為 → 「～を枝分かれさせる、分割する」（語義18）
  • 中心から分かれた曲線の区別される部分 → 「曲線の枝」（語義19）

語源

  • 中英語からさかのぼると、古フランス語・アングロフランス語の branche、後期ラテン語の branca「動物の足、前足」に関係する。現代の学習では、幹から分かれて伸びる枝を、組織・学問・経路などの分かれた部分に重ねると理解しやすい。brunch「ブランチ、朝昼兼用の食事」は breakfast と lunch の混成語で、branch とは別の語である。

語形成

branches名詞の複数形「枝、支店など」、動詞の三人称単数現在形「枝分かれするなど」。
branched動詞の過去形・過去分詞。形容詞として「枝のある、枝分かれした」という構造も表す。語義12を参照。
branching現在分詞・動名詞。「枝分かれすること」。branching paths は「枝分かれしていく経路」で、過程にも構造にも着目できる。
branchless形容詞。「枝のない」。技術文脈の branchless code は条件分岐を用いないコードを指す。
branch office複合名詞。「支店、支社」。branch が名詞 office を前から修飾する。

語義 1

【名詞・可算】支店、支部、分館

頻度 8/10
一般、企業、サービス、団体運営。

会社・団体・施設などの一部として、別の場所で営業・活動する拠点。銀行や店舗の「支店」、団体の「支部」、図書館の「分館」などを指す。

文法パターン1
  • a branch of 〈会社・団体〉＝その支店・支部。a local branch＝地域の支店・支部。open a branch in 〈都市〉＝そこに支店を開く。a branch office＝支店・支社。a branch manager＝支店長。at one's nearest branch＝最寄りの支店で。
コロケーション・構文例6

a branch of 〈会社・団体〉

用途拠点の所属を明示する。

例A new branch of the bookstore will open near the station.

訳その書店の新しい支店が、駅の近くに開店する予定だ。

a local branch

用途地域の営業・活動拠点。

例Please contact your local branch for opening hours.

訳営業時間については、お近くの支店にお問い合わせください。

open a branch in 〈都市〉

用途新しい拠点の開設。

例The bank plans to open a branch in Sapporo next spring.

訳その銀行は、来春札幌に支店を開く予定だ。

a branch office

用途本社と区別した事務所。

例The company has a branch office on the fifth floor.

訳その会社は、5階に支店の事務所を置いている。

a branch manager

用途支店の責任者。

例The branch manager will review your application.

訳支店長が、あなたの申込書を確認する予定だ。

at one's nearest branch

用途利用する窓口を案内する。

例You can return the library book at your nearest branch.

訳その図書館の本は、最寄りの分館で返却できます。

語法・注意1
  • 単数は a branch、複数は branches。branch office の branch は名詞の前置修飾で、単数形を使う。ここでは独立した「支店の」という形容詞義を立てない。支店は通常同じ会社の一部で、subsidiary「子会社」はそれ自体が別の会社という違いがある。headquarters「本社・本部」は統括する中心であり、支店と同じではない。a branch of the bank の of は所属、a branch in Kobe の in は所在地を示す。地方の支店とは限らず、同じ都市内の別店舗も branch と呼べる。
類義語3

outlet

頻度 7/10

定義商品やサービスを販売する店舗・窓口。

違い販売の場所という機能が中心で、団体の支部や図書館の分館には通常使わない。安売り店だけを意味するわけではない。

例The chain has more than 80 retail outlets.

訳そのチェーンには、80店を超える小売店舗がある。

chapter

頻度 5/10

定義大きな団体の地域支部。

違い協会・会員組織などの地域集団を表し、普通の銀行支店には使わない。

例The association's local chapter organizes monthly talks.

訳その協会の地元支部は、毎月講演会を開いている。

office

頻度 9/10

定義会社や組織が業務を行う事務所。

違いbranch より広く、本社・独立事務所も含む。所属組織の一拠点であることは文脈で決まる。

例Our Osaka office handles orders from western Japan.

訳当社の大阪事務所は、西日本からの注文を扱う。

語義 2

【名詞・可算】枝

頻度 9/10
一般、自然、園芸。

木の幹や太い枝、植物の主な茎などから分かれて伸びる部分。細い枝から太い枝まで指せ、葉が付いていることは必須ではない。

文法パターン1
  • a branch of 〈木〉＝その木の枝。a tree branch＝木の枝。on a branch＝枝の上に。a broken branch＝折れた枝。cut off a branch＝枝を切り落とす。the lower branches＝下のほうの枝。
コロケーション・構文例5

a branch of 〈木〉

用途枝が生えている木を示す。

例A branch of the old oak hangs over the path.

訳古いオークの木の枝が、道の上に張り出している。

on a branch

用途枝の上にいるものの位置。

例A small bird was sitting on a branch above the fence.

訳小さな鳥が、塀の上方の枝に止まっていた。

a broken branch

用途枝の状態を説明する。

例A broken branch blocked the garden gate after the storm.

訳嵐の後、折れた枝が庭の門をふさいでいた。

cut off a branch

用途剪定などで枝を切り取る。

例The gardener cut off a branch that was rubbing against the wall.

訳庭師は、壁にこすれていた枝を切り落とした。

the lower branches

用途枝の高さによる区別。

例Snow weighed down the lower branches of the pine.

訳雪の重みで、その松の下のほうの枝が垂れ下がっていた。

語法・注意1
  • twig は特に細い小枝、bough は太い大枝。branch 自体に太さの厳密な基準はない。英語では a branch of a tree と a branch on a tree の両方が使え、前者は木の一部である関係、後者は付いている位置に着目する。an olive branch は文字どおり「オリーブの枝」のほか、offer/extend an olive branch で「和解の意思を示す」という定着した比喩になる。The manager offered an olive branch by agreeing to reopen talks（話し合いの再開に同意することで、責任者は和解の意思を示した）のように使い、実際の枝を渡す必要はない。幹 trunk は木の別の部分を指す対照語で、branch の反意語ではない。
類義語3

twig

頻度 7/10

定義木や低木の細い小枝。

違いbranch より細く小さい部分を指し、通常は大きな枝をこう呼ばない。

例The nest was made of dry twigs.

訳その巣は、乾いた小枝でできていた。

bough

頻度 5/10

定義木の太い大枝。

違い大きさを強調し、文学的な描写にもよく使う。branch は太さを限定しない。

例The heavy bough bent under the weight of the fruit.

訳その太い枝は、実の重みでしなっていた。

limb

頻度 6/10

定義木の幹から伸びる大きな枝。

違い主に大きな枝を指す。人や動物の手足という別義もあるが、ここでは木についての用法。

例The storm tore a limb from the tree.

訳嵐で、その木の大枝がもぎ取られた。

語義 3

【名詞・可算】部門、部局

頻度 7/10
政治、行政、組織運営。

政府・軍・警察・団体などを、機能や任務によって分けた一部。語義1のような別の場所にある拠点とは限らない。

文法パターン1
  • a branch of government＝政府の一部門。the executive branch＝行政府。the legislative branch＝立法府。the judicial branch＝司法府。a branch of 〈組織〉＝その機能別部門。
コロケーション・構文例5

a branch of government

用途政府の機能別部門を指す。

例The report examines the relationship between the branches of government.

訳その報告書は、政府の各部門の関係を検討している。

the executive branch

用途行政を担う部門。

例The proposal would give the executive branch greater authority.

訳その提案は、行政府により大きな権限を与えるものだ。

the legislative branch

用途立法を担う部門。

例The legislative branch debated the proposed changes.

訳立法府は、提案された変更について審議した。

the judicial branch

用途司法を担う部門。

例The article discusses the independence of the judicial branch.

訳その記事は、司法府の独立について論じている。

a branch of 〈組織〉

用途担当業務による組織内の区分。

例She joined the investigative branch of the agency.

訳彼女は、その機関の調査部門に加わった。

語法・注意1
  • government の「部門」は店舗ではないので「政府の支店」と訳さない。行政・立法・司法という区分を説明する際によく使うが、branch という語だけで各国の制度構成や権限の詳細が決まるわけではない。department、division、section との組織上の階層関係も各組織による。語義1と同じ a branch of ... の形でも、都市・窓口を指すか、任務による一部門を指すかで意味が変わる。
類義語3

division

頻度 8/10

定義大きな組織の中で特定の業務を担う部門。

違い企業の事業部などに広く使う。branch のように政府の三権を表す定型句とは必ずしも一致しない。

例The medical devices division reported strong sales.

訳医療機器部門は、好調な売上を報告した。

department

頻度 9/10

定義特定の仕事を担当する組織内の部署。

違い経理・人事など日常的な部署名に使う。必ず branch より小さいとは限らない。

例Please contact the human resources department.

訳人事部に連絡してください。

wing

頻度 6/10

定義大きな組織の中で役割や立場を共有する一部。

違い政党の一派や組織の特定機能を持つ集団に使い、正式な行政区分とは限らない。

例The research wing develops new materials.

訳研究部門は、新しい素材を開発している。

語義 4

【名詞・可算】分野、部門

頻度 7/10
学術、教育、一般的な分野説明。

学問・知識・活動などの大きな領域の中で、独自の対象や方法を持つ一分野。

文法パターン1
  • a branch of 〈学問・活動〉＝その一分野。the branch of 〈学問〉 concerned with 〈対象〉＝その対象を扱う分野。a specialized branch of 〈領域〉＝専門化した一分野。different branches of 〈領域〉＝その領域のさまざまな分野。
コロケーション・構文例4

a branch of 〈学問〉

用途大きな学問の中の位置付け。

例Phonetics is a branch of linguistics.

訳音声学は、言語学の一分野である。

the branch of 〈学問〉 concerned with 〈対象〉

用途扱う対象を用いた分野の定義。

例Ecology is the branch of biology concerned with relationships between organisms and their environment.

訳生態学は、生物とその環境の関係を扱う生物学の分野である。

a specialized branch of 〈領域〉

用途専門性の高い下位分野。

例She works in a specialized branch of engineering.

訳彼女は、工学の専門性の高い一分野で働いている。

different branches of 〈領域〉

用途複数分野の協力や比較。

例The conference brings together researchers from different branches of science.

訳その学会には、科学のさまざまな分野の研究者が集まる。

語法・注意1
  • 「～の一分野」は a branch of ... が基本で、a branch about ... としない。branch はより大きな領域の一部である関係を示す。大学の物理的な学部・研究室を指す department とは必ずしも同じでない。専門分野の所属を表す語義であり、企業の支店を表す語義1と混同しない。
類義語3

field

頻度 9/10

定義研究・仕事・活動の領域。

違い上位分野との関係を明示せずに使え、branch より独立した領域として述べやすい。

例She is an expert in the field of robotics.

訳彼女は、ロボット工学の専門家である。

discipline

頻度 7/10

定義一定の方法や知識体系を持つ学問分野。

違い学問としての体系を強調する。branch はその中の小さな分野にも使う。

例The project combines several academic disciplines.

訳そのプロジェクトは、複数の学問分野を組み合わせている。

specialty

頻度 7/10

定義人が特に専門としている分野。

違い分野の分類だけでなく、個人・組織が専門とする対象に焦点を置く。イギリス英語では speciality という形も使う。

例Her medical specialty is cardiology.

訳彼女の医療上の専門は、循環器分野である。

語義 5

【名詞・可算】分岐路、支流、支線

頻度 6/10
地理、交通、身体の構造、一般描写。

道・川・鉄道・血管などの主要な経路から分かれたり、そこへつながったりする一つの経路。枝に似て突き出た部分を指す場合もある。

文法パターン1
  • a branch of 〈川・道路・血管〉＝その分かれた流れや経路。the eastern branch＝東側の分岐。a branch line＝鉄道などの支線。take the left branch＝左側の分岐路を進む。
コロケーション・構文例4

a branch of 〈川〉

用途川の分かれた流れ。

例This branch of the river flows through the village.

訳この川の支流は、その村を通って流れる。

a branch line

用途鉄道の本線と支線の区別。

例A short branch line connects the port to the main railway.

訳短い支線が、港と鉄道の本線を結んでいる。

take the left branch

用途道が分かれる地点での方向案内。

例At the fork, take the left branch toward the lake.

訳分かれ道では、湖のほうへ向かう左側の道を進んでください。

a branch of 〈血管〉

用途血管などの枝分かれした構造。

例The diagram shows a small branch of the artery.

訳その図は、動脈から分かれた細い血管を示している。

語法・注意1
  • 川の branch は、本流へ合流する支流にも、本流から分かれる流れにも使われるため、常に tributary と同じ流れの向きとは限らない。米国の南部・中部では branch が単に「小川」を指す地域用法もある。a branch line の branch は名詞の前置修飾。fork は道の分かれ目自体も指すが、branch はそこから伸びる側の経路に着目する。a branch of an antler「枝角の突起」のように、細く枝状に出た部分にも広がる。
類義語3

tributary

頻度 5/10

定義より大きな川へ流れ込む川。

違い合流する向きが意味に含まれる。branch は川から分かれて流れる側も表し得る。

例The stream is a tributary of the larger river.

訳その小川は、より大きな川に流れ込む支流である。

offshoot

頻度 5/10

定義主なものから枝分かれした部分。

違い派生して生じたことを強調し、植物・組織・思想などにも広く使える。

例A narrow offshoot of the path led to the beach.

訳道から分かれた細い小道が、浜辺へ続いていた。

spur

頻度 4/10

定義本線から短く分かれた道や線路。

違い特に短い支線・引込線に使い、branch より形状や用途が限定される。

例A rail spur serves the industrial park.

訳鉄道の引込線が、その工業団地に通じている。

語義 6

【名詞・可算】系統、分家

頻度 5/10
家族の歴史、言語学、系統説明。

共通の祖先や起源から分かれた、家族・言語などの一群。個々の人や言語そのものより、大きな系譜の中での位置に焦点がある。

文法パターン1
  • a branch of the family＝一族のある系統。the maternal branch of the family＝母方の家系。a branch of 〈語族〉＝その語族の一系統。
コロケーション・構文例3

a branch of the family

用途一族の中の特定の系統。

例One branch of the family settled in Australia.

訳その一族の一つの系統は、オーストラリアに定住した。

the maternal branch of the family

用途母方の系譜を述べる。

例She traced the maternal branch of her family back to a small coastal town.

訳彼女は母方の家系を、海沿いの小さな町までさかのぼって調べた。

a branch of 〈語族〉

用途言語の系統分類。

例English belongs to the Germanic branch of the Indo-European language family.

訳英語は、インド・ヨーロッパ語族のゲルマン語派に属する。

語法・注意1
  • family の branch は、日本語の法的・家制度上の「分家」と常に一致せず、単に母方・父方や特定の祖先からの系統を表すこともある。言語学の branch は語族内の系統的なまとまりで、単なる dialect「方言」の言い換えではない。共通の起源を示す of が典型的。
類義語2

line

頻度 6/10

定義祖先から子孫へつながる一つの血筋・系統。

違い連続したつながりに重点を置く。branch は、より大きな一族からの分岐を意識させる。

例The title passed down through the male line.

訳その称号は、父系を通じて受け継がれた。

lineage

頻度 5/10

定義人や集団の祖先から続く系譜。

違い出自や系譜そのものを表し、必ずしも大きな系譜の一分岐とは限らない。

例The museum documents the lineage of the ruling family.

訳その博物館は、支配者一族の系譜を記録している。

語義 7

【動詞・自動詞】枝分かれする、分岐する

頻度 6/10
一般、自然、経路・構造の説明。

植物が枝を出したり、道・管・流れなどが中心から複数の方向へ分かれて伸びたりする。組織や思想が元の系統から分かれて生じるという比喩にも使う。

文法パターン7
  • something + branch＝枝を出す・分岐する
  • branch into 〈分岐後の部分〉＝複数の部分に分かれる
  • branch from 〈もとのもの〉＝そこから分かれて伸びる
  • something + branch off＝脇へ分かれる
  • something + branch off from 〈本線・もとの流れ〉＝そこから分岐する
  • something + branch off 〈本線・もとの流れ〉＝from を置かずに分岐元を示す
  • something + branch out over 〈場所〉＝枝を張り出させる。単独の branch off の off と、branch out の out は小辞。branch off 〈本線・もとの流れ〉の off は分岐元を導く前置詞で、from/into も起点・分岐先を導く前置詞。
コロケーション・構文例7

something + branch

用途木が枝を出すこと自体を述べる。

例This tree branches close to the ground.

訳この木は、地面に近いところで枝分かれする。

branch into 〈分岐後の部分〉

用途分かれた後の数や構造。

例The pipe branches into two smaller pipes behind the wall.

訳その管は、壁の裏で2本の細い管に分かれる。

branch from 〈もとのもの〉

用途分岐する起点。

例Several narrow streets branch from the main road.

訳幹線道路から、何本かの細い道が分かれている。

branch off

用途分岐する方向や地点。

例The path branches off to the right just before the bridge.

訳その小道は、橋のすぐ手前で右に分かれる。

branch off from 〈本線・もとの流れ〉

用途本線からの分岐を明示する。

例A side road branches off from the highway near the tunnel.

訳トンネルの近くで、脇道が幹線道路から分かれている。

branch off 〈本線・もとの流れ〉

用途from を使わずに、道路の分岐元を示す。

例A narrow lane branches off the main road beside the post office.

訳郵便局のそばで、細い小道が幹線道路から分かれている。

branch out over 〈場所〉

用途植物が物理的に枝を伸ばす。

例The old tree branches out over the garden wall.

訳その古い木は、庭の塀の上に枝を張り出している。

語法・注意1
  • The pipe branches into two smaller pipes は管自体が分かれる自動詞。人が管を分ける branch the pipe into ... は他動詞で、語義18。branch from ... は物理的な起点だけでなく、ある分野・思想からの派生にも使える。道路主語の The road branches off は道路の形状、人物主語の We branched off は実際に進路を変える行為（語義9）である。木についての branch out は文字どおり枝を伸ばすが、会社や人の活動については新分野への展開を表す句動詞になる（語義8）。branch off the main road のように from なしでも分岐元を続けられる。この off は道を導く前置詞として働く。branch the road off のように直接目的語を挟む形にはしない。
類義語3

fork

頻度 6/10

定義道や流れが二つ以上の方向へ分かれる。

違い分かれ目の形状に焦点があり、特に二股に分かれる場合に使いやすい。

例The trail forks just beyond the gate.

訳その道は、門を少し過ぎたところで二手に分かれる。

diverge

頻度 6/10

定義同じ起点から異なる方向へ進む。

違い離れていく方向差に重点があり、必ずしも木のような枝状構造を想定しない。

例The two routes diverge at the edge of the forest.

訳その二つの経路は、森の端で別の方向へ分かれる。

bifurcate

頻度 3/10

定義二つの枝・部分に分かれる。

違い二分することを明示する専門的・硬い語。branch は三つ以上に分かれる場合も含む。

例The main channel bifurcates before reaching the coast.

訳主要な水路は、海岸に達する前に二つに分かれる。

反意語2

converge

頻度 6/10

定義複数の経路が一つの地点へ向かって集まる。

違い分かれて伸びる方向に対し、集まる方向という対立。完全に一体化するとは限らない。

例Several paths converge near the visitor center.

訳何本かの道が、ビジターセンターの近くに集まっている。

merge

頻度 7/10

定義複数の流れや経路が合流して一つになる。

違い分岐に対する合流という方向・結果の対立で、一つになる結果を強く表す。

例The two streams merge below the bridge.

訳二つの小川は、橋の下流で合流する。

語義 8

【句動詞・自動詞】新分野に進出する、活動を広げる

頻度 6/10
一般、事業展開、個人の活動。

branch out の形で、人・企業などが、それまでとは異なる分野・活動・事業に取り組む。活動の種類を増やすことが中心で、単に同じ商品の売上が増えるだけとは異なる。

文法パターン4
  • someone/organization + branch out＝活動を新たな方向へ広げる
  • someone/organization + branch out into 〈分野〉＝その分野へ進出する
  • someone/organization + branch out into doing something＝新しい活動を始める
  • someone/organization + branch out from 〈従来の分野〉 into 〈新分野〉＝旧分野から新分野へ活動を広げる。out は小辞、into/from は前置詞で、直接目的語は取らない。
コロケーション・構文例4

branch out

用途新たな活動への展開をまとめて述べる。

例After years of doing the same work, she decided to branch out.

訳何年も同じ仕事を続けた後、彼女は新しい分野にも取り組むことにした。

branch out into 〈分野〉

用途進出先の事業分野。

例The furniture maker is branching out into home lighting.

訳その家具メーカーは、家庭用照明にも事業を広げている。

branch out into doing something

用途新しく行う活動。

例The bakery has branched out into selling baking kits online.

訳そのパン店は、パン作りキットのオンライン販売にも進出した。

branch out from 〈従来の分野〉 into 〈新分野〉

用途展開前後の活動を対比する。

例The designer branched out from clothing into interior design.

訳そのデザイナーは、衣服からインテリアデザインへと活動分野を広げた。

語法・注意1
  • into は前置詞なので、動作を続ける場合は into selling のように -ing 形にする。branch out to sell のような目的を表す to 不定詞も文として作れるが、分野を示す基本形は branch out into ...。branch out the business や branch it out のように直接目的語を挟まない。元の活動を完全にやめることは含まれない。物理的に木の枝が伸びる branch out は語義7。市場内で規模だけを拡大するなら expand のほうが適切な場合がある。
類義語3

diversify

頻度 6/10

定義事業や活動の種類を増やす。

違い複数分野に分散する経営上の性質を強調し、branch out より事業・投資の文脈に寄りやすい。

例The company diversified into medical equipment.

訳その会社は、医療機器にも進出して事業を多角化した。

expand

頻度 8/10

定義規模や範囲を広げる。

違い新分野に進まなくても、同じ事業の規模拡大に使える。

例The retailer plans to expand into three new markets.

訳その小売業者は、新たに三つの市場へ進出する予定だ。

venture

頻度 6/10

定義不確実性や危険を伴う新しい領域へ踏み出す。

違いventure into ... は未知の分野への挑戦という含みが強い。branch out は必ずしも危険を強調しない。

例The publisher ventured into digital games.

訳その出版社は、デジタルゲームの分野に乗り出した。

語義 9

【句動詞・自動詞】脇道に入る、進路を変える

頻度 5/10
道順、旅行、移動の描写。

branch off の形で、人や乗り物が、それまで進んでいた道から別の道へ向きを変える。道自体が枝分かれしていることではなく、進む側の行為を表す。

文法パターン5
  • someone + branch off＝進路を変える
  • someone + branch off to the left/right＝左・右へ分かれて進む
  • someone + branch off onto 〈道〉＝その道へ入る
  • someone + branch off from 〈もとの道〉＝そこから外れて進む
  • someone + branch off 〈もとの道〉＝from なしで、もとの道から分かれて進む。
コロケーション・構文例4

branch off to the left

用途人が左の道へ進む。

例We branched off to the left when we reached the old mill.

訳古い製粉所に着いたところで、私たちは左の道へ入った。

branch off onto 〈道〉

用途入っていく脇道を示す。

例The cyclists branched off onto a narrow lane beside the river.

訳自転車に乗った人たちは、川沿いの細い道へ進路を変えた。

branch off from 〈もとの道〉

用途元の経路を明示する。

例We branched off from the main trail to visit the waterfall.

訳私たちは滝を見に行くため、主要な登山道から脇道へ入った。

branch off 〈もとの道〉

用途元の道を off の直後に置く。

例We branched off the main road just after the bridge.

訳橋を渡ってすぐに、私たちは幹線道路から脇道へ入った。

語法・注意1
  • The road branches off は道路が分かれる構造（語義7）、We branch off は進む人が道を変える動作。自動詞で、branch us off のように目的語を挟まない。branch off the main road では off が前置詞として道を導き、from を補わなくてもよい。branch off from the main road や branch off onto a lane では、from/onto がそれぞれ起点・移動先を導く。いずれも branch someone off のように人を直接目的語にする構造ではない。事業分野を増やす意味には通常 branch out into ...（語義8）を使う。
類義語2

turn off

頻度 8/10

定義今進んでいる道から曲がって別の道へ入る。

違い移動の指示で広く使い、branch off ほど分岐した道を意識させない。

例Turn off the main road at the next junction.

訳次の交差点で、幹線道路から曲がってください。

bear

頻度 6/10

定義進行方向を少し左または右へ向ける。

違いbear left/right は緩やかな方向変更を表し、必ず脇道に入るとは限らない。

例Bear right after the bridge.

訳橋を渡ったら、右寄りに進んでください。

語義 10

【慣用表現・副詞句】徹底的に、根こそぎ

頻度 4/10
主にイギリス英語、文章語、改革・撤廃の議論。

root and branch の形で、根本から細部まで、対象全体にわたって徹底的に変えたり取り除いたりすることを表す。根から枝まで植物全体に及ぶという比喩で、一部分だけへの対処ではない。

文法パターン1
  • reform something root and branch＝対象を抜本的に改革する。remove something root and branch＝対象を根こそぎ取り除く。通常、動詞と目的語の後で動作の及ぶ程度を示す。
コロケーション・構文例2

reform something root and branch

用途仕組みの全体を改める。

例The report argues that the funding system must be reformed root and branch.

訳その報告書は、資金配分の仕組みを抜本的に改革する必要があると論じている。

remove something root and branch

用途悪習などを徹底してなくす。

例The campaign aims to remove corruption root and branch.

訳その運動は、腐敗を根こそぎなくすことを目指している。

語法・注意1
  • root and branch は定着した組み合わせで、この意味では通常 roots and branches と複数にしない。ここでは副詞句なので、reform something root and branch のように後ろに置き、名詞を目的語に取る新たな動詞ではない。名詞前の a root-and-branch reform は「抜本的な改革」という形容詞用法で、ハイフンを使うのが普通（語義11）。副詞的に用いるときは通常 root and branch と分けて書く。
類義語2

thoroughly

頻度 8/10

定義対象の細部まで十分に、徹底的に。

違い調査・清掃などにも広く使える。root and branch は改革や排除の徹底性を強調しやすい。

例The committee examined the proposal thoroughly.

訳委員会は、その提案を徹底的に検討した。

completely

頻度 9/10

定義一部を残さず、完全に。

違い程度を一般的に表す語で、根本まで変えるという比喩的な強調は root and branch のほうが強い。

例The old system has been completely replaced.

訳古いシステムは、完全に置き換えられた。

語義 11

【慣用表現・形容詞・限定用法】抜本的な、全面的な

頻度 4/10
主にイギリス英語、文章語、改革・見直し。

root-and-branch の形で、改革・点検などが根本から細部まで全体に及ぶことを表す。名詞の前で、その範囲や徹底性を示す。

文法パターン1
  • a root-and-branch review＝全面的な見直し。root-and-branch reform＝抜本的改革。主に名詞前で用い、比較級や very による程度修飾は通常しない。
コロケーション・構文例2

a root-and-branch review

用途一部分に限らない全面的な点検。

例The board ordered a root-and-branch review of the recruitment process.

訳取締役会は、採用手続きの全面的な見直しを命じた。

root-and-branch reform

用途基本的な仕組みまで変える改革。

例The proposal calls for root-and-branch reform of local services.

訳その提案は、地域サービスの抜本的な改革を求めている。

語法・注意1
  • 名詞前では root-and-branch とハイフンで結ぶ形が一般的で、ハイフンなしの表記も見られる。a root-and-branch review では句全体が review を修飾する。We reviewed the system root and branch ではハイフンなしの副詞句が動作の程度を示す（語義10）。root-and-branch の意味は「根と枝に関する」という字義的な分類ではない。
類義語2

comprehensive

頻度 8/10

定義対象の関連する部分を広く網羅した。

違い範囲の広さに重点があり、根本から変えることまでは必ずしも含まない。

例The team conducted a comprehensive review of the policy.

訳チームは、その方針を包括的に見直した。

radical

頻度 7/10

定義基本的な仕組みにまで及ぶ、抜本的な。

違い変化の根本性を強調する。root-and-branch は細部まで含めた全体性も強調する。

例The service needs radical reform.

訳そのサービスは、抜本的な改革を必要としている。

語義 12

【形容詞・限定用法／叙述用法・branched】枝のある、枝分かれした

頻度 4/10
植物、構造の説明、化学などの専門文脈。

branched の形で、植物・管・分子などに枝や分岐がある構造を表す。実際に誰かが分けたという過去の行為を述べず、形の性質を説明できる。

文法パターン1
  • a branched stem＝枝分かれした茎。a branched chain＝枝分かれした鎖。be highly branched＝多くの分岐を持つ。単純な比較級ではなく more highly branched などで分岐の程度を比較する。
コロケーション・構文例3

a branched stem

用途植物の茎の構造。

例Each plant has a branched stem with several flower clusters.

訳それぞれの植物には、いくつかの花房を付けた枝分かれした茎がある。

a branched chain

用途分子構造の分岐。

例The molecule contains a branched chain of carbon atoms.

訳その分子は、炭素原子が枝分かれしてつながった鎖を含む。

be highly branched

用途多くの枝・分岐がある状態。

例The plant's root system is highly branched.

訳その植物の根系は、よく枝分かれしている。

語法・注意1
  • branched は名詞の前と be の後に使える。a branched stem は「枝分かれした構造の茎」で、誰かに切り分けられたという意味ではない。The stem branched は過去の動詞、The stem is branched は形の説明になる。branching は分岐していく過程にも着目でき、a branching pattern「枝分かれする模様」などに使う。よく使う程度表現は highly branched、much-branched などで、very branched より具体的。分子の branched-chain amino acids の branched-chain は「分岐鎖の」という一まとまりの前置修飾なのでハイフンを付ける。
類義語1

forked

頻度 4/10

定義二股などに分かれた形を持つ。

違い先端が分かれた形を強調し、複雑に多数の枝を持つ構造まで必ずしも含まない。

例The lizard has a forked tongue.

訳そのトカゲは、先が二つに分かれた舌を持つ。

反意語1

unbranched

頻度 3/10

定義枝分かれしていない。

違い分岐の有無という同じ構造軸での直接的な対立。

例The plant produces a single unbranched stem.

訳その植物は、枝分かれしない茎を1本伸ばす。

語義 13

【名詞・可算】処理の分岐、分岐先

頻度 5/10
コンピューター、プログラミング。

プログラムの実行が、通常の順序から別の命令や処理経路へ移ること、または条件によって選ばれる経路・処理部分。ソフトウェア開発の履歴を分ける語義14とは異なる。

文法パターン1
  • a conditional branch＝条件付き分岐。an unconditional branch＝無条件分岐。a branch of 〈処理・条件文〉＝その一方の処理経路。a branch instruction＝分岐命令。
コロケーション・構文例3

a conditional branch

用途条件に応じて実行先を変える。

例A conditional branch sends execution to the error handler when the check fails.

訳確認に失敗すると、条件付き分岐によって実行がエラー処理へ移る。

an unconditional branch

用途条件判定を伴わない実行先の変更。

例An unconditional branch transfers control to the specified instruction.

訳無条件分岐は、指定された命令へ制御を移す。

a branch of 〈条件文〉

用途選ばれる処理部分。

例Only one branch of this if statement is executed on each pass.

訳この if 文では、通過するたびに一方の分岐だけが実行される。

語法・注意1
  • 条件を満たしたときだけの移動が conditional branch で、branch が常に条件付きとは限らない。ある説明では実行先の変更、別の説明では選択される処理部分に重点が置かれる。branch instruction は分岐を行う命令。Git などの開発ブランチはコードをどう開発するかの系統であり、実行時の分岐と混同しない。
類義語1

jump

頻度 4/10

定義プログラムの制御を別の命令位置へ移すこと。

違い実行先への移動を強調する。branch は分かれた処理経路そのものも表す。用語の使い分けは命令体系による。

例The jump skips the remaining instructions in the block.

訳そのジャンプは、ブロック内の残りの命令を飛ばす。

語義 14

【名詞・可算】開発ブランチ

頻度 5/10
ソフトウェア開発、バージョン管理。

バージョン管理で、他の開発の流れと分けて変更を進められる一つの開発系列。機能追加や修正を分離して進め、後で統合するためなどに使う。

文法パターン1
  • create a branch＝開発ブランチを作る。work on a branch＝その系列上で変更する。merge a branch into 〈別のブランチ〉＝そこへ統合する。switch to a branch＝作業対象のブランチを切り替える。
コロケーション・構文例4

create a branch

用途独立した変更作業を始める。

例Create a branch before making changes to the payment feature.

訳支払い機能を変更する前に、ブランチを作成してください。

work on a branch

用途変更作業の系列を分ける。

例The team is working on a separate branch for the redesign.

訳そのチームは、再設計用の別ブランチで作業している。

merge a branch into 〈別のブランチ〉

用途開発の流れを統合する。

例We merged the feature branch into the main branch after testing.

訳テスト後、機能開発用ブランチをメインブランチへ統合した。

switch to a branch

用途作業の対象系列を変える。

例Switch to the release branch before applying the fix.

訳修正を適用する前に、リリース用ブランチへ切り替えてください。

語法・注意1
  • branch は一般に「開発の流れ」を指す。Git では、その先端のコミットを指す参照が進むことで開発の流れを追跡するので、単にすべてのファイルを複製したフォルダーという意味ではない。実行時に選ばれる処理部分（語義13）とは別。新たな機能の作業だけでなく、リリースの維持や修正にも使う。main、master などは実際に付けられたブランチ名であり、branch の意味自体に固定されているわけではない。
語義 15

【動詞・自動詞】処理が分岐する

頻度 4/10
コンピューター、プログラミング。

プログラムや実行の流れが、別の命令位置・処理経路へ移る。条件に応じて経路を選ぶ場合にも、無条件で別の位置へ進む場合にも使う。

文法パターン2
  • program/execution + branch to 〈処理・命令位置〉＝そこへ処理が移る
  • branch on 〈条件・値〉＝その条件や値に基づいて分岐する。to/on の後は前置詞の目的語で、branch の直接目的語ではない。
コロケーション・構文例2

branch to 〈処理・命令位置〉

用途実行先の変更。

例The program branches to an error handler if the file cannot be opened.

訳ファイルを開けない場合、プログラムはエラー処理へ分岐する。

branch on 〈条件・値〉

用途分岐の判断基準。

例The routine branches on the value returned by the validation function.

訳そのルーチンは、検証関数が返す値に基づいて分岐する。

語法・注意1
  • ここでは自動詞で、branch the error handler とはしない。実行先は to、判断基準は on で示す。語義13の名詞を使った a branch to the error handler と、動詞の The program branches to the error handler の構造を区別する。新しい開発系列を作る動詞用法は語義16・17。実行時の分岐とは、動作の主体・目的・結果が異なる。
類義語1

jump

頻度 4/10

定義プログラムの実行が別の命令位置へ移る。

違い移動先への飛び越しに焦点を置く。branch との厳密な区別は言語や命令体系に依存する。

例Execution jumps to the beginning of the loop.

訳実行は、ループの先頭へ移る。

語義 16

【動詞・自動詞・branch off を含む】開発の流れを分ける、新しいブランチを作る

頻度 3/10
ソフトウェア開発、バージョン管理。

ソフトウェアのバージョン管理で、ある開発系列や記録時点を起点に、変更作業を別の系列で進める。実行中のプログラムが条件に応じて処理先を変えることではない。

文法パターン2
  • developer/team + branch off 〈元のブランチ・コミット〉＝そこを起点に開発系列を分ける
  • developer/team + branch from 〈起点〉＝その時点・系列から分ける。off/from の後は起点で、作られる新ブランチの名前ではない。
コロケーション・構文例2

branch off 〈元のブランチ〉

用途既存の開発系列を起点に別の作業を始める。

例We branched off the release branch to develop the fix separately.

訳修正を別に進めるため、リリース用ブランチから新しい開発ブランチを作った。

branch from 〈起点〉

用途開発を分けた起点を示す。

例The team branched from the last stable commit before testing the new feature.

訳チームは、新機能を試す前に、最後の安定したコミットを起点として開発ブランチを作った。

語法・注意1
  • branch off the release branch では off が元の開発系列を導く。branch from ... でも起点を示せる。新しく作るブランチを直接目的語に置く branch a new branch は他動詞用法（語義17）。同じ off があっても、人が実際に脇道へ進む語義9とは活動領域が違う。ここで作るのはコードの開発系列であり、プログラム実行時の分岐先（語義15）ではない。
語義 17

【動詞・他動詞】開発ブランチを作成する

頻度 3/10
ソフトウェア開発、バージョン管理。

バージョン管理で、新しい開発系列を作る。直接目的語には作成するブランチなどを置き、起点の系列は from ... で示せる。

文法パターン3
  • branch a new branch＝新しい開発ブランチを作る
  • branch a new branch from 〈既存のブランチ・コミット〉＝そこから新しい系列を作る
  • a branch + be branched from 〈起点〉＝その起点から作成される。
コロケーション・構文例2

branch a new branch from 〈既存のブランチ〉

用途作成する系列と起点を明示する。

例The developer branched a new topic branch from the release branch.

訳開発者は、リリース用ブランチから新しい作業用ブランチを作成した。

be branched from 〈起点〉

用途作られた系列を主語にする。

例This maintenance branch was branched from the last stable release.

訳この保守用ブランチは、最後の安定版リリースを起点に作成された。

語法・注意1
  • branch a branch のように動詞と名詞が続くことがある。繰り返しを避けて create a branch とする言い方も一般的。branch off the release branch（語義16）では off の後が起点、branch a new branch from the release branch では直接目的語が新たに作る系列である。目的語の種類を区別し、実行時に処理先を切り替える動詞（語義15）と混ぜない。
語義 18

【動詞・他動詞】～を枝分かれさせる、分割する

頻度 3/10
構造・設計の説明、やや専門的。

管・経路などを、複数の枝や下位の部分に分ける。一般の自動詞用法より少なく、構造を組み立てる技術的な説明などに見られる。

文法パターン2
  • branch something into 〈複数の部分〉＝対象をいくつかに枝分かれさせる
  • something + be branched into 〈複数の部分〉＝そのように分けられる。直接目的語は分割する対象。
コロケーション・構文例2

branch something into 〈複数の部分〉

用途管路を複数の系統に分ける。

例The installer branched the supply pipe into two smaller lines.

訳施工担当者は、供給管を2本の細い管路に分けた。

be branched into 〈複数の部分〉

用途分けられた対象を主語にする受動態。

例The main duct is branched into three smaller ducts above the ceiling.

訳主ダクトは、天井の上で3本の細いダクトに分けられている。

語法・注意1
  • The pipe branches into two lines（語義7）は管が分かれる自動詞、The installer branches the pipe into two lines は施工者が管を分ける他動詞。代名詞なら branch it into ... と直接置く。日常の一般的な分割には divide や split がより広く使われる。be branched into ... は分割の受動・結果を述べ、a branched pipe は枝分かれした構造を述べる形容詞用法（語義12）。
類義語2

divide

頻度 9/10

定義全体をいくつかの部分に分ける。

違い枝状にすることを含まず、面積・集団・量の分割にも広く使う。

例The planner divided the site into four sections.

訳計画担当者は、敷地を四つの区画に分けた。

split

頻度 8/10

定義一つのものを二つ以上の部分へ分ける。

違い分かれる境目や分離に重点があり、枝としてつながった構造を保つとは限らない。

例The device splits the signal into two channels.

訳その装置は、信号を二つのチャンネルに分ける。

語義 19

【名詞・可算】曲線の枝

頻度 2/10
数学、曲線の説明。

数学で、一つの曲線のうち、切れ目や特別な点などによって他の部分と区別される部分。双曲線の離れた二つの部分などを指す。

文法パターン1
  • a branch of 〈曲線〉＝その曲線の枝。the two branches of a hyperbola＝双曲線の二つの枝。
コロケーション・構文例1

the two branches of a hyperbola

用途分かれた曲線部分を数える。

例The diagram shows the two branches of a hyperbola.

訳その図は、双曲線の二つの枝を示している。

語法・注意1
  • 「枝」は曲線の区別される部分という用語で、物理的な枝が幹につながっている必要はない。学問の一分野を表す a branch of mathematics（語義4）とは、同じ branch of ... でも意味が異なる。
