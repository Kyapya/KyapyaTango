主要語義 1更新 2026-10-18

発音記号

米: /ˈspes.ə.faɪ/｜英: /ˈspes.ɪ.faɪ/

  • 3音節で第1音節に強勢。示した米英形は第2音節が /ə/ と /ɪ/ で異なる。specifies、specified は y を i に替えるが、specifying は y を保つ。specified の語尾は /faɪd/。

語源

  • 古フランス語 specifier、後期ラテン語 specificare「具体的に示す」にさかのぼる。specific「特定の」と同じ系列で、さらに species「形、種類」に関連する。specific、species、special が同じ語源系列。「どのもの・どの条件かを特定できるようにする」が現在義の手掛かり。

語形成

specification名詞「仕様、仕様書、明細」。製品などの要求条件は複数形 specifications も多く、口語の略は specs。
specific形容詞「具体的な、特定の」。a specific date は具体的な日付、a specified date は指定済みの日付。
specifically副詞「具体的に、特に、明確に」。specify の動作を表す動詞の代用にはならない。
specified過去形・過去分詞。「明示された、指定された」という受動的意味で名詞の前後に置ける。
unspecified形容詞「明示されていない、特定されていない」。an unspecified amount のように使う。

語義 1

【動詞・他動詞】明示する、具体的に指定する

頻度 8/10
中立～やや硬い。申込書、契約、業務連絡、技術仕様で特に有用。

対象、数値、条件、手順などを、何を指すかがはっきり分かるように述べる。人の発言にも、契約・仕様書などに書かれている内容にも使う。単に詳しく説明するだけでなく、日付を一つ示すような短い指定にも使える。仕様に材料を指定する用法もこの意味に含まれる。

文法パターン7
  • specify 〈日時・条件・対象〉＝内容を明示する
  • specify that 〈節〉＝～と明記する
  • specify 〈疑問詞節〉＝何を・誰が・どのように～するかを明示する
  • specify 〈疑問詞〉 + to do＝何を・どうするべきかを指定する
  • specify 〈材料〉 for 〈用途〉＝その用途に使う材料を指定する
  • be specified in 〈文書〉＝文書に明記されている
  • unless otherwise specified＝別段の指定がない限り。文脈から内容が分かる He didn't specify. のような目的語省略もある。
コロケーション・構文例7

specify a delivery date

用途注文時に希望日や必要日を明確にする。

例Please specify a delivery date when you place the order.

訳注文の際に配達日を指定してください。

specify that 〈節〉

用途契約や説明書に明記された条件を述べる。

例The contract specifies that payment is due within thirty days.

訳契約には、30日以内に支払うことが明記されている。

specify 〈疑問詞節〉

用途担当者や方法について、どの点が明記されているかを示す。

例The procedure specifies who must approve each expense.

訳その手順書には、各経費を誰が承認しなければならないかが明記されている。

specify how to do something

用途操作方法の指定の有無を述べる。

例The manual does not specify how to reset the password.

訳マニュアルには、パスワードを再設定する方法が明示されていない。

specify 〈材料〉 for 〈用途〉

用途設計で使用材料を定める。

例The architect specified stainless steel for the handrails.

訳建築家は手すりの材料にステンレス鋼を指定した。

be specified in 〈文書〉（specify の受動態）

用途要件がどの文書に定められているかを示す。

例The minimum dimensions are specified in the drawings.

訳最小寸法は図面に明記されている。

unless otherwise specified（specify の受動分詞を使う定型句）

用途個別の例外指定がない場合に適用される原則を示す。

例Unless otherwise specified, all prices include delivery.

訳別段の記載がない限り、価格にはすべて配送料が含まれる。

語法・注意1
  • 「サイズを明示する」は specify the size であり、specify about the size はこの他動詞構文の代わりにしない。「誰かに～するよう指示する」のつもりで specify someone to do とせず、specify that someone must do または instruct someone to do とする。specify how to install it の how to は疑問詞付き不定詞であり、単独の specify to install it とは異なる。specify when payment is due のような間接疑問では平叙文の語順を使い、specify when is payment due とはしない。specified は a specified period と the period specified in the agreement の両方で使えるが、「特定の」というだけの specific と常に交換できるわけではない。specify は「明示」、identify は「何であるかを突き止める・識別」が中心で、調査して特定する意味を自動的に含まない。
類義語5

state

頻度 9/10

定義内容を言葉で述べる、明記する。

違いspecify より広く、細部や選択肢を特定することに焦点を置かない。

例The notice states the reason for the closure.

訳その通知には閉鎖の理由が記されている。

stipulate

頻度 5/10

定義条件として明確に定める。

違い契約上の要求や条件を強く意識させる。specify は事実や寸法を示すだけでもよい。

例The agreement stipulates a minimum order quantity.

訳契約では最低発注数量が定められている。

designate

頻度 6/10

定義対象を特定の役割・用途のために指定する。

違い人や場所などに役割を与えることが中心。specify は内容を明確に述べる点が中心。

例We designated this room as a quiet workspace.

訳この部屋を静かに作業するための場所に指定した。

spell out

頻度 7/10

定義内容を省略せず分かりやすく説明する。

違い理解しやすいよう詳述することを強調する。specify は短い数値の指定にも使える。

例The email spells out the next steps.

訳そのメールには次に行うことが分かりやすく詳述されている。

define

頻度 8/10

定義意味、範囲、条件を明確に定める。

違い境界や概念そのものを定める点が中心。specify は対象・条件・数値などを具体的に明示する点に焦点があり、両者は重なる場合もある。

例The policy defines each team's responsibilities.

訳その方針は各チームの責任範囲を定めている。

該当する語義・用例がありません。
