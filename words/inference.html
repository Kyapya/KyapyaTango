inference

主要語義 3更新 2026-10-20

発音記号

米・英: /ˈɪn.fər.əns/

  • 上の代表形では3音節で、第1音節に強勢がある。動詞 infer は後ろに強勢があるが、inference は語頭側に移る。この表記の /r/ は後ろに母音が続く位置にあり、英でも発音される。速い発話などでは弱い部分が圧縮されることもある。

コアイメージ

中心は「与えられた情報から、直接そのまま示されていない結果を導くこと」。人の結論、結論を導く過程、学習済みモデルによる出力に対応する。ただし、AIの専門用法が、人間と同じような論理的思考をしていることを意味するわけではない。

  • 情報から導かれた結論 → 「推論による結論・推測」（語義1）
  • 情報から結論を導く過程 → 「推論・推定」（語義2）
  • モデルで入力から結果を導く処理 → 「学習済みモデルによる推論処理」（語義3）

語源

  • 中世ラテン語 inferentia、inferre「持ち込む・導き入れる」にさかのぼり、推論に関する意味につながる。in-「中へ」と ferre「運ぶ」の組合せで、この in- は否定ではない。同系の infer「推論する」のほか、ferre の系統には transfer「移す」と confer「授ける・協議する」がある。現代の推論が文字どおり何かを運ぶという意味ではない。

語形成

infer動詞。「証拠などから推論する」。infer 〈結論〉 from 〈証拠〉、infer that 〈内容〉の形を取る。
inferred／inferringinfer の過去形・過去分詞／現在分詞。これらは r を重ねるが、名詞 inference では r は一つ。
inferential形容詞。「推論による・推論に関する」。inferential statistics は「推測統計学」。
inferentially副詞。「推論によって・推論的に」。主に学術的な文脈で使う。

語義 1

【名詞・可算】推論による結論・推測

頻度 6/10
ややフォーマル。学術・読解・報道・ビジネス分析。頻度評点は学習上の目安で、コーパス実測値ではない。

直接明示されていないことについて、手がかり・証拠・前提から考えて導いた結論。根拠のない思いつきとは区別されるが、根拠が弱かったり推論の仕方が誤っていたりすれば、結論も誤りうる。inference と呼ぶだけで確実な事実になるわけではない。

文法パターン6
  • draw/make an inference＝推論して結論を出す
  • an inference from 〈証拠〉＝証拠から導いた結論
  • an inference about 〈対象〉＝対象についての推測
  • the inference that 〈節〉＝その節の内容という推論上の結論
  • a reasonable/unwarranted inference＝妥当な
  • 根拠不十分な推論上の結論。
コロケーション・構文例5

draw an inference from 〈証拠〉

用途どの証拠から結論を導くのかを示す。

例We cannot draw a reliable inference from such a small sample.

訳これほど小さな標本から、信頼できる結論を導くことはできない。

make an inference about 〈対象〉

用途何について推測するのかを示す。

例Readers make inferences about the character's motives from her actions.

訳読者は登場人物の行動を手がかりに、その動機を推測する。

the inference that 〈節〉

用途導かれた結論の内容を節で示す。

例The evidence supports the inference that the two incidents were connected.

訳証拠からは、二つの出来事が関連していたという結論が支持される。

a reasonable inference

用途根拠から見て無理のない結論だと評価する。

例Given the repeated delays, it was a reasonable inference that the project needed more staff.

訳遅延が繰り返されていたことを考えると、その計画には人員の追加が必要だという推測は妥当だった。

an unwarranted inference

用途根拠が足りない結論を批判する。

例Assuming that silence means agreement would be an unwarranted inference.

訳沈黙が同意を意味すると考えるのは、根拠のない推測だろう。

語法・注意1
  • 一つの結論は an inference、複数なら inferences。a inference ではない。from は根拠、about は対象、that 節は結論の内容を示す。the inference that the plan had failed の that は、失敗したという内容を導くもので、直前の名詞を主語・目的語として置き換える関係代名詞ではない。普通の作文では make/draw an inference とし、do an inference を基本形として覚えない。標準的な作文では、imply は話し手や事実が何かを暗に示す側、infer は受け手や分析者が結論を導く側、inference はその結論または過程である。Your message implies urgency. は「そのメッセージは緊急性を示唆する」、I infer urgency from your message. は「私はそのメッセージから緊急だと判断する」。interference「干渉・妨害」とは別語。
類義語3

conclusion

頻度 8/10

定義考察や検討の末に得た結論。

違い結論全般を広く表す。inference は、情報から直接明示されていないことを導いたという関係を前面に出す。

例The committee reached a different conclusion after reviewing the new evidence.

訳委員会は新たな証拠を検討した結果、別の結論に達した。

deduction

頻度 5/10

定義既知のことや前提から推論して得た結論。

違い日常語では広く推理の結果を指すこともあるが、論理学では演繹による結論に関わる。inference は演繹だけに限定されない。

例Her deduction was based on the location of the missing files.

訳彼女の推理は、なくなったファイルの保管場所を根拠としていた。

supposition

頻度 4/10

定義十分に確かめられていない推測・仮定。

違い根拠から導く手続より、そうではないかと考える内容に重点がある。inference も誤りうるが、証拠や前提とのつながりを示す。

例The report distinguishes verified facts from suppositions.

訳その報告書は、確認済みの事実と推測を区別している。

語義 2

【名詞・不可算】推論・推定

頻度 6/10
論理学・学術・読解・統計・分析。

証拠や前提から結論を導く過程・働き。日常的な推測、論理的な推論、標本データを用いた統計的推定などに使う。観察した内容をそのまま報告するのではなく、そこから別の情報や結論を得るという点が中心。

文法パターン5
  • by inference＝推論によって
  • a process of inference＝推論の過程
  • rules of inference＝推論規則
  • statistical inference＝統計的推論
  • inference from 〈情報〉 to 〈結論〉＝情報から結論への推論。
コロケーション・構文例4

by inference

用途直接の記述や観察ではなく、手がかりから知ることをいう。

例We know the approximate date only by inference from the materials used.

訳おおよその年代は、使われた材料から推測して分かるだけだ。

a process of inference

用途結論に至る考え方そのものを説明する。

例Understanding an unstated intention often involves a process of inference.

訳明言されていない意図を理解するには、しばしば推論の過程が必要になる。

rules of inference

用途論理において前提から結論を導く規則をいう。

例The course introduces basic rules of inference before asking students to construct proofs.

訳その授業では、証明を組み立てさせる前に、基本的な推論規則を紹介する。

statistical inference

用途標本データから母集団などについて結論を得る統計的な手続をいう。

例Statistical inference allows researchers to estimate population characteristics from sample data.

訳統計的推論によって、研究者は標本データから母集団の特性を推定できる。

語法・注意1
  • この用法は過程・活動なので、Inference requires assumptions. のように不可算として使う。一方、an inference は語義1の個別の結論を指すことが多い。inference 全体を「一般から個別への推論」だけ、または「個別から一般への推論」だけと定義しない。演繹・帰納などは推論の異なる形である。統計的推論でも、標本の偏りやモデルの前提によって結論の妥当性は変わり、必ず正しい母集団の値が得られるわけではない。observation「観察」は対照概念になりうるが、観察は推論の材料にもなるため、単純な反意語ではない。
類義語3

reasoning

頻度 7/10

定義理由や情報を結びつけて考えること・その筋道。

違い考える過程を広く表す。inference は前提・情報から結論を導く関係に焦点がある。

例The answer is correct, but the reasoning needs to be explained.

訳答えは正しいが、そこに至る考え方を説明する必要がある。

deduction

頻度 4/10

定義前提から、その前提が正しければ必然的に成立する結論を導く推論。

違い論理学での演繹という特定の型。inference はこの型に限らず、帰納的な推論なども含む。

例The proof proceeds by deduction from the stated assumptions.

訳その証明は、示された仮定からの演繹によって進む。

induction

頻度 4/10

定義個別の観察・事例から一般的な傾向や法則を導く推論。

違い事例から一般化する型の推論で、inference のすべてではない。結論は通常、前提だけから論理的に必然とはならない。

例Induction from a few observations can produce an unreliable generalization.

訳少数の観察からの帰納は、信頼性の低い一般化につながることがある。

語義 3

【名詞・通常不可算】学習済みモデルによる推論処理

頻度 5/10
機械学習・AI・計算機システム。分野内での使用頻度ではなく英語全体での学習目安。

機械学習・AIで、学習済みモデルに入力を与えて、予測・分類・生成結果などを得る処理。モデルを学習させる training と区別される用語。画像の分類にも文章の生成にも使い、人間のように筋道を立てて考える場合だけを指すわけではない。

文法パターン5
  • run/perform inference＝推論処理を行う
  • inference on 〈機器〉＝その機器上での推論
  • inference latency＝推論の遅延時間
  • inference costs＝推論にかかる費用
  • at inference time＝推論の実行時に。
コロケーション・構文例5

run inference

用途学習済みモデルを使って入力を処理することをいう。

例The application runs inference on images captured by the camera.

訳そのアプリは、カメラが撮影した画像に対して推論処理を行う。

inference on 〈機器〉

用途推論の実行場所となる機器を示す。

例Inference on the device allows the application to work without a network connection.

訳端末上で推論を行うため、そのアプリはネットワーク接続がなくても動作できる。

inference latency

用途モデルの実行に伴う応答の遅れを測定・評価する。

例The team reduced inference latency without changing the model's predictions on the test set.

訳チームは、テストデータに対するモデルの予測結果を変えずに推論の遅延時間を短縮した。

inference costs

用途推論処理に必要な計算資源などの費用をいう。

例Inference costs rose as more users began generating long responses.

訳長い回答を生成する利用者が増えるにつれて、推論にかかる費用が上昇した。

at inference time

用途学習時ではなくモデルを実際に使う時点を示す。

例At inference time, the system combines the user's input with retrieved documents.

訳推論の実行時に、システムは利用者の入力と検索で取得した文書を組み合わせる。

語法・注意2
  • 通常は run inference のように不可算で使うが、処理回数を数える技術文脈では an inference、inferences と表す場合もある。inference request などでは名詞が別の名詞を修飾している。training は学習によってモデルのパラメータ等を調整する側、inference はモデルを利用して出力を得る側という区別が基本。ただし、実システムには状態の更新や適応を組み合わせたものもあり、「推論時には何も一切更新されない」と一般化しない。
  • ここでの inference は専門的な処理名なので、処理結果の正しさや、人間と同じ理解・論理的思考を保証しない。training は対になる工程であって、論理的な反意語ではない。
