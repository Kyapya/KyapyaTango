ENGLISH–JAPANESE EXTRA

install

主要語義 6更新 2026-10-12

発音記号

米: /ɪnˈstɑːl/｜英: /ɪnˈstɔːl/。2音節で第2音節に主強勢がある。示した米英差は第2音節の母音 /ɑː/ と /ɔː/。米語には /ɔː/ を使う発音もある。名詞でも動詞と同じ位置に強勢を置く発音があるため、「名詞なら前に強勢」と機械的に変えない。installed の -ed は /d/。

コアイメージ

共通するのは、対象を所定の場所・環境・役割に据え、そこで使える、役割を果たせる、または落ち着いて過ごせる状態にすること。自動詞では対象側の導入、名詞ではその作業を指す。

  • 機器を使用する位置への据え付け → 「設置する・取り付ける」（語義1）
  • ソフトを使用する環境への据え付け → 「インストールする」（語義2）
  • ソフトが使用する環境に据わる過程 → 「インストールされる」（語義3）
  • 導入作業としての環境への据え付け → 「インストール・導入作業」（語義4）
  • 人物を任務を果たす地位への据え付け → 「就任させる・役職に就ける」（語義5）
  • 人物を落ち着いて過ごす場所への据え付け → 「落ち着かせる・腰を据える」（語義6）

語源

  • 中世ラテン語 installare にさかのぼり、in-「中へ」と stallum「席・場所」から成る。アングロフランス語 enstaller・installer を経た系統があり、初期には正式な席・地位に就けることを表した。stallum はゲルマン系の語に由来し、英語の stall「区画・売店・聖職者席」と同根。installation「設置・就任」も同じ中世ラテン語の語族に属する。

語形成

installed過去形・過去分詞。「設置済みの・就任した」のように名詞を修飾するが、意味は対応する動詞から理解できる。
installing現在分詞・動名詞。l は2つのまま -ing を付ける。
installation設置・ソフトの導入・施設・就任・空間を用いた美術作品などを表す名詞。
installer設置作業者、またはソフトを導入するプログラム。可算名詞。
reinstall再び設置する・再インストールする他動詞。re-install とも書く。
uninstallソフトウェアを削除してインストールを解除する動詞。一般の設備の撤去には通常 remove を用いる。
preinstall出荷などより前にあらかじめソフトを導入する他動詞。pre-install とも書く。

語義 1

【動詞・他動詞】設置する・取り付ける

頻度 8/10
一般・建設・設備・業務。

設備・機器・備品などを所定の場所に置き、固定・接続などをして使える状態にする。実際に使用を始めることや動作試験の完了までを、常に意味するわけではない。

文法パターン5
  • install 〈機器・設備〉＝機器・設備を設置する
  • install 〈設備〉 in 〈場所〉＝場所の中に設備を設置する
  • install 〈設備〉 on 〈面・構造物〉＝面・構造物に設備を取り付ける
  • have something installed＝物を取り付けてもらう
  • be installed＝設置される・設置済みである
コロケーション・構文例5

install new equipment

用途新しい機器を使えるように据え付ける。

例The contractor will install new equipment next week.

訳その請負業者は来週、新しい機器を設置する予定だ。

install something in 〈場所〉

用途室内などに設備を置く。

例They installed a ventilation system in the workshop.

訳彼らは作業場に換気システムを設置した。

install something on 〈面・構造物〉

用途面に取り付ける関係を示す。

例The crew installed solar panels on the roof.

訳作業員たちは屋根に太陽光パネルを取り付けた。

have something installed

用途自分で作業せず、取り付けてもらう。

例We had a new lock installed yesterday.

訳私たちは昨日、新しい錠を取り付けてもらった。

be properly installed

用途適切に取り付けられた状態を示す。

例The heater must be properly installed before use.

訳その暖房器具は使用前に適切に設置されていなければならない。

語法・注意1
  • install a machine は「機械を設置する」で、機械を組み立てる assemble、操作する operate、始動させる start と同じではない。目的語を取るため、「技師が機器を設置した」は The technician installed the equipment.。受動態の be installed は設置の出来事にも設置済みの状態にも使える。英国では instal という綴りもあるが、install が一般的で、どちらの綴りでも installed・installing は l が2つ。
類義語3

fit

頻度 7/10

定義部品・設備を所定の場所に取り付ける。

違い特に英国英語でよく使い、サイズを合わせて取り付ける対象にも自然。

例A technician fitted a new valve to the pipe.

訳技師がその管に新しい弁を取り付けた。

set up

頻度 8/10

定義機器・設備を使えるように準備する。

違い固定工事を伴わない準備や接続にも広く使える句動詞。

例Please set up the projector before the meeting.

訳会議の前にプロジェクターを準備してください。

mount

頻度 6/10

定義機器・物を台や壁などに固定する。

違い支える面や構造物への固定に焦点があり、接続・使用準備全体を含むとは限らない。

例The camera is mounted on the wall.

訳そのカメラは壁に取り付けられている。

反意語1

remove

頻度 9/10

定義取り付けた物を取り外す・撤去する。

違い設置位置に置くことに対する方向上の反対。物を破壊することは含意しない。

例They removed the old air conditioner.

訳彼らは古いエアコンを取り外した。

語義 2

【動詞・他動詞】インストールする

頻度 8/10
コンピューター・一般。

ソフトウェア・アプリ・更新プログラムなどをコンピューターや端末に導入し、利用できるようにする。ファイルを受信する download と同一ではなく、ダウンロード後に別の導入処理が必要なこともある。

文法パターン4
  • install 〈ソフトウェア〉＝ソフトウェアを導入する
  • install 〈アプリ〉 on 〈端末〉＝端末にアプリを導入する
  • install something from 〈媒体・入手元〉＝その媒体・入手元から導入する
  • be installed on 〈端末〉＝端末にインストールされている
コロケーション・構文例4

install an app on 〈端末〉

用途端末を on で示す。

例She installed the app on her tablet.

訳彼女はそのアプリを自分のタブレットにインストールした。

install the latest version

用途新しい版を導入する。

例Please install the latest version of the software.

訳そのソフトウェアの最新版をインストールしてください。

install something from 〈媒体〉

用途導入元の媒体を示す。

例The technician installed the driver from a USB drive.

訳技師はUSBドライブからそのドライバーをインストールした。

be installed on 〈端末〉

用途導入済みの状態を述べる。

例The software is already installed on all company laptops.

訳そのソフトウェアは会社のすべてのノートパソコンにすでにインストールされている。

語法・注意1
  • install the app on your phone が基本で、端末そのものを目的語にして install your phone とすると「電話を設置する」という別の意味になり得る。installed software の installed は導入済みを示す過去分詞。download は入手、install は導入、update は更新で、それぞれ行為の焦点が異なる。語義3ではソフトを主語にして自動詞でも使う。
類義語2

set up

頻度 8/10

定義ソフトやシステムを使用できるように準備する。

違いインストールだけでなく、利用者情報や設定を整えることも含み得る。

例The administrator set up the accounting software for the team.

訳管理者はチームが使えるように会計ソフトを設定した。

load

頻度 6/10

定義プログラムを機器やメモリーに読み込む。

違い導入の意味と重なる場合があるが、実行時にメモリーへ読み込むことも表す。

例The technician loaded the control software onto the device.

訳技師はその機器に制御ソフトを読み込んだ。

反意語1

uninstall

頻度 7/10

定義インストールしたソフトを削除する。

違い導入に対する方向上の反対。利用者が作ったファイルや全設定まで必ず消えるとは限らない。

例I uninstalled the app from my phone.

訳私は携帯電話からそのアプリをアンインストールした。

語義 3

【動詞・自動詞】インストールされる

頻度 6/10
コンピューター。動作説明やトラブルの報告。

ソフトウェアや更新プログラムを主語にして、その導入処理が行われることを表す。表面上は能動形だが、ソフトが自ら意思を持って作業するという意味ではない。

文法パターン3
  • 〈ソフトウェア〉 + install automatically＝ソフトウェアが自動的に導入される
  • 〈ソフトウェア〉 + install on 〈端末・システム〉＝ソフトウェアがその環境に導入される
  • 〈ソフトウェア〉 + fail to install＝ソフトウェアの導入が失敗する
コロケーション・構文例3

〈更新プログラム〉 + install automatically

用途自動導入の挙動を述べる。

例The update installs automatically when you restart the computer.

訳コンピューターを再起動すると、その更新プログラムは自動的にインストールされる。

〈ソフトウェア〉 + install on 〈システム〉

用途導入先との適合を述べる。

例The program will not install on this older system.

訳そのプログラムは、この古いシステムにはインストールできない。

〈更新プログラム〉 + fail to install

用途導入処理の失敗を報告する。

例The update failed to install because there was not enough disk space.

訳ディスク容量が足りなかったため、その更新プログラムのインストールは失敗した。

語法・注意1
  • The app installs automatically. は自動詞、The app is installed automatically. は語義2の他動詞の受動態で、どちらも自然。一般の物や人について何でもこの自動詞にできるわけではない。人が職に就く場合は She was installed as president. とし、She installed as president. とは通常いわない。
語義 4

【名詞・可算】インストール・導入作業

頻度 5/10
IT・ややくだけた技術的なやり取り。一般的な説明文では installation が無難。

ソフトウェアを導入する一回の作業。IT分野では installation の短い言い方として使い、a clean install のような定着表現がある。

文法パターン4
  • an install of 〈ソフトウェア〉＝ソフトウェアの一回の導入
  • a clean install＝既存の導入状態を引き継がず行う新規導入
  • a fresh install＝新たに行うインストール
  • a failed install＝失敗したインストール
コロケーション・構文例4

a clean install

用途以前の導入環境を引き継がない導入を指す。

例The technician recommended a clean install of the operating system.

訳技師は基本ソフトをクリーンインストールすることを勧めた。

a fresh install

用途新たな導入作業を示す。

例A fresh install took less than ten minutes.

訳新規インストールには10分もかからなかった。

a failed install

用途導入が成功しなかったことを指す。

例We checked the log after the failed install.

訳インストールが失敗した後、私たちはログを確認した。

an install of 〈ソフトウェア〉

用途導入対象を of で示す。

例An install of the full package requires more disk space.

訳完全版パッケージのインストールには、より多くのディスク容量が必要だ。

語法・注意1
  • 動詞だけでなく名詞として a・the を伴い、複数は installs。a clean install は単なる「きれいな設置」ではない。具体的に何が削除・保持されるかは対象ソフトや手順によって異なり、この語だけでデータ保全を保証しない。住宅設備の取り付けなどを一般に名詞で述べるときは installation を使う。
類義語1

installation

頻度 8/10

定義ソフトウェアを導入する作業。

違いinstall より中立的で、説明書や一般向けの案内にも広く使える。

例The installation was completed successfully.

訳インストールは正常に完了した。

語義 5

【動詞・他動詞】就任させる・役職に就ける

頻度 5/10
正式な役職・政治・宗教・組織の人事。

人を重要な役職・権限のある地位に据える。正式な就任式を伴う場合もあるが、式典を行うことがすべての用例の必須条件ではない。文脈によっては、権力を持つ側がその人物を据えるという含みが出る。

文法パターン4
  • install someone as 〈役職名〉＝人をその役職に就ける
  • install someone in office＝人を公職・地位に就ける
  • be installed as 〈役職名〉＝その役職に就任する
  • a newly installed 〈役職者〉＝新しく就任した役職者
コロケーション・構文例4

install someone as president

用途正式な役職へ人を据える。

例The association installed Dr. Lee as president at its annual meeting.

訳その協会は年次総会でリー博士を会長に就任させた。

be installed as chair

用途就任する人物を主語にする。

例She was installed as chair of the board in April.

訳彼女は4月に理事会の議長に就任した。

install someone in office

用途公的な地位に就ける行為を述べる。

例The ceremony formally installed the new governor in office.

訳その式典によって、新しい知事は正式に就任した。

a newly installed 〈役職者〉

用途名詞前の過去分詞表現を示す。

例The newly installed director announced a review of the budget.

訳新たに就任した理事は予算の見直しを発表した。

語法・注意1
  • as president のように、役職名を補語として用いる場合は無冠詞がよく使われる。install someone as the new president のように特定する言い方もある。install は地位に据える局面を表し、選挙で選ぶ elect、採用する hire、候補を指名する nominate のいずれとも同義ではない。be installed は受動態で、再帰代名詞の省略形ではない。
類義語3

appoint

頻度 8/10

定義人を役職に任命する。

違い任命という決定を表す一般的な語で、就任式や実際に地位へ据える局面を必ずしも強調しない。

例The board appointed her as chief executive.

訳取締役会は彼女を最高経営責任者に任命した。

induct

頻度 5/10

定義正式な手続きを経て役職や組織に迎え入れる。

違いinduct someone into office などといい、正式な導入手続きに焦点がある。

例The new members were inducted into the association.

訳新しい会員たちは正式に協会に迎え入れられた。

inaugurate

頻度 5/10

定義正式に役職に就任させる。

違い特に高位の公職への就任を式典と結びつけて述べやすい。

例The president was inaugurated in January.

訳大統領は1月に就任した。

反意語2

depose

頻度 4/10

定義統治者などを地位から退かせる。

違い地位へ据えることに対する方向上の反対で、特に権力者の強制的な退位を表す。

例The ruler was deposed after the revolt.

訳その支配者は反乱の後に退位させられた。

dismiss

頻度 7/10

定義人を職務・地位から解任する。

違い職に就けることへの方向上の反対。従業員や役職者に広く使い、統治者に限らない。

例The board dismissed the director.

訳理事会はその理事を解任した。

語義 6

【動詞・他動詞、再帰用法を含む】落ち着かせる・腰を据える

頻度 4/10
やや文語的・描写的。会話ではユーモラスに使うこともある。

人を特定の部屋・席などに落ち着かせる。自分自身を目的語にする install oneself では、その場所に陣取る・腰を据えることを表す。ある程度落ち着いて過ごす含みがあり、単に一瞬座ることとは違う。

文法パターン4
  • install someone in 〈部屋・席〉＝人を部屋・席に落ち着かせる
  • install oneself in 〈部屋・席〉＝自分が部屋・席に腰を据える
  • install oneself at 〈机など〉＝自分が机などに陣取る
  • be installed in 〈場所〉＝その場所に落ち着いている
コロケーション・構文例4

install someone in 〈部屋〉

用途客などが落ち着ける場所を用意する。

例We installed our guests in the upstairs bedroom.

訳私たちは客たちを上階の寝室に落ち着かせた。

install oneself in 〈席〉

用途自分が席に腰を落ち着ける。

例He installed himself in the armchair with a newspaper.

訳彼は新聞を手に、肘掛け椅子に腰を据えた。

install oneself at 〈机など〉

用途机などに陣取って過ごす。

例She installed herself at the kitchen table to finish the report.

訳彼女は報告書を仕上げるため、台所のテーブルに腰を据えた。

be comfortably installed in 〈場所〉

用途落ち着いている状態を表す。

例By evening, the visitors were comfortably installed in their rooms.

訳夕方までには、訪問客たちはそれぞれの部屋でくつろいでいた。

語法・注意1
  • 能動形で「自分が腰を据える」なら install myself・install herself のように主語に一致する再帰代名詞が必要。She installed herself at the desk. と、She was installed at the desk. という受動・結果状態の形は別の構造。oneself の位置は動詞の直後で、install in the chair oneself とはしない。会社・習慣が「定着する」という意味に無制限に広げない。
類義語2

settle

頻度 8/10

定義人を落ち着かせる、または自分が落ち着く。

違い中立的で日常的。settle the guests in their rooms や settle into a chair のように構文が変わる。

例She settled into a comfortable chair.

訳彼女は座り心地のよい椅子に落ち着いた。

ensconce

頻度 3/10

定義人を安全・快適な場所に落ち着かせる。

違いさらに文語的で、居心地よく陣取って動かないような描写に適する。

例He ensconced himself by the fire.

訳彼は暖炉のそばにゆったりと陣取った。

該当する語義・用例がありません。
