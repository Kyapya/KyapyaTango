発音記号

米: /kɔːr/｜英: /kɔː(r)/。1音節。英米差は第1音節末の /r/ で、米音では発音し、英音の括弧付き /r/ は後ろに母音が続く場合などの連結で現れる。名詞・形容詞・動詞で基本の発音は同じ。

  • 複数形・三人称単数現在形 cores は米: /kɔːrz/｜英: /kɔːz/、過去形・過去分詞 cored は米: /kɔːrd/｜英: /kɔːd/。どちらも1音節で、英米差は第1音節の母音に続く /r/ の有無である。coring は米・英: /ˈkɔːrɪŋ/。2音節で第1音節に主強勢があり、母音が続くため英音にも /r/ が現れる。corps の単数形とは同音になるが、corpse は語末に /s/ があり別の語である。

コアイメージ

外側や周辺に対して、内部を構成する部分や機能上の中核。物体の芯だけでなく、活動を支える主要部分を指し、専門用法では何の内部・中核として扱うかによって対象が定まる。

  • 物事の中心を成す本質的な内容 → 「核心、本質、最も重要な部分」（語義1）
  • 物体の中心を成す内部の部分 → 「物の中心部、内部の核」（語義2）
  • 果実の中心を成す種を含む部分 → 「果実の芯」（語義3）
  • 活動の中心を成す主要な部分 → 「主要な、中核の、基本となる」（語義4）
  • 胴体の中心を成す筋肉のまとまり → 「体幹の筋群、胴体中心部」（語義5）
  • 活動の中心を成す人のまとまり → 「中心を成す人々、中核集団」（語義6）
  • 果実の中心部分を取り除く動作 → 「果実の芯を取り除く」（語義7）
  • 対象の中心まで及ぶ深さや程度 → 「芯まで、心底、徹底的に：to the core」（語義8）
  • 命令処理の中心を成すCPU内の単位 → 「CPUの処理コア」（語義9）
  • 変動の大きい品目を除いて捉える物価の基調 → 「物価の基調を見るため一部の品目を除いた」（語義10）
  • 原子炉の中心を成す反応部分 → 「原子炉の炉心」（語義11）
  • 対象の内部を抜き出した試料 → 「内部から採った柱状の試料」（語義12）
  • 内部の試料となる部分を取り出す動作 → 「コア試料を採取する」（語義13）
  • 磁気回路の中心を成す材料・部材 → 「コイルなどの磁性体の芯、鉄心」（語義14）
  • 鋳型内部の形を作る部材 → 「鋳型の中子」（語義15）
  • 建物の設備や動線をまとめる中核部分 → 「建物の設備・縦動線をまとめたコア」（語義16）
  • ケーブル内部を構成する導体単位 → 「ケーブルの芯線・絶縁された導体」（語義17）
  • 剥片を採る元となる石の塊 → 「石器の材料となる石核」（語義18）
  • 磁気的な記憶を担う素子 → 「磁気コアメモリの記憶素子」（語義19）

語源

  • 中英語から使われているが、語の起源は確定していない。心臓を意味するラテン語 cor と形や意味が似ていることだけで、直接の由来と断定しない。果実の芯を取り除く動詞は、名詞 core を基にした用法である。

語形成

cores名詞の複数形、または動詞の三人称単数現在形。前後の構造で区別する。
cored動詞の過去形・過去分詞。a cored apple は、芯を取り除いたリンゴという受動的な関係を示す。
coring動詞の -ing 形。綴りは語末の e を落として作る。
corer芯やコアを取り出す道具・器具を表す名詞。果実の芯抜き器やコア試料の採取器具などを指し、core の比較級として作られた形ではない。

語義 1

【名詞：可算・通常単数】核心、本質、最も重要な部分

頻度 8/10
一般・議論・業務・評論。

問題・議論・考えなどを成り立たせる、中心的で重要な部分。周辺の事情や細部と区別して、何が本質なのかを述べる。

文法パターン5
  • the core of the problem
  • at the core of something
  • at its core
  • get to the core of something
  • form the core of something。
コロケーション・構文例5

the core of the problem

用途問題の本質的な部分を示す。

例The lack of reliable data is the core of the problem.

訳信頼できるデータがないことが、その問題の核心だ。

at the core of something

用途中心的な要因や理念の位置付けを示す。

例Trust is at the core of a lasting partnership.

訳長続きする協力関係の中心には、信頼がある。

at its core

用途対象を本質的に捉えて説明する。

例At its core, the dispute is about who has the authority to decide.

訳本質的には、その争いは誰に決定権があるのかという問題だ。

get to the core of something

用途周辺の話から重要な点へ到達することを述べる。

例Her question got to the core of the disagreement.

訳彼女の質問は、意見の相違の核心を突いた。

form the core of something

用途何が中心的内容を構成するかを述べる。

例These principles form the core of the training programme.

訳これらの原則が、その研修プログラムの中心を成している。

語法・注意1
  • at the core of は中心的位置、get to the core of は核心へ到達する動きで、前置詞は構文ごとに読む。core が必ず唯一の原因を意味するわけではなく、中心的な考え・内容・部分にも使える。

違い本質的な性質や特徴に焦点がある。core は問題の中心部分や、中心を成す要素のまとまりにも使う。

例Simplicity is the essence of this design.

訳簡潔さが、このデザインの本質だ。

語義 2

【名詞：可算】物の中心部、内部の核

頻度 7/10
一般・科学・構造の説明。

物体の内側にあり、周囲の部分に包まれた中心的な部分。必ず幾何学的に一点の中心を指すのではなく、内部の層・塊・構造を指すこともある。

文法パターン5
  • the core of something
  • at the core of something
  • a solid core
  • the Earth's core
  • an inner core。
コロケーション・構文例4

the core of something

用途何の内部中心かを示す。

例The core of the structure is surrounded by several protective layers.

訳その構造の中心部は、いくつもの保護層に囲まれている。

a solid core

用途内部の中心部が固体であることを述べる。

例The model contains a solid core inside a hollow shell.

訳その模型は、中空の外殻の内側に固体の芯を持つ。

the Earth's core

用途地球の中心部を指す。

例The diagram shows the Earth's core beneath the outer layers.

訳その図は、外側の層の下にある地球の核を示している。

an inner core

用途さらに内側の中心部を区別する。

例The sample has an inner core and a darker outer layer.

訳その試料には、内側の芯と、より暗い色の外層がある。

語法・注意1
  • the core of the Earth の of は全体と部分の関係を示す。中心という位置だけでなく、内側にまとまった部分を捉えるため、数学の点としての centre と必ず同じではない。天体の構造や組成の詳細は、core という語自体からは決まらない。

定義中心となる場所・点・部分。

違い米語では center。位置としての中心を広く表す。core は、外側に包まれた内部や、物事を支える中心的な塊を意識させやすい。

例Place the marker at the centre of the circle.

【名詞：可算】果実の芯

頻度 7/10
日常・調理。

リンゴ・ナシなどの中央にある、種を含む比較的硬い部分。果実全体の形や食べられる部分とは区別して呼ぶ。

文法パターン4
  • an apple core
  • a pear core
  • remove the core
  • cut out the core。
コロケーション・構文例4

an apple core

用途リンゴの中央部分を一つの物として述べる。

例She left an apple core on the plate.

訳彼女は、皿の上にリンゴの芯を残した。

a pear core

用途ナシの芯を述べる。

訳そのナシの芯には、濃い色の種がいくつか入っていた。

【形容詞】主要な、中核の、基本となる

頻度 8/10
一般・業務・教育。

組織・事業・教育・考え方などを成り立たせる、中心的で重要な部分に属する。周辺的・付随的なものに対し、外せない主要部分を示す。

  • core subjects
  • a core curriculum
  • core values
  • core members
  • be core to something。
コロケーション・構文例6

core business

用途企業の中心となる事業を述べる。

例The company decided to focus on its core business.

訳その会社は、中核事業に集中することを決めた。

core subjects

用途教育課程の基本となる科目を示す。

例Students take core subjects alongside a choice of electives.

訳学生は、選んだ選択科目に加えて、基本となる科目を履修する。

a core curriculum

用途共通の基本課程を述べる。

例The university introduced a core curriculum for first-year students.

訳その大学は、一年生向けの共通の基本課程を導入した。

core values

用途行動や組織を支える基本的価値観を述べる。

例Fairness and transparency are among the organization's core values.

訳公平性と透明性は、その組織の基本的価値観に含まれている。

core members

用途集団の中心となるメンバーを述べる。

例The core members meet weekly to coordinate the work.

訳中核メンバーは、作業を調整するため毎週集まる。

用途述語位置で、何にとって重要な中核かを示す。

例Clear communication is core to effective teamwork.

訳明確な意思疎通は、効果的なチームワークの中核となる。

語法・注意1
  • 名詞前の用法が多いが、be core to something のような述語用法もあるため、限定用法だけと断定しない。core と同じ形の名詞が名詞を修飾する分析と重なる場合もある。core curriculum の具体的な必修範囲は制度によって異なり、全ての学校で同じ内容を示すわけではない。比較級を機械的に corer と作らない。

語義 7

【動詞：他動詞、過去分詞修飾を含む】果実の芯を取り除く

頻度 5/10
調理・レシピ。

リンゴやナシなどから、種を含む中央の芯を取り除く。名詞 core が表す部分を除去する動作であり、芯を加えるという意味ではない。

文法パターン4
  • core an apple
  • peel and core something
  • a cored pear
  • be cored before cooking。
コロケーション・構文例4

core an apple

用途リンゴの芯を取り除く作業を述べる。

例Core the apple before cutting it into rings.

訳リンゴを輪切りにする前に、芯を取り除いてください。

peel and core something

用途皮むきと芯の除去を並べて述べる。

例She peeled and cored the pears for the dessert.

訳彼女は、デザート用にナシの皮をむき、芯を取り除いた。

a cored pear

用途芯を取った状態の果実を過去分詞で修飾する。

例Place each cored pear in the baking dish.

訳芯を取り除いたナシを、それぞれ焼き皿に入れてください。

be cored before cooking

用途調理前の下ごしらえを受動形で述べる。

例The apples are cored before they are cooked.

訳リンゴは、加熱調理の前に芯を取り除く。

語法・注意1
  • 規則活用で core–cored–cored、-ing 形は coring。a cored apple は過去分詞による修飾であり、この動詞が果実を直接目的語に取ることと整合する。remove the core from an apple と言い換えると、除去する部分と処理される果実の関係が見えやすい。

文法パターン4

  • be rotten to the core

コロケーション・構文例4

shake someone to the core

用途人を深く動揺させることを述べる。

例The sudden loss shook him to the core.

訳突然の喪失に、彼は心の底から動揺した。

a professional to the core

語法・注意1
  • the を含む to the core という形を使う。句全体は程度の深さを示し、必ず否定的とは限らない。a professional to the core のように肯定的な評価にも使える。at the core は中心にある位置、to the core は中心まで及ぶ範囲・程度という違いがある。

【名詞：可算】CPUの処理コア

頻度 6/10
コンピュータ・CPUの仕様。

CPU内で命令の実行を担う処理単位。複数のコアを持つCPUは、複数の処理を並行して進める構成を取れる。CPU全体や、ソフトウェア上のスレッドそのものと同一ではない。

文法パターン4
  • a processor core
  • multiple cores
  • a six-core processor
  • physical cores。
コロケーション・構文例4

a processor core

用途CPU内部の処理単位を指す。

例Each processor core can execute instructions.

訳各プロセッサコアは、命令を実行できる。

multiple cores

用途処理コアが複数ある構成を述べる。

例The software distributes the workload across multiple cores.

訳そのソフトウェアは、処理負荷を複数のコアに分配する。

a six-core processor

用途コア数を名詞前の複合修飾で示す。

例This computer has a six-core processor.

訳このコンピュータは、6コアのプロセッサを搭載している。

physical cores

用途論理的な処理単位の表示と物理コアを区別する。

例The specification lists six physical cores and twelve threads.

訳その仕様には、物理コア6個、スレッド12本と記載されている。

語法・注意1
  • six-core のように名詞の前でまとめて修飾すると、core を単数形にしハイフンでつなぐ。一方、six cores は複数形。thread や logical processor の数は物理コア数と必ず一致するわけではなく、全てのCPUで1コアが常に2スレッドという決まりもない。コア数だけで性能比率を断定しない。Intel Core のようなブランド名と、一般名詞の core も区別する。
語義 10

【形容詞・経済指標】物価の基調を見るため一部の品目を除いた

頻度 5/10
経済・物価統計・金融報道。

core CPI／core inflation などで、変動が大きい一部の品目を除いて物価の基調を捉える指標を示す。何を除くかは国や指標によって異なるため、core という名前だけで除外範囲を一律には決められない。

文法パターン4
  • core inflation
  • core CPI
  • US core CPI
  • Japan's core CPI。
コロケーション・構文例3

core inflation

用途一部の品目を除いて見た物価上昇を、総合の物価上昇と区別する。

例The report distinguishes core inflation from headline inflation.

訳その報告書は、コアインフレ率と総合のインフレ率を区別している。

US core CPI

用途米国で一般にコアCPIと呼ばれる系列の範囲を述べる。

例US core CPI excludes food and energy.

訳米国のコアCPIは、食品とエネルギーを除いている。

Japan's core CPI

用途日本で一般にコアCPIと呼ばれる系列を示す。

例Japan's core CPI excludes fresh food rather than all food and energy.

訳日本のコアCPIが除くのは、食品全般とエネルギーではなく、生鮮食品である。

語法・注意1
  • CPI は消費者物価指数、inflation は物価上昇を表し、指数の水準と上昇率は区別する。米国の一般的な core CPI と日本の一般的なコアCPIでは範囲が異なり、さらに core-core などの呼び方にも複数の除外範囲がある。総合指数から食品やエネルギーの価格が消えたという意味ではなく、除外品目が生活に重要でないという評価でもない。本文の例は用語の範囲の説明で、現在の指数値や投資判断を示すものではない。
語義 11

【名詞：可算】原子炉の炉心

頻度 4/10
原子力・技術・報道。

原子炉で核分裂反応が起こる中心的な部分。原子炉全体や発電所全体ではなく、炉内の機能上の中核を指す専門語。

文法パターン3
  • a reactor core
  • the core of a nuclear reactor
  • core temperature。
コロケーション・構文例2

a reactor core

用途原子炉の炉心を述べる。

例The diagram identifies the reactor core inside the vessel.

訳その図は、容器の内部にある炉心を示している。

core temperature

用途炉心という部位の温度を述べる。

例The reactor test report includes measurements of core temperature.

訳原子炉の試験報告書には、炉心温度の測定値が含まれている。

語法・注意1
  • この core は機能を持つ部分の名称であり、単に原子炉の幾何学的中心点という意味ではない。部品構成や運転の安全条件は別の技術事項で、この語の定義だけから操作方法を導かない。
語義 12

【名詞：可算】内部から採った柱状の試料

頻度 4/10
地質学・地球科学・調査。

岩石・堆積物・氷などの内部を調べるために採取した、柱状などの細長い試料。内部の層や構造を保持した試料として扱う。

文法パターン4
  • a sediment core
  • an ice core
  • a rock core
  • analyse a core sample。
コロケーション・構文例3

a sediment core

用途堆積物の層を調べる試料を述べる。

例The sediment core preserved layers from different periods.

訳その堆積物コアには、異なる時期の層が残されていた。

an ice core

用途氷の内部から採った試料を述べる。

例Researchers compared several ice cores collected from the region's ice sheet.

訳研究者たちは、その地域の氷床から採取した複数のコアを比較した。

analyse a core sample

用途採取した内部試料を分析対象として示す。

例The laboratory analysed the core sample to examine the sequence of layers.

訳研究室では、層の順序を調べるためコア試料を分析した。

語法・注意1
  • the core of the Earth は地球そのものの中心部、an ice core は採り出された試料で、同じ対象ではない。core sample は試料であることを明示した複合語であり、必ず元の物体の中心軸から採ったという意味ではない。
語義 13

【動詞：他動詞】コア試料を採取する

頻度 2/10
地質調査・科学的な試料採取。

地層や堆積物などから、内部を調べるためのコア試料を採取する。採取する対象の物質や採取地点を目的語にして述べる。果実の不要な芯を除去する用法と違い、取り出すコア自体を分析対象として扱う。

文法パターン3
  • core sediments
  • core a site
  • be cored at several locations。
コロケーション・構文例3

core sediments

用途堆積物からコア試料を採取することを述べる。

例The team cored the lake-bed sediments to study older layers.

訳チームは、古い層を調べるため、湖底の堆積物からコア試料を採取した。

core a site

用途試料採取を行った地点を目的語にする。

例Researchers cored the site near the centre of the lake.

訳研究者たちは、湖の中央近くの地点でコア試料を採取した。

be cored at several locations

用途物質を採取対象とする受動態で、複数の採取位置を述べる。

例The sediments were cored at several locations to compare the layers.

訳層を比較するため、複数の場所で堆積物からコア試料が採取された。

語法・注意1
  • core a site は地点という空間を丸ごと取り除く意味ではなく、その地点で採取するという表現。受動態の The site was cored. でも同じ関係を保つ。ここでは採取作業を述べる動詞として扱い、実際の掘削・採取の手順や安全条件は説明していない。
語義 14

【名詞：可算】コイルなどの磁性体の芯、鉄心

頻度 3/10
電気・電子工学。

コイルや変圧器などで磁気回路を構成する中心的な材料・部材。鉄に限らず、フェライトなどの磁性材料を用いるものもある。

文法パターン3
  • an iron core
  • a ferrite core
  • a transformer core。
コロケーション・構文例3

an iron core

用途鉄を使った磁性体の芯を述べる。

例The coil is wound around an iron core.

訳コイルは、鉄心のまわりに巻かれている。

a ferrite core

用途フェライト材料の芯を示す。

例The component uses a ferrite core rather than a solid iron rod.

訳その部品は、鉄の棒ではなくフェライトの芯を使っている。

a transformer core

用途変圧器の磁気回路を構成する部材を述べる。

例The engineer examined the transformer core for damage.

訳技術者は、変圧器の鉄心に損傷がないか調べた。

語法・注意1
  • core を常に鉄製と決めつけない。鉄心という日本語は典型的な場合の訳で、具体的な材料は修飾語や部品仕様で確認する。CPUの処理コアとも、果実の芯とも別の専門対象を指す。
語義 15

【名詞：可算】鋳型の中子

頻度 2/10
鋳造・製造業。

鋳造品の内部に空洞や穴を作るため、鋳型の内側に配置する形状部分。製品の内部形状を作る役割を持つ。

文法パターン3
  • a sand core
  • place a core in a mould
  • remove the core。
コロケーション・構文例2

a sand core

用途砂を材料とする中子を指す。

例The drawing shows a sand core for the hollow section of the casting.

訳その図面は、鋳物の中空部分を作る砂中子を示している。

place a core in a mould

用途鋳型と中子の位置関係を述べる。

例The diagram shows where the core is placed in the mould.

訳その図は、鋳型内のどこに中子を配置するかを示している。

語法・注意1
  • 英語の mould は米語では mold とも綴る。core は外形を作る鋳型全体の単なる別名ではなく、内側の形を作る部材として区別する。実際の製造工程や安全手順は、専門の仕様に基づく。
語義 16

【名詞：可算】建物の設備・縦動線をまとめたコア

頻度 3/10
建築。

建物で、階段・エレベーター・設備配管などを集めた中心的な区画や構造部分。建物の機能をまとめて支える区域として使う。

文法パターン3
  • a service core
  • a central core
  • the building's core。
コロケーション・構文例2

a service core

用途設備などをまとめた建物内の区画を述べる。

例The lifts and service shafts are grouped in a service core.

訳エレベーターと設備シャフトは、設備コアにまとめられている。

a central core

用途建物の中心部にあるコアを示す。

例Offices surround the central core containing the stairs and lifts.

訳階段とエレベーターを収めた中央のコアを囲むように、事務室が配置されている。

語法・注意1
  • 建築上の core は機能的な区画を表し、どの部位が含まれるかは設計によって異なる。建物内の全ての部屋を指す語でも、常に正確な幾何学的中央だけを指す語でもない。

a cable core

語義 18

【名詞：可算】石器の材料となる石核

頻度 2/10
考古学・石器研究。

石器を作る際に、石の剥片をはがし取る元となる石の塊。はがれた剥片そのものとは区別する。石核自体を道具として利用したかどうかは、別の観点である。

文法パターン3
  • a flint core
  • a stone core
  • flakes removed from a core。
コロケーション・構文例2

a flint core

用途フリントの石核を述べる。

例The archaeologist identified several scars on the flint core.

訳考古学者は、フリントの石核にいくつかの剥離痕を確認した。

flakes removed from a core

用途石核と剥片の関係を示す。

例The display shows flakes removed from a core during tool production.

訳展示には、道具の製作時に石核からはがされた剥片が示されている。

語法・注意1
  • この core は、物体の中心を測った位置という意味ではなく、剥片を取る元の石材という専門名称。石核と剥片の関係を区別して訳す。
語義 19

【名詞：可算】磁気コアメモリの記憶素子

頻度 2/10
コンピュータ史・記憶装置。

磁気コアメモリで情報を保持する、磁性材料の小さな輪などの素子。歴史的なコンピュータの記憶装置の文脈で使われる。現在のCPUの処理コアとは機能も対象も異なる。

文法パターン3
  • a magnetic core
  • magnetic cores
  • core memory。
コロケーション・構文例3

a magnetic core

用途記憶装置の一つの磁性素子を述べる。

例In this memory system, a magnetic core stores one bit.

訳この記憶装置では、一つの磁気コアが1ビットを保持する。

magnetic cores

用途記憶装置を構成する多数の素子を述べる。

例The museum's computer contains an array of small magnetic cores.

訳博物館のコンピュータには、小さな磁気コアを並べた部分がある。

core memory

用途その素子を用いた記憶装置の名称を述べる。

例The exhibit explains how core memory stored data in early computers.

訳展示では、初期のコンピュータでコアメモリがどのようにデータを保持したかを説明している。

語法・注意1
  • core memory と processor core は同じ core を含むが、前者は記憶、後者は命令処理の単位を表す。歴史的な用語を、現代の全てのメモリやCPUにそのまま当てはめない。
