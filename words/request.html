ENGLISH–JAPANESE EXTRA

request

主要語義 5更新 2026-10-13

発音記号

米・英: /rɪˈkwest/

  • 2音節で、第2音節 /kwest/ に強勢がある。名詞と動詞で強勢は変わらない。
  • 複数形・三人称単数現在形 requests は /rɪˈkwests/、過去形・過去分詞 requested は /rɪˈkwestɪd/。requested では語尾が1音節増える。

コアイメージ

共通核は「必要・希望するものを、相手に求めること」。求める行為、その伝達内容、求められた対象、求められている状態へと焦点が移る。

  • 相手に求める行為・内容 → 「依頼・要請・要求」（語義1）
  • 相手に求める働きかけ → 「依頼する・要請する・要求する」（語義2）
  • コンピューターに求める処理 → 「処理要求・リクエスト」（語義3）
  • 演奏者などに求めた曲 → 「リクエスト曲」（語義4）
  • 多くの相手から求められる状態 → 「需要がある・引っ張りだこである」（語義5）

語源

  • 中英語にフランス語系の名詞 requeste が入り、動詞としても使われるようになった。さらにさかのぼると、ラテン語 requirere「求める、尋ねる」の系統に属する。re- はここでは強意を表し、quaerere は「探し求める」の意。現代の request を「もう一度質問する」と分解して理解する語ではない。
  • inquire「尋ねる、調べる」と acquire「獲得する」も、さかのぼれば quaerere を共有する。request は必要なものを相手に求めること、inquire は情報を求めて尋ねること、acquire は実際に得ることを中心とし、同根でも現在の意味・文型は異なる。

語形成

requester / requestor（名詞）依頼者、要求元。人だけでなく、情報処理で要求を送る側にも使う。
requested（過去分詞）要求された、依頼された。the requested information「求められた情報」のように名詞を修飾するが、request の過去分詞であり、「必須の」とは限らない。

語義 1

【名詞・可算、定型句では無冠詞】依頼・要請・要求

頻度 9/10
一般・ビジネス・公的文書。会話でも使うが、動詞 ask を使った表現より改まって聞こえやすい。

何かを提供してもらう、行為をしてもらう、許可を得るなどのために相手へ求めること、またはその求めの内容。改まった、丁寧な求め方と結び付きやすいが、軽いお願いに限らず、組織からの要請にも使う。実現したこと、承認されたことまでは表さない。

文法パターン11
  • a request for something＝物・情報などを求める依頼
  • a request to do something＝何かをすることを求める依頼
  • a request that 〈主語〉 + 〈動詞の原形〉＝あることを実行するよう求める依頼
  • make a request＝依頼をする
  • grant a request＝依頼を認める
  • a request from someone＝人からの依頼
  • at someone's request＝その人に頼まれて
  • at the request of someone＝その人の依頼によって
  • on request＝求めがあれば、求めに応じて
  • upon request＝求めがあれば、求めに応じて
  • by popular request＝大勢からの要望により
コロケーション・構文例10

make a request for something

用途何を求めるかを for の後に示す。

例We made a request for additional training.

訳私たちは追加の研修を要望した。

a request to do something

用途申請者などが希望する行為を不定詞で示す。

例Her request to work remotely was approved.

訳彼女のリモート勤務の申請は承認された。

a request that 〈主語〉 + 〈動詞の原形〉

用途誰が何をするよう求められているかを節で明確にする。

例The letter included a request that all invoices be sent electronically.

訳その手紙には、すべての請求書を電子形式で送るようにとの依頼が含まれていた。

grant a request

用途提出された依頼や申請を認める。

例The manager granted my request for two days off.

訳上司は私の2日間の休暇申請を認めた。

a request from someone

用途依頼の送り手を示す。

例We received a request from a customer for a larger size.

訳顧客から、もっと大きいサイズを求める依頼が届いた。

at someone's request

用途特定の人の依頼が行動のきっかけだったと述べる。

例At the author's request, we removed the photograph.

訳著者の依頼で、私たちはその写真を削除した。

at the request of someone

用途依頼者を of の後に示す。

例The meeting was postponed at the request of the client.

訳顧客の要請で、会議は延期された。

available on request

用途常時配布しているとは限らず、希望すれば入手できると案内する。

例A printed copy is available on request.

訳ご希望があれば、印刷したものをお渡しできます。

upon request

用途求めに応じて行うサービスなどを改まって示す。

例We can arrange an interpreter upon request.

訳ご要望に応じて、通訳を手配できます。

by popular request

用途大勢の希望を受けた再実施などを告知する。

例The workshop is returning by popular request.

訳多くの方のご要望により、そのワークショップを再び開催します。

語法・注意3
  • 個別の依頼は a request、several requests と数える。on request、upon request、by request は無冠詞の定型句であり、その形から通常の個別依頼もすべて不可算と考えない。at your request は「あなたに頼まれて」、on request は「求めがあれば」で、前者は依頼者、後者は提供などの条件に焦点がある。
  • 名詞の a request for information に対し、動詞は request information（語義2）。名詞の for を動詞に移した request for information を、同じ他動詞構文として使わない。a request to do something の行為者は文脈で決まるため、必要なら a request that the supplier send a sample のように節で明示する。要求を表す that 節では原形を使え、英国英語では that all invoices should be sent のような should も使う。
  • request は demand より圧力の弱い、丁寧な表現になりやすいが、依頼の重要度や従う義務がないことまで保証しない。拒否することは deny/refuse/reject a request と表せるが、これらは依頼への対応であり request 自体の反意語ではない。
類義語4

demand

頻度 8/10

定義何かを強く求める要求。

違いrequest より、相手が応じるべきだという強い姿勢や圧力を表しやすい。

例The workers made a demand for safer equipment.

訳労働者たちは、より安全な設備を強く要求した。

appeal

頻度 7/10

定義支援や対応を求める訴えかけ。

違いrequest より、広い相手への呼びかけや、理解・同情に訴える面が目立つ。

例The charity launched an appeal for blankets.

訳その慈善団体は毛布の提供を呼びかけた。

application

頻度 8/10

定義許可・職・サービスなどを得るための正式な申請。

違いrequest より、決まった手続きに従って資格や提供を求める場面に限定される。

例Please submit your application by Friday.

訳金曜日までに申請書を提出してください。

plea

頻度 6/10

定義切実に何かを求める懇願。

違い中立的な request より、必死さや強い感情がこもりやすい。

例Her plea for help went unanswered.

訳彼女の助けを求める切実な訴えに、応える人はいなかった。

語義 2

【動詞・他動詞】依頼する・要請する・要求する

頻度 8/10
フォーマル・ビジネス・公的な案内。日常会話では ask for、ask someone to が一般的。

欲しい物・情報・許可などを明示して求める、または人にある行為をするよう求める。依頼内容を目的語・節・不定詞で示す形と、相手を目的語にして to 不定詞を続ける形がある。丁寧な依頼や正式な要請で使われ、依頼が受け入れられたかどうかは別である。

文法パターン9
  • request something＝物・情報などを求める
  • request something from someone＝相手に物・情報などを求める
  • request that 〈主語〉 + 〈動詞の原形〉＝あることをするよう要請する
  • request that 〈主語〉 + should + 〈動詞の原形〉＝あることをするよう要請する、主に英国英語でも使う形
  • request to do something＝自分が何かをすることを願い出る
  • request someone to do something＝人に何かをするよう要請する
  • be requested to do something＝何かをするよう求められる
  • be requested not to do something＝何かをしないよう求められる
  • request permission to do something＝何かをする許可を求める
コロケーション・構文例9

request something

用途欲しい物や対応を直接目的語にする。

例The guest requested a quiet room.

訳その宿泊客は静かな部屋を希望した。

request something from someone

用途求める物と、その提供を求める相手を分けて示す。

例We requested a revised estimate from the contractor.

訳私たちは請負業者に、修正した見積もりを依頼した。

request that 〈主語〉 + 〈動詞の原形〉

用途要請の中身を主語付きの節で表す。

例The editor requested that the author revise the introduction.

訳編集者は、著者に序論を書き直すよう要請した。

request that 〈主語〉 + should + 〈動詞の原形〉

用途要求を表す should を用いた節で依頼内容を示す。

例The committee requested that the report should be made public.

訳委員会は、その報告書を公表するよう要請した。

request to do something

用途話者・主語自身がある行為をしたいと改まって申し出る。

例The witness requested to speak in private.

訳その証人は、非公開で話したいと申し出た。

request someone to do something

用途相手を直接示し、その人にしてほしいことを続ける。

例The chair requested the participants to keep their remarks brief.

訳議長は参加者に、発言を短くするよう求めた。

be requested to do something

用途掲示や案内で、相手に取ってほしい行動を丁寧に示す。

例Visitors are requested to sign in at reception.

訳来訪者の方は、受付で記帳をお願いします。

be requested not to do something

用途掲示などで、控えてほしい行為を示す。

例Passengers are requested not to block the doors.

訳乗客の皆様は、ドアをふさがないようお願いします。

request permission to do something

用途行為そのものより、それを行う許可を明示的に求める。

例The photographer requested permission to use the image.

訳その写真家は、その画像を使用する許可を求めた。

語法・注意3
  • 物を求めるときは request a copy、相手から求めるときは request a copy from her。ask her for a copy と同じ語順をそのまま移さない。request someone to do は成立する能動構文で、受動態でしか使えないわけではない。ただし be requested to do は案内・掲示でよく見かける。
  • request that she attend では、要求を表す節の動詞が原形 attend になり、主語が she でも attends にはしない。過去の requested の後でも、その要求内容を表す原形は使える。受動なら request that it be sent。英国英語では should attend、should be sent も使える。この should は、単なる助言の「〜したほうがよい」と同じ働きではない。
  • request to speak では話すのは依頼する主語、request her to speak では話すよう求められるのは her。自分の行為の許可を明確にしたければ request permission to speak とできる。request 自体には承認・実施の意味がなく、We requested a refund. は「返金を求めた」であって「返金された」ではない。丁寧な掲示の受動態が実質的な指示となることもあるが、法的な拘束力は語だけでは決まらない。
類義語4

ask for

頻度 10/10

定義物・情報・対応などを求める。

違いrequest より日常的。物を求めるときに for が必要で、ask for a copy とする。

例I asked for a copy of the receipt.

訳私は領収書のコピーを頼んだ。

ask

頻度 10/10

定義人に何かをするよう頼む。

違いask someone to do は request someone to do より広い会話場面で使える。疑問を尋ねる別の意味もある。

例She asked me to check the address.

訳彼女は私に住所を確認するよう頼んだ。

demand

頻度 8/10

定義何かを強い調子で要求する。

違いrequest より、当然応じてもらうべきだという姿勢を示しやすい。

例The customer demanded an explanation for the delay.

訳その顧客は、遅れについて説明するよう強く求めた。

solicit

頻度 6/10

定義支援・意見・寄付などを積極的に募る。

違いrequest より、相手に働きかけて集めることを強調し、複数の相手への募集にも使われる。

例The organization solicited suggestions from its members.

訳その組織は会員から提案を募った。

語義 3

【名詞・可算】処理要求・リクエスト

頻度 6/10
情報処理・ウェブサービス。

コンピューター、プログラム、サーバーなどに、情報の取得や処理の実行を求める指示・メッセージ。人からの依頼という語義1を情報処理に用いたもので、要求を送ったことと、処理が完了したことは区別する。

文法パターン4
  • send a request to 〈システム〉＝システムに処理要求を送る
  • process a request＝要求に対応する処理を行う
  • a request for 〈データ・処理〉＝データや処理を求める要求
  • a request from 〈クライアントなど〉＝クライアントなどからの要求
コロケーション・構文例3

send a request to 〈システム〉

用途要求の送り先を示す。

例The app sends a request to the server when you open the page.

訳ページを開くと、アプリはサーバーにリクエストを送る。

process a request

用途受け取った要求をシステムが処理する。

例The server could not process the request because a required field was missing.

訳必須項目が欠けていたため、サーバーはそのリクエストを処理できなかった。

a request for 〈データ〉

用途取得を求めるデータを示す。

例The client sent a request for the latest exchange rates.

訳クライアントは、最新の為替レートを取得するリクエストを送った。

語法・注意1
  • request は要求側のメッセージ、response はそれに対する応答として対比される。両者はやり取りの役割の違いであり、反意語ではない。request が HTTP の要求を指す場合もあるが、この語だけで通信方式・処理内容・成功の有無は決まらない。send、receive、process、reject など、周囲の動詞で段階を読む。
類義語2

query

頻度 6/10

定義データベースなどから情報を取り出すための問い合わせ。

違いrequest は処理要求を広く指すが、query は主に情報の検索・照会に焦点がある。

例The database returned no results for the query.

訳そのクエリに対して、データベースからは結果が返されなかった。

command

頻度 6/10

定義システムに特定の動作を行わせる命令。

違いrequest はやり取りの要求側として捉え、command は実行させる操作の指示として捉える。すべての request が操作コマンドとは限らない。

例Enter the command to display the file list.

訳ファイルの一覧を表示するコマンドを入力してください。

語義 4

【名詞・可算】リクエスト曲

頻度 5/10
ラジオ・音楽番組・ライブ演奏。

聴き手が演奏者や番組などにかけてほしいと頼んだ曲・楽曲。曲を求める依頼そのものに加え、その依頼の対象となった曲を指す。

文法パターン3
  • play a request＝リクエストされた曲を演奏する、かける
  • take requests＝曲のリクエストを受け付ける
  • a request from 〈聴き手〉＝その聴き手のリクエスト曲
コロケーション・構文例2

play a request

用途聴き手が希望した曲を演奏する、または放送する。

例The pianist played a request from someone in the audience.

訳ピアニストは、観客の一人がリクエストした曲を演奏した。

take requests

用途演奏・放送する曲の希望を受け付ける。

例The band takes requests during the second half of the show.

訳そのバンドは、公演の後半に曲のリクエストを受け付ける。

語法・注意1
  • The next request is a jazz standard. の request は「次にかけるリクエスト曲」。a request for a song は「曲を求める依頼」であり、依頼という行為・内容と、求められた曲という対象のどちらを指すかを動詞や文脈で判断する。語義2の動詞 request a song は「その曲をかけてほしいと頼む」。
語義 5

【慣用表現・前置詞句】需要がある・引っ張りだこである

頻度 2/10
古風・文語。

in request の形で、人や物が求められている状態を表す。現代では古風に響く表現で、通常は in demand を使う。

文法パターン2
  • be in request＝需要がある
  • be much in request＝大いに求められている
コロケーション・構文例1

be much in request

用途古風な語り口で、人の人気や需要の高さを表す。

例His services were much in request among wealthy families.

訳彼の仕事は、裕福な家庭の間で引っ張りだこだった。

語法・注意1
  • on request「求めに応じて」と取り違えない。in request は、依頼を提出中という意味ではない。現在の業務文書では His services were in high demand. のように書くほうが一般的。
類義語1

in demand

頻度 8/10

定義人や物が多く求められている。

違いin request と同じ需要の軸を表す、現代の一般的な表現。

例Experienced technicians are in demand.

訳経験豊富な技術者の需要がある。

該当する語義・用例がありません。
