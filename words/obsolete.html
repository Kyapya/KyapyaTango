発音記号

米: /ˌɑːb.səˈliːt/｜英: /ˈɒb.sə.liːt/

  • 3音節。ここに示す米音は第3音節 /liːt/ に主強勢、第1音節 /ɑːb/ に第2強勢があり、英音は第1音節 /ɒb/ に主強勢がある。第1音節の母音も米 /ɑː/、英 /ɒ/ と異なる。強勢には変異があり、米音でも第1音節に主強勢を置く発音、英音でも第3音節に主強勢を置く発音がある。形容詞と動詞で強勢を必ず変える語ではない。

コアイメージ

語義1・2の共通核は、現用のものとしての通用性・必要性を失うこと。物そのものの消滅や故障とは限らない。ただし、語義3の「痕跡的な、退化的な、不明瞭な」は、このコアイメージだけでは説明できない。生物の形態記述では、部位の発達の程度や輪郭の明瞭さを表すため、現在使われているかどうかとは分けて理解する。

  • 現用のものとしての通用性・必要性を失った状態 → 「時代遅れの、廃れた、もはや使われない」（語義1）
  • 現用のものとしての通用性・必要性を失わせる変化 → 「旧式化させる、時代遅れにする」（語義2）

語源

  • ラテン語 obsoletus「古くなった、使い古された」に由来し、obsolescere「使われなくなる」と結びつく。中心にあるのは、時間や変化によって以前の役割・通用性を失うこと。同語源語には obsolescent「廃れつつある」、obsolescence「陳腐化、廃れること」がある。さらに古い語の分解には説の違いがあるため、現代英語の ob- と任意の語を組み合わせて意味を推測しない。

語形成

obsolescent（形容詞）＝時代遅れになりつつある、廃れかけた。変化の途中に焦点がある。
obsolescence（名詞、不可算）＝陳腐化する過程、または陳腐化した状態。obsolete と obsolescent の両方に対応し得る。
obsoletes / obsoleted / obsoleting（動詞の活用形）＝三人称単数現在／過去・過去分詞／現在分詞。-ing では末尾の e を落とす。obsoleted の -ed は /ɪd/ となる。
obsoleted（過去分詞）＝新技術などによって旧式化された、廃止対象にされた。形容詞 obsolete「旧式である」と、変化を受けたことを表す過去分詞を区別する。

語義 1

【形容詞：限定・叙述】時代遅れの、廃れた、もはや使われない

頻度 7/10
標準的。技術、ビジネス、社会の変化、言語の説明。日常的な old より改まった響きがある。

技術・製品・方法・考え方・語などが、現在の用途や慣行に合わなくなった、必要性を失った、または一般に使われなくなった状態。新しいものに置き換えられた場合に多いが、新製品の登場だけが原因とは限らない。「古い」という年代の説明より、現在の通用性・実用性の喪失に焦点がある。obsolete equipment でも動作する機器や一部で使用中の機器はあり、故障・完全消滅を必ず意味しない。

文法パターン4
  • obsolete 〈機器・方法・語〉＝廃れたものを名詞の前から修飾
  • 〈物・方法など〉 + be/become/seem obsolete＝旧式である・旧式になる・旧式に見える
  • make/render 〈O〉 + obsolete＝Oを旧式化させる
  • be made/rendered obsolete by 〈原因〉＝その原因で旧式化する。completely、largely、increasingly、technologically などで範囲や程度・観点を示せる。more obsolete も文脈上可能だが、一般には increasingly obsolete や nearly obsolete が明確。obsolete to do という不定詞補文を基本構文として使う語ではない。
コロケーション・構文例8

obsolete equipment

用途現在の技術・業務から見て旧式になった機器を述べる。

例The workshop still uses some obsolete equipment because replacement parts remain available.

訳交換部品がまだ手に入るため、その作業場では旧式の機器も一部使い続けている。

become obsolete

用途以前は役立っていたものが通用しなくなる変化を述べる。

例These skills could become obsolete if the entire process is automated.

訳工程全体が自動化されれば、これらの技能は必要とされなくなるかもしれない。

make 〈O〉 obsolete

用途新しい技術などが従来の道具・方法の必要性を失わせると述べる。

例The new tracking system made our handwritten delivery log obsolete.

訳新しい追跡システムの導入で、手書きの配送記録は不要になった。

render 〈O〉 obsolete

用途改まった文章で旧式化の原因と結果を結びつける。

例Changes in the file format rendered the old conversion tool obsolete.

訳ファイル形式の変更により、従来の変換ツールは役に立たなくなった。

be rendered obsolete by 〈原因〉

用途旧式化する側を主語にして、変化の原因を示す。

例The navigation charts were rendered obsolete by major changes to the harbour.

訳港の大規模な変更によって、その航海用海図は現状に合わなくなった。

be increasingly obsolete

用途用途・使用範囲が次第に失われていると述べる。

例Paper directories are increasingly obsolete as contact details move online.

訳連絡先の情報がオンラインへ移るにつれて、紙の名簿はますます使われなくなっている。

be technologically obsolete

用途外見や故障ではなく、技術面での旧式化を示す。

例The scanner is technologically obsolete, but it still produces clear images.

訳そのスキャナーは技術的には旧式だが、今でも鮮明な画像を取り込める。

an obsolete word

用途現代の通常の言語使用から消えた語を指す。

例The editor added a note to explain an obsolete word in the original letter.

訳編集者は、手紙の原文にある廃語を説明する注を加えた。

語法・注意1
  • obsolete は状態を表す形容詞なので、The device is obsolete.「その機器は旧式だ」と言う。The device is obsoleted by a new model. は語義2の受動態で、新型によって旧式化されるという作用を表す。make it obsolete の obsolete は目的語 it の補語で、make it to obsolete とはしない。obsolescent は「廃れつつある」を前面に出すが、obsolete も increasingly、nearly などと結びつくため、常に完全な二者択一を表すわけではない。辞書の obsolete というラベルは通常の現代使用が失われた語・語義を示す。archaic は古風だが特殊な文体などに使用が残るものに使われ、厳密な年代の区切りは辞書ごとに異なる。人に obsolete と言うと「もう役に立たない」と切り捨てる響きが出やすく、技能や役割を具体的に主語にするほうが意図を伝えやすい。
類義語4

outdated

頻度 8/10

定義現在の事情・知識・標準に合わなくなった。

違い情報・考え方にも広く使い、修正や更新が必要だと示す。obsolete より、一般に使われなくなったという含みが弱い。

例The website lists outdated opening hours.

訳そのウェブサイトには古い営業時間が載っている。

outmoded

頻度 5/10

定義新しい方法・慣行に合わず、時代遅れになった。

違い方法・考え方・様式への評価に向き、物が実際に使われなくなったかより現在との不適合を強調する。

例The report challenges outmoded assumptions about family life.

訳その報告書は、家庭生活についての時代遅れの思い込みに疑問を投げかけている。

antiquated

頻度 5/10

定義非常に古く、現代には不適切と思われる。

違い古さや不便さへの批判が強い。obsolete も現役で使われている物に使えるが、antiquated は非常に古く、今の用途に不適切だという評価を強めやすい。

例Staff spend hours entering data into an antiquated system.

訳職員は、ひどく古いシステムへのデータ入力に何時間も費やしている。

archaic

頻度 5/10

定義過去の時代に属し、今では古風な。

違いとくに言葉・表現では、古風な文体として残ることがある。obsolete の辞書ラベルより現代使用の余地を残す。

例The poem uses archaic language to create a sense of distance from modern life.

訳その詩は古風な言葉を使い、現代生活からの隔たりを感じさせている。

反意語2

current

頻度 8/10

定義現在使われている、現在通用している。

違い現在の通用性という同じ軸で対立する。新しいこと自体ではなく、今も有効・現役である点に焦点がある。

例The glossary includes both historical terms and current terminology.

訳その用語集には、歴史的な語と現在通用している専門用語の両方が載っている。

up-to-date

頻度 8/10

定義最新の情報・技術・状況に対応している。

違い現状への適合性という軸での対立。obsolete でないものがすべて最新というわけではなく、程度上の反対である。

例We need an up-to-date inventory of all the equipment.

訳すべての機器について、最新の在庫一覧が必要だ。

語義 2

【動詞：他動詞】旧式化させる、時代遅れにする

頻度 3/10
技術・製品管理・ビジネスの文章。形容詞用法ほど一般的ではなく、広い読者には make obsolete が分かりやすい。

技術・新製品・方針の変更などが、従来の製品・設備・仕組みを不要または旧式にすること。製品管理などでは、メーカーが既存品を廃止扱いにすることも表す。形容詞の状態を生じさせる動詞であり、物を物理的に壊すことではない。

文法パターン3
  • 〈新技術・メーカーなど〉 + obsolete 〈既存製品・仕組み〉＝既存のものを旧式化させる
  • be obsoleted by 〈新技術・後継品など〉＝新しいものによって旧式化される
  • obsoleted 〈部品・製品〉＝旧式化・廃止扱いにされたもの。目的語は旧式化される対象で、obsolete to 〈対象〉とはしない。
コロケーション・構文例4

obsolete existing equipment

用途技術の進歩が既存設備の実用性を失わせると述べる。

例A sudden change in transmission technology could obsolete much of the existing equipment.

訳伝送技術の急変によって、既存設備の多くが旧式化する可能性がある。

obsolete a product

用途メーカーが従来の製品を廃止対象にすることを述べる。

例The manufacturer plans to obsolete the older controller once its replacement is available.

訳メーカーは、後継機が販売可能になり次第、旧型の制御装置を廃止扱いにする予定だ。

be obsoleted by 〈後継技術〉

用途既存の仕組みが新技術によって不要になることを示す。

例The proprietary cable was obsoleted by a standard wireless connection.

訳標準の無線接続方式が登場し、その専用ケーブルは不要になった。

obsoleted components

用途旧式化・廃止扱いになった部品を過去分詞で修飾する。

例The service manual provides replacement options for obsoleted components.

訳整備マニュアルには、廃止扱いになった部品の代替品が示されている。

語法・注意1
  • 語義1の an obsolete component は「旧式の部品」という状態、an obsoleted component は何らかの変化・判断によって旧式化または廃止扱いにされた部品である。後者から製造・販売・保守がすべて同日に終了するとは判断できず、具体的な扱いはメーカーの記述を読む。「旧式になる」を一般的に言うなら become obsolete を用い、この他動詞を目的語なしで The device obsoleted. としない。過去分詞の限定用法にハイフンは付けない。日常の説明では The new system made it obsolete. と言い換えられる。
類義語3

supersede

頻度 5/10

定義新しいものが従来のものに取って代わる。

違い後継関係・置換そのものを示す。obsolete はその結果として従来品が通用しなくなる点を前面に出す。

例The revised specification supersedes the previous version.

訳改訂された仕様書が旧版に取って代わる。

outdate

頻度 3/10

定義既存のものを時代遅れにする。

違い意味は近いが、現在の知識や事情に合わなくするという広い変化を表せる。メーカーによる廃止扱いを特に示す語ではない。

例Rapid discoveries can outdate a textbook before a new edition is ready.

訳発見が相次ぐと、改訂版の準備ができる前に教科書の内容が古くなってしまうことがある。

replace

頻度 9/10

定義別のものをその役割・位置に入れる。

違い実際の交換・交代を表す平易な語。交換前のものが時代遅れであるとは限らず、obsolete より理由の範囲が広い。

例We replaced the damaged sensor with an identical one.

訳破損したセンサーを同じ型のものに交換した。

語義 3

【形容詞：限定・叙述】痕跡的な、退化的な、不明瞭な

頻度 2/10
生物学、植物学、分類・形態の記述。一般の技術や製品についての「時代遅れ」と区別する。

動植物の器官や部分が、関連する生物の対応部分などと比べて十分に発達していない、著しく縮小している、またははっきり認めにくい状態。形態を記述する専門用法で、その部分が現在使われないことや、特定の進化の経緯を必ず述べるわけではない。

文法パターン2
  • an obsolete 〈organ/part〉＝痕跡的・不明瞭な器官や部分
  • 〈部位〉 + be obsolete＝部位が痕跡的・不明瞭である。
コロケーション・構文例2

obsolete teeth

用途形態記述で、歯状の突起がほとんど認められないことを示す。

例The leaf margin has obsolete teeth that are difficult to distinguish.

訳その葉の縁には、判別しにくいほど不明瞭な鋸歯がある。

〈部位〉 + be obsolete

用途器官や部分の縮小・不明瞭さを述べる。

例In this specimen, one petal is nearly obsolete.

訳この標本では、花弁の1枚がほとんど痕跡的になっている。

語法・注意1
  • obsolete equipment の「もはや現用でない」という意味を、そのまま植物の器官に当てはめない。形態記述の teeth は葉の縁などの歯状部分を指すことがあり、人や動物の歯とは限らない。部位が小さい・不明瞭だという記述だけから、機能が完全にない、あるいは祖先がどのような形だったとまでは断定できない。
類義語1

rudimentary

頻度 3/10

定義器官・部分が未発達で、基本的・不完全な形にとどまる。

違い発達の程度が低いことに重点がある。obsolete はこの専門義では、縮小して痕跡的・不明瞭であることも表す。

例The organ remains rudimentary in the adult.

訳成体でもその器官は未発達なままである。

該当する語義・用例がありません。
