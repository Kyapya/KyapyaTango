base

主要語義 29更新 2026-10-28

発音記号

米・英: /beɪs/。1音節で、母音は二重母音 /eɪ/。名詞・動詞・形容詞で発音を変えない。複数形・三人称単数形 bases は /ˈbeɪsɪz/、動詞の過去形・過去分詞 based は /beɪst/、basing は /ˈbeɪsɪŋ/。based の語尾に母音を加えて2音節にしない。音楽の低音を表す bass とは同音だが、魚を表す bass は別の発音なので一律に同音と覚えない。

コアイメージ

物・活動・判断がよりどころとする土台や足場・基準点。野球の足場から生まれた語義13〜17も、戻って確かめる接点、押さえるべき要点、正しい足場からの逸脱、最初の足場への到達としてつなげて覚えられるが、句全体の定着した意味は各項で学ぶ。語義11・25は「低い」という別系統の形容詞で、この核を共有しない同綴異義。語義22・23・26は制度的専門義で、酸塩基反応の性質・核酸の特定成分・トランジスタの特定部分という語彙的な定義自体を、この土台の核から予測できないため個別に覚える。語義27・28の俗語 based も、通常の分詞とは意味系統を分ける同綴異義として扱い、土台から好意的評価を直接導かない。

  • 物を支える土台となる部分 → 「底部、付け根、支えとなる部分」（語義1）
  • 活動を支える土台となる場所 → 「活動拠点、生活や事業の拠点」（語義2）
  • 軍事活動を支える土台となる施設 → 「軍事基地」（語義3）
  • 組織を支える土台となる人や産業 → 「支持基盤、顧客基盤、経済的な基盤」（語義4）
  • 計画を支える土台となる考え → 「考え・計画の基礎、出発点」（語義5）
  • 判断を支える土台を定めること → 「根拠・基礎を置く、基づかせる」（語義6）
  • 活動を支える土台へ配置すること → 「拠点を置く、配置する」（語義7）
  • 物や活動を支える土台の指定 → 「～に基づく、～を拠点とする」（語義8）
  • 完成物を支える土台となる材料 → 「主成分、基礎材料、下に重ねる層」（語義9）
  • 追加前の土台となる部分や仕様 → 「基本の、追加分を含まない」（語義10）
  • 主張を支える土台の欠如 → 「根拠のない：baseless」（語義12）
  • 走者の足場となる競技上の地点 → 「野球・ソフトボールの塁、ベース」（語義13）
  • 状況を確かめ直す接点への立ち寄り → 「連絡を取る、近況や進捗を確認し合う：touch base」（語義14）
  • 準備の足場となる各要点の確保 → 「必要な点を漏れなく押さえる：cover all the bases」（語義15）
  • 判断の正しい足場からの逸脱 → 「的外れで、間違って：off base」（語義16）
  • 進展の最初の足場への到達 → 「最初の段階に進む：get to first base」（語義17）
  • 図形の高さの土台となる辺や面 → 「図形の底辺、底面」（語義18）
  • 位取りを組み立てる土台となる数 → 「記数法の基数」（語義19）
  • 累乗や対数の土台となる数 → 「累乗・対数の底」（語義20）
  • 比率計算の土台となる量 → 「割合・比較の基準となる数値」（語義21）
  • 語形成の土台となる形 → 「語形成の基体」（語義24）
  • 恋愛的な進展の最初の足場 → 「キスに至る段階：first base」（語義29）

語源

  • 名詞の基本的な系列は、フランス語を経由し、ラテン語 basis を通じて、ギリシャ語の基盤・足場を表す語にさかのぼる。動詞 base は名詞に由来する。一方、卑しい・品位の低いという形容詞は、フランス語 bas、ラテン語 bassus「低い」の系列で、名詞と同じ語源から全てを説明しない。basis と base は関連していても、現代の語形・使い方は別である。

語形成

based動詞の過去形・過去分詞。based on は根拠、based in は拠点を示すことが多い。名詞の前では evidence-based、Tokyo-based などの複合修飾も作る。
baseless主張などに根拠がないことを表す形容詞。卑しいという base に単純に否定を加えた意味ではない。
baseness道徳的な卑しさを表す名詞。名詞 base の拠点や土台を数える複数形ではない。
basely卑劣にという副詞。基本的にという basically と取り違えない。

語義 1

【名詞：可算・通常単数】底部、付け根、支えとなる部分

頻度 9/10
日常・物の説明・身体・建築。

物の下側にある部分や、それを支える底・台。また、体の部位や物が他の部分とつながる付け根を指す。どの物の base かによって、底面・ふもと・基部などと訳し分ける。

文法パターン5
  • the base of something
  • at the base of something
  • a broad base
  • a metal base
  • the base of the thumb。
コロケーション・構文例5

the base of something

用途物の最下部や支える部分を述べる。

例Water had collected around the base of the wall.

訳壁の下の部分の周囲に、水がたまっていた。

at the base of something

用途山などの下側の位置を示す。

例The village lies at the base of the mountain.

訳村は、その山のふもとにある。

a broad base

用途下部の幅が広く、安定している形を述べる。

例The vase has a broad base that keeps it from tipping easily.

訳その花瓶は底が広く、簡単には倒れない。

a metal base

用途支台の材料を述べる。

例The lamp is fixed to a heavy metal base.

訳ランプは、重い金属製の台座に固定されている。

the base of the thumb

用途指の付け根の位置を述べる。

例The glove was worn through at the base of the thumb.

訳手袋は、親指の付け根のところが擦り切れていた。

語法・注意1
  • base は物との位置関係で意味が決まる。山ならふもと、ランプなら台座、親指なら付け根と、日本語の一語に固定しない。at the base は位置、the base of the object は対象との関係を示す。建物の地盤とつながる基礎構造を特に述べる foundation より、base は台や底面を広く指せる。
類義語2

bottom

頻度 10/10

定義物や場所の一番下の部分。

違い上下関係の最下部を広く指す。base はそこが物を支える部分・付着部であるという面にも注目する。

例There was some sand at the bottom of the bag.

訳かばんの底には、少し砂があった。

foundation

頻度 8/10

定義建物などを安定して支える基礎。

違い全体を構造的に支える基礎に重点がある。base は小さな物の台座や、身体の付け根にも使う。

例The engineers checked the building's foundations.

訳技術者たちは、建物の基礎を確認した。

語義 2

【名詞：可算】活動拠点、生活や事業の拠点

頻度 8/10
一般・旅行・業務・調査。

人や組織が滞在し、そこを中心として活動する場所。恒久的な本拠地にも、旅行や調査の一時的な拠点にも使う。

文法パターン5
  • a base for doing something
  • use somewhere as a base
  • an operational base
  • a home base
  • return to base。
コロケーション・構文例5

a base for doing something

用途何をする拠点なのかを示す。

例The town is a convenient base for exploring the surrounding hills.

訳その町は、周囲の丘陵を巡るのに便利な拠点だ。

use somewhere as a base

用途一定の場所を拠点として使う。

例The researchers used the village as a base during the survey.

訳研究者たちは、調査中、その村を拠点として使った。

an operational base

用途実務的な活動を行う拠点を述べる。

例The rescue team established an operational base near the affected area.

訳救援隊は、被災地域の近くに活動拠点を設けた。

a home base

用途戻ってくる中心的な拠点を指す。

例She travels frequently but keeps a home base in Tokyo.

訳彼女は頻繁に旅をするが、東京に生活の拠点を置いている。

return to base

用途作業や活動の拠点へ戻る。

例The survey team returned to base before dark.

訳調査隊は、暗くなる前に拠点へ戻った。

語法・注意1
  • a base for exploring の for の後ろには動名詞を置ける。a base in Tokyo なら所在地であり、for と役割が違う。拠点に戻るなどの慣用的な使い方では return to base と無冠詞になることがあるが、全ての文で冠詞を省くわけではない。a base は必ずしも会社の登記上の本社や、個人の正式な住所ではない。
類義語1

headquarters

頻度 8/10

定義組織を指揮・管理する本部。

違い管理・指揮の中心という役割がある。base は調査隊の一時的な滞在先など、必ずしも本部でない活動拠点にも使う。

例The company moved its headquarters to a larger building.

訳会社は、本社をより大きな建物に移した。

語義 3

【名詞：可算・慣用的に無冠詞も】軍事基地

頻度 7/10
軍事・報道・歴史。

軍が人員・装備を配置し、訓練・補給・作戦などを行う拠点。一般的な活動拠点より、軍事施設という対象が明確な用法。

文法パターン5
  • a military base
  • an air base
  • a naval base
  • be stationed at a base
  • return to base。
コロケーション・構文例5

a military base

用途軍の施設としての基地を指す。

例The road passes a military base outside the city.

訳その道路は、市外にある軍事基地のそばを通っている。

an air base

用途軍用機などの活動拠点を述べる。

例The aircraft returned to the air base after the exercise.

訳航空機は、演習後に航空基地へ戻った。

a naval base

用途海軍の拠点を述べる。

例The port developed around a naval base.

訳その港は、海軍基地を中心に発展した。

be stationed at a base

用途人員が基地に配置されていることを述べる。

例He was stationed at a base near the coast.

訳彼は、海岸近くの基地に配属されていた。

return to base

用途軍事任務から所属基地に帰還する。

例The patrol was ordered to return to base.

訳哨戒隊は、基地へ戻るよう命じられた。

語法・注意1
  • base を全て一般旅客用の空港と訳さない。an air base は軍事的な航空拠点を指す。at a base は所在地、to base は帰還先など、前置詞の働きを区別する。この単語だけでは、特定の基地の所有権・管轄・運用条件は分からない。
語義 4

【名詞：可算・通常単数】支持基盤、顧客基盤、経済的な基盤

頻度 8/10
ビジネス・政治・経済・報道。

人や組織を継続的に支える支持者・顧客・収入源などのまとまり。物理的な場所ではなく、活動を成り立たせる人的・経済的な支えを表す。

文法パターン5
  • a customer base
  • a fan base
  • a support base
  • an economic base
  • broaden one's base。
コロケーション・構文例5

a customer base

用途継続的に商品やサービスを利用する顧客の層を述べる。

例The business built a loyal customer base over many years.

訳その事業は、長年かけて忠実な顧客層を築いた。

a fan base

用途人や作品を支えるファンの集まりを述べる。

例The band has a small but enthusiastic fan base.

訳そのバンドには、少人数ながら熱心なファンがついている。

a support base

用途政治家や運動を支える人々の層を述べる。

例The candidate's support base extends beyond the capital.

訳その候補者の支持層は、首都の外にも広がっている。

an economic base

用途地域などの経済を支える産業・活動を述べる。

例Tourism has become an important part of the island's economic base.

訳観光は、その島の経済基盤の重要な部分になった。

broaden one's base

用途支持者や顧客などの範囲を広げる。

例The organization hopes to broaden its base by reaching younger members.

訳その組織は、若い会員を取り込んで基盤を広げたいと考えている。

語法・注意1
  • customer base は顧客が集まる建物ではなく、顧客層を指す。fan base のように前の名詞で何の基盤かを示せる。広い顧客層があることと、一人ひとりが高額の売上を生むことは別であり、base だけでは人数や収益性は決まらない。tax base も経済の文章で見るが、具体的な課税対象や計算範囲は税制度ごとに確認する。
語義 5

【名詞：可算】考え・計画の基礎、出発点

頻度 7/10
一般・教育・業務・議論。

判断・計画・発展などの出発点として使う知識・考え・情報など。人的な支持層ではなく、何かを組み立てるための内容的な土台を指す。

文法パターン4
  • a sound base for something
  • a knowledge base
  • build on an existing base
  • provide a base for something。
コロケーション・構文例4

a sound base for something

用途活動の確かな土台を述べる。

例The initial survey provides a sound base for further research.

訳初期調査は、追加研究の確かな土台を提供している。

a knowledge base

用途活動を支える蓄積した知識を述べる。

例The training helped the team develop a broader knowledge base.

訳研修は、チームがより幅広い知識の基盤を築く助けになった。

build on an existing base

用途既存の基礎を生かしてさらに発展させる。

例The course builds on the existing base of skills that students bring with them.

訳その授業は、学生が既に持っている技能の基盤を生かして進められる。

provide a base for something

用途今後の活動に必要な足場を提供する。

例The agreement provides a base for future cooperation.

訳その合意は、今後の協力の基礎となる。

語法・注意1
  • base は抽象的な基盤にも使えるので、物理的な底にしか使えないとは覚えない。ただし basis と常に交換できるわけではなく、on a daily basis のような定着した表現を on a daily base に変えない。knowledge base は一般的な知識の蓄積のほか、情報技術の文脈では整理された知識の集合を指す場合がある。
類義語1

basis

頻度 8/10

定義判断や活動が依拠する理由・土台。

違い判断根拠や方式を述べる表現に広く使う。base は発展の出発点や蓄積した資源としての基盤を述べることもあり、定着した構文ごとに選ぶ。

例The decision was made on the basis of the available evidence.

訳その決定は、利用できる証拠に基づいて行われた。

語義 6

【動詞：他動詞】根拠・基礎を置く、基づかせる

頻度 9/10
日常・業務・学術・報道。

判断・作品・計画などを、情報・原則・経験などから成り立つものにする。base A on B では、A が基づくもの、B がその根拠や素材となる。

文法パターン5
  • base something on something
  • base something upon something
  • be based on evidence
  • be based on a true story
  • base a decision on the assumption that …。
コロケーション・構文例5

base something on something

用途何を何に基づかせるかを能動態で示す。

例We based the estimate on last year's sales figures.

訳私たちは、昨年の売上高に基づいて見積もりを出した。

base something upon something

用途upon を用いて根拠を改まって述べる。

例The author bases her argument upon a detailed study of the records.

訳著者は、記録の詳細な調査を議論の根拠にしている。

be based on evidence

用途受動態で、証拠に基づくことを述べる。

例The recommendation is based on evidence from several trials.

訳その勧告は、複数の試験の証拠に基づいている。

be based on a true story

用途作品の素材となる実際の出来事を述べる。

例The film is loosely based on a true story.

訳その映画は、実話を緩やかに下敷きにしている。

base a decision on the assumption that …

用途判断を支える想定の内容を示す。

例They based the decision on the assumption that demand would continue to rise.

訳彼らは、需要が上がり続けるという想定に基づいて決定した。

語法・注意1
  • We base our plans on evidence. の目的語は our plans で、根拠 evidence は on の後ろに置く。Our plans are based on evidence. では plans が主語になる。「計画は証拠に基づく」の意味で Our plans base on evidence. と他動詞の目的語や受動の be を落とさない。based on は根拠・素材、based in は活動場所を示すことが多い。また、根拠が assumption なら、based on だけで内容が証明済みとは言えない。
類義語1

ground

頻度 6/10

定義判断や考えを根拠・現実に結びつける。

違いground something in evidence のように、実際の事実・経験との結びつきを強調する。base A on B の on を、全ての近義語へ機械的に移さない。

例Her analysis is grounded in practical experience.

訳彼女の分析は、実務経験に根ざしている。

語義 7

【動詞：他動詞・受動態が多い】拠点を置く、配置する

頻度 8/10
一般・業務・活動場所の説明。

人・組織・活動を、一定の場所を中心として動くように置く。どの根拠で判断したかではなく、どこで活動するかを述べる。

文法パターン4
  • be based in 〈都市・地域〉
  • be based at 〈施設〉
  • base operations in 〈都市・地域〉
  • base oneself in 〈都市・地域〉。
コロケーション・構文例4

be based in 〈都市・地域〉

用途人や組織が活動の中心とする都市・地域を述べる。

例The designer is based in Osaka but works with clients worldwide.

訳そのデザイナーは大阪を拠点としながら、世界各地の顧客と仕事をしている。

be based at 〈施設〉

用途特定の施設などを拠点として述べる。

例The research team is based at the university's coastal laboratory.

訳研究チームは、大学の沿岸研究所を拠点としている。

base operations in 〈都市・地域〉

用途活動の拠点を能動態で設定する。

例The company decided to base its regional operations in Singapore.

訳会社は、地域事業の拠点をシンガポールに置くことにした。

base oneself in 〈都市・地域〉

用途自分の活動拠点を置く。

例She based herself in the capital while researching the book.

訳彼女は、本の調査をしている間、首都を拠点にした。

語法・注意1
  • be based in Tokyo は東京が拠点であるという意味で、常にその瞬間東京にいるとは限らない。名詞や代名詞を置く場合は base the team in Tokyo／base it in Tokyo とする。base oneself の再帰代名詞は主語に合わせる。所在地の in と、建物・施設を指す at は具体的な場所の捉え方で選ぶ。根拠を示す based on data と混同しない。
語義 8

【複合修飾 -based：名詞の前】～に基づく、～を拠点とする

頻度 8/10
一般・業務・製品・学術。

前に置いた情報・素材・場所などを、基盤・主な構成・活動拠点として持つことを表す複合修飾。前半の語の種類によって関係が変わる。

文法パターン4
  • an evidence-based approach
  • a Tokyo-based company
  • a plant-based product
  • a web-based service。
コロケーション・構文例4

an evidence-based approach

用途証拠を基盤とする方法を述べる。

例The team adopted an evidence-based approach to evaluating the programme.

訳チームは、事業を評価するために証拠に基づく方法を採用した。

a Tokyo-based company

用途所在地を前から一まとまりで修飾する。

例A Tokyo-based company developed the software.

訳東京を拠点とする会社が、そのソフトウェアを開発した。

a plant-based product

用途植物由来の材料を基盤とする製品を述べる。

例The shop introduced a new plant-based product.

訳店は、植物由来の新しい製品を導入した。

a web-based service

用途ウェブを利用基盤とするサービスを述べる。

例The organization replaced the paper forms with a web-based service.

訳その組織は、紙の申請書をウェブベースのサービスに置き換えた。

語法・注意1
  • 名詞の前では Tokyo-based company のように通常ハイフンで結び、叙述位置では The company is based in Tokyo. と通常の構文に戻せる。evidence-based は根拠、Tokyo-based は拠点なので、どちらも同じ前置詞で復元できるわけではない。plant-based の具体的な原材料の範囲や表示基準を -based だけから決めつけない。ここでの用法は一般的な複合修飾。インターネット上の評価表現 based は、別の語義27・28で扱う。
語義 9

【名詞：可算・通常単数】主成分、基礎材料、下に重ねる層

頻度 7/10
調理・製品・塗装・化粧など。

混合物や製品の主な材料、また上に別のものを加えるための土台となる材料や層。出来上がった物の底の形だけでなく、素材としての役割に注目する。

文法パターン5
  • a tomato base
  • a base for a sauce
  • an oil base
  • apply a base coat
  • a makeup base。
コロケーション・構文例5

a tomato base

用途料理の中心となる材料を述べる。

例The soup has a rich tomato base with herbs and beans.

訳そのスープは、濃厚なトマトをベースに、ハーブと豆を加えている。

a base for a sauce

用途さらに材料を加えてソースを作る土台を述べる。

例The stock provides a base for the sauce.

訳そのだし汁が、ソースのベースになる。

an oil base

用途他の成分を含ませる基礎材料を述べる。

例The product uses an oil base to carry the colour.

訳その製品は、色の成分を含ませる基材として油を使っている。

apply a base coat

用途上に塗る層に先立つ塗膜を作る。

例They applied a base coat before painting the final colour.

訳彼らは、仕上げの色を塗る前に下塗りをした。

a makeup base

用途メイクの基礎となる層や製品を述べる。

例She applied a makeup base before putting on her foundation.

訳彼女は、ファンデーションを付ける前に化粧下地を塗った。

語法・注意1
  • a base for the sauce の for は、この材料から何を作るかを示す。a tomato base は主な材料の種類を述べ、必ずトマトしか入っていないとは限らない。化粧品の base は基礎となる役割を広く指し、具体的な製品が primer か foundation かは商品説明や使い方で確認する。英語と日本語の商品分類を単語だけで同一視しない。
語義 10

【名詞の限定用法・形容詞的用法】基本の、追加分を含まない

頻度 7/10
給与・価格・商品仕様。base pay は特に北米で使う。

賃金・価格・機種などについて、追加手当や追加装備を含める前の基本となる額・仕様を表す。道徳的に卑しいという形容詞の意味とは別である。

文法パターン4
  • base salary
  • base pay
  • the base price
  • the base model。
コロケーション・構文例4

base salary

用途手当や成果報酬などと区別した基本給を述べる。

例The job offers a base salary plus a performance bonus.

訳その仕事では、基本給に加えて業績賞与が支給される。

base pay

用途通常の支給額の土台を述べる。

例Overtime payments are separate from base pay.

訳時間外手当は、基本給とは別に支払われる。

the base price

用途オプションなどを加える前の価格を述べる。

例The base price does not include delivery or installation.

訳基本価格には、配達費と設置費は含まれていない。

the base model

用途基本仕様の機種を述べる。

例Even the base model includes a rear camera.

訳基本モデルでも、後方カメラが付いている。

語法・注意1
  • base salary／basic salary のように、地域や慣用によって選ばれる形がある。base が付けば全ての契約で同じ手当を除外するというわけではなく、含まれる範囲は条件を読む。ここでの base は主に名詞の前に置き、The salary is base. とすると卑しいという別の形容詞の読みを誘うため、基本給という意味には使わない。
語義 11

【形容詞】卑しい、卑劣な

頻度 4/10
硬い表現・文学的な非難。

動機・行為・欲望などが、道徳的に低劣であると強く非難する。所得や身分が低いという意味を現代の人に機械的に当てはめる語ではない。

文法パターン5
  • base motives
  • base instincts
  • a base betrayal
  • be base
  • baser instincts。
コロケーション・構文例4

base motives

用途行為の動機を道徳的に非難する。

例He accused his rival of acting from base motives.

訳彼は、ライバルが卑劣な動機から行動していると非難した。

base instincts

用途人の低劣な衝動に訴えることを述べる。

例The speech appealed to the crowd's base instincts.

訳その演説は、群衆の卑しい本能に訴えかけた。

a base betrayal

用途裏切りを強く非難する。

例She regarded the sale of their secrets as a base betrayal.

訳彼女は、自分たちの秘密を売り渡すことを卑劣な裏切りと見なした。

be base

用途行為の性質を述語で評価する。

例His conduct was base, whatever excuse he offered.

訳どんな言い訳をしたにせよ、彼の振る舞いは卑劣だった。

語法・注意1
  • 限定用法と叙述用法がある。比較は baser、最上級は basest。基礎的なという意味の basic と交換できない。basely は卑劣に、baseness は卑劣さという派生形で、この評価の系列に属する。
類義語2

vile

頻度 5/10

定義道徳的に極めて不快で、嫌悪すべき。

違いbase が品位・動機の低劣さを強調するのに対し、vile は嫌悪感をより前面に出す。

例It was a vile attempt to intimidate a witness.

訳それは、証人を脅そうとする実に卑劣な試みだった。

dishonorable

頻度 4/10

定義名誉や倫理に反する。

違いbase と重なるが、dishonorable は守るべき名誉や行動規範への違反を中心にする。

例The committee condemned his dishonorable conduct.

訳委員会は、彼の不名誉な振る舞いを非難した。

反意語1

noble

頻度 6/10

定義動機や行為が道徳的に立派な。

違い動機・行為の道徳的な高さという評価軸で base と対立する。身分上の貴族という意味とは区別する。

例Her decision was guided by noble motives.

訳彼女の決断は、気高い動機に導かれていた。

語義 12

【形容詞】根拠のない：baseless

頻度 6/10
報道・議論・やや硬い表現。

主張・疑い・告発などに、それを支える事実や理由がない。単にまだ最終的に証明されていないという弱い意味よりも、根拠を欠くと判断する表現である。

文法パターン4
  • baseless allegations
  • a baseless accusation
  • baseless rumors
  • be baseless。
コロケーション・構文例4

baseless allegations

用途申し立てに根拠がないと述べる。

例The company rejected the allegations as baseless.

訳会社は、その申し立てには根拠がないとして退けた。

a baseless accusation

用途非難の根拠の欠如を指摘する。

例A baseless accusation can still damage a person's reputation.

訳根拠のない非難でも、人の評判を傷つけることがある。

baseless rumors

用途裏付けのないうわさを述べる。

例The report helped put an end to the baseless rumors.

訳その報告書は、根拠のないうわさを終わらせる助けになった。

be baseless

用途主張の根拠のなさを述語で示す。

例Their claim proved to be baseless.

訳彼らの主張には根拠がないと判明した。

語法・注意1
  • 発音は /ˈbeɪsləs/。base の土台・根拠の系列に -less が付いた形で、卑しくないという意味ではない。限定・叙述とも可能。baseless と false は同義ではなく、根拠があるかと内容が真実かは別の判断である。
類義語2

unfounded

頻度 6/10

定義疑いなどに確かな根拠がない。

違いbaseless に近い。unfounded fears のように、不安が実情に裏付けられていない場合にもよく使う。

例Her fears turned out to be unfounded.

訳彼女の不安は、取り越し苦労だったと分かった。

unsubstantiated

頻度 5/10

定義証拠による裏付けが示されていない。

違いbaseless よりも、証拠がまだ提示・確認されていないという状態に焦点を置ける。

例The article repeated several unsubstantiated claims.

訳その記事は、裏付けが示されていない主張をいくつも繰り返した。

語義 13

【名詞：可算】野球・ソフトボールの塁、ベース

頻度 6/10
野球・ソフトボール。

走者が進んで踏む塁。野球などの競技で定義される場所・標識を指し、活動拠点という一般義だけから競技上の意味を決めない。

文法パターン6
  • first base
  • second base
  • third base
  • steal a base
  • the bases are loaded
  • on base。
コロケーション・構文例4

first base

用途一塁や一塁への到達を述べる。

例The runner reached first base before the throw arrived.

訳走者は、送球が届く前に一塁に到達した。

steal a base

用途盗塁を述べる。

例She stole a base in the final inning.

訳彼女は、最終回に盗塁した。

the bases are loaded

用途満塁の状態を述べる。

例The bases were loaded with two outs.

訳二死満塁だった。

on base

用途走者が塁に出ていることを述べる。

例There were two runners on base.

訳塁上には二人の走者がいた。

語法・注意1
  • first base のような塁名は通常無冠詞。塁を一つ数える場合は a base とする。home base とも言えるが、野球の本塁の標識は home plate と呼ぶ。基地へ戻る return to base の無冠詞と、野球の塁名の無冠詞を同じ制度上の用法とは考えない。
語義 14

【動詞句・自動詞的】連絡を取る、近況や進捗を確認し合う：touch base

頻度 7/10
くだけたビジネス会話・連絡。

人と短く連絡を取り、近況・状況・次の行動などを確認する。野球からの慣用表現で、実際に触ったり拠点へ移動したりする必要はない。

文法パターン4
  • touch base
  • touch base with someone
  • touch base about something
  • touch base with someone next week。
コロケーション・構文例3

touch base

用途文脈上明らかな相手との連絡を提案する。

例Let's touch base tomorrow after the meeting.

訳明日の会議の後で、また状況を確認し合いましょう。

touch base with someone

用途連絡を取る相手を明示する。

例I need to touch base with our designer before we decide.

訳決める前に、デザイナーと話をしておく必要がある。

touch base about something

用途連絡の話題を明示する。

例We touched base about the delivery schedule this morning.

訳今朝、納品日程について連絡を取り合った。

語法・注意1
  • base はこの句では単数・無冠詞。相手は with の後に置き、touch someone base や touch bases とはしない。進捗確認は典型的な目的だが、毎回正式な報告を交換するとは限らない。受動態を作る句として覚えない。
語義 15

【動詞句・他動詞的】必要な点を漏れなく押さえる：cover all the bases

頻度 6/10
くだけた表現・特に北米のビジネスや日常。

計画や対応に必要な事項・可能性に一通り配慮する。実際に完全無欠であることを証明する語ではなく、漏れを防ぐため広く対処するという慣用表現。

文法パターン3
  • cover all the bases
  • cover all bases
  • cover one's bases。
コロケーション・構文例3

cover all the bases

用途必要な配慮を一通り行う。

例We checked transport, meals, and accessibility to cover all the bases.

訳必要な点を漏れなく押さえるため、交通手段、食事、利用のしやすさを確認した。

cover all bases

用途冠詞を入れない形で、網羅的な準備を述べる。

例The checklist helps new staff cover all bases.

訳そのチェックリストは、新人が必要な点を漏れなく確認する助けになる。

cover one's bases

用途自分側で必要な備えを整える。

例I asked for written confirmation to cover my bases.

訳念のため必要な備えをしておこうと、書面での確認を求めた。

語法・注意1
  • bases は複数形。この慣用義で cover all the base と単数にしない。oneself を直接置くのではなく、my／your／our などの所有格で bases を修飾する。
語義 16

【形容詞句】的外れで、間違って：off base

頻度 5/10
北米・くだけた表現。

推測・評価・発言などが、正しい理解から外れている。人について使う場合は、その人の考えや判断が誤っているという意味になる。

文法パターン3
  • be off base
  • be way off base
  • an off-base assumption。
コロケーション・構文例3

be off base

用途推測や判断が誤っていると述べる。

例Your estimate is off base; the actual cost is much higher.

訳その見積もりは的外れです。実際の費用はもっと高いです。

be way off base

用途大きく見当違いであることを強調する。

例I was way off base when I guessed why she had resigned.

訳彼女が辞めた理由についての私の推測は、大きく外れていた。

an off-base assumption

用途名詞の前で、前提の誤りを指摘する。

例The whole argument rests on an off-base assumption.

訳その議論全体が、誤った前提に立っている。

語法・注意1
  • 叙述では off base、名詞の前では off-base とハイフンを付ける。基地の外で暮らすという字義的な off base とは文脈を分ける。人への直接的な評価になるため、強く言うと相手の判断を否定する響きがある。
語義 17

【動詞句・自動詞的】最初の段階に進む：get to first base

頻度 4/10
くだけた比喩・特に北米。

計画や交渉などで、最初の成果・進展を得る。特に否定文で、初歩の段階にさえ到達できないことを表す。

文法パターン3
  • not get to first base
  • never get to first base
  • not even get to first base with something。
コロケーション・構文例2

not get to first base

用途最初の進展も得られないことを述べる。

例Without a clear budget, the proposal won't get to first base.

訳明確な予算がなければ、その提案は、最初の進展にさえ至らないだろう。

not even get to first base with something

用途何について進展できないかを示す。

例We didn't even get to first base with the negotiations.

訳交渉は、最初の段階にさえ進まなかった。

語法・注意1
  • 一般的な進展の比喩と、野球で一塁に到達する字義を区別する。first base は無冠詞。恋愛の文脈でキスに至ることを表す語義29もあり、with someone があっても業務上の進展とは限らない。
語義 18

【名詞：可算】図形の底辺、底面

頻度 5/10
幾何学・数学教育。

図形の高さなどを考える際の基準となる辺や面。三角形では底辺、角柱・円柱などでは底面と訳す。紙面の下に描かれた部分に限らない。

文法パターン3
  • the base of a triangle
  • a triangular base
  • a circular base。
コロケーション・構文例3

the base of a triangle

用途三角形の底辺を指定する。

例Choose this side as the base of the triangle.

訳この辺を、三角形の底辺として選びなさい。

a triangular base

用途立体の底面の形を述べる。

例The prism has a triangular base.

訳その角柱は、三角形の底面を持つ。

a circular base

用途円形の底面を持つ立体を述べる。

例The cone has a circular base with a radius of three centimeters.

訳その円錐は、半径3センチメートルの円形の底面を持つ。

語法・注意1
  • height は選んだ base に対応する垂直方向の高さ。図を回転させても、指定した辺や面が自動的に別のものへ変わるわけではない。日常の物の底部を表す語義1と関係するが、数学では基準の選び方を含む。
語義 19

【名詞：可算】記数法の基数

頻度 4/10
数学・情報処理。

位取り記数法で、隣り合う位の重みの関係を決める数。十進法は base ten、二進法は base two と表す。

文法パターン4
  • in base ten
  • in base two
  • a base-ten number system
  • convert from base two to base ten。
コロケーション・構文例3

in base ten

用途十進表記であることを示す。

例The answer is written in base ten.

訳答えは十進法で書かれている。

in base two

用途二進表記を指定する。

例Five is written as 101 in base two.

訳5は、二進法では101と書く。

a base-ten number system

用途名詞を修飾して記数法を説明する。

例We normally use a base-ten number system for everyday calculations.

訳日常の計算には、通常十進の記数法を使う。

語法・注意1
  • base ten のような名称は無冠詞。名詞の前に置く複合修飾では base-ten のようにハイフンを使う。二進法の base が2であることと、個々の計算式の累乗の底が2であることは別の話である。
語義 20

【名詞：可算】累乗・対数の底

頻度 4/10
数学。

累乗で何乗するかの対象になる数。また、対数で基準とする数。どちらも数学的な関係の中で base と呼ばれ、記数法の基数とは用途を区別する。

文法パターン3
  • the base and the exponent
  • a logarithm to base ten
  • a logarithm with base two。
コロケーション・構文例2

the base and the exponent

用途累乗の構成部分を区別する。

例In three to the fourth power, the base is three and the exponent is four.

訳3の4乗では、底は3で、指数は4である。

a logarithm to base ten

用途対数の底を示す。

例The logarithm of one hundred to base ten is two.

訳10を底とする100の対数は2である。

語法・注意1
  • base と exponent は同じ計算に使う別の要素で、反意語ではない。対数の to base ten と、十進表記を示す in base ten は前置詞を含めて区別する。
語義 21

【名詞：可算】割合・比較の基準となる数値

頻度 5/10
数量比較・統計・経済の説明。

割合や変化率などを計算するとき、計算の出発点・基準にする量。何を base に採るかで同じ変化の割合も変わるため、基準量を明示する。

文法パターン3
  • use something as a base
  • a base of 100
  • the base for calculating something。
コロケーション・構文例2

use something as a base

用途割合計算の基準値を指定する。

例Use last year's sales as a base when calculating the percentage increase.

訳増加率を計算するときは、前年の売上高を基準にする。

a base of 100

用途指数の基準値を述べる。

例The index uses a base of 100 for the first year.

訳その指数では、初年度の基準値を100としている。

語法・注意1
  • base は、ここでは比率そのものではなく比率を計算する基準量。base year は比較の基準年という複合表現。税務の tax base も課税の基準となる範囲・量を指すが、具体的な算定内容は税の種類や制度によって異なり、常に総収入そのものとは限らない。
語義 22

【名詞：可算】化学の塩基

頻度 5/10
化学・理科教育。

酸に対する化学的な性質で分類される物質。どの酸塩基理論を用いるかによって定義の仕方があり、プロトンを受け取る物質、電子対を供与する物質などとして扱う。

文法パターン4
  • a strong base
  • a weak base
  • act as a base
  • acids and bases。
コロケーション・構文例3

a strong base

用途酸塩基としての強さの分類を述べる。

例The textbook lists sodium hydroxide as a strong base.

訳その教科書は、水酸化ナトリウムを強塩基として挙げている。

a weak base

用途弱塩基という分類を述べる。

例Ammonia is a weak base in water.

訳アンモニアは、水中では弱塩基である。

act as a base

用途反応の中で塩基として働くことを述べる。

例In this reaction, the molecule acts as a base by accepting a proton.

訳この反応では、その分子はプロトンを受け取ることで塩基として働く。

語法・注意1
  • 化学での base を土台と訳さない。alkali は水に溶ける塩基を指す用語として使われるが、base 全体と無条件に同一視しない。strong／weak はこの分類では濃度が高い／低いと同義ではない。物質を味見して判定するという意味の語ではなく、安全性もこの語だけでは分からない。
語義 23

【名詞：可算】核酸を構成する塩基

頻度 4/10
分子生物学・遺伝学。

DNAやRNAを構成する、アデニンなどの塩基部分。配列の説明では A、T、G、C などで表される単位に注目して使う。

文法パターン3
  • a sequence of bases
  • a base pair
  • the order of the bases。
コロケーション・構文例2

a sequence of bases

用途核酸の塩基配列を述べる。

例The diagram shows a short sequence of bases in DNA.

訳その図は、DNA中の短い塩基配列を示している。

a base pair

用途二つの塩基の対を述べる。

例The illustration highlights one base pair in the DNA molecule.

訳その図解では、DNA分子の一つの塩基対が強調されている。

語法・注意1
  • base と nucleotide は完全な同義語ではない。ヌクレオチドは塩基だけでなく糖・リン酸部分も含む。base pair を塩基が一個という意味で数えない。ここでは語彙上の区別を述べており、配列だけから病気や性質を判断できるという含意はない。
語義 24

【名詞：可算】語形成の基体

頻度 3/10
言語学・語形成。

接辞などを付けて新しい語形・語を作る際に、その操作の土台となる形。すでに接辞を含んだ形が、次の操作の base になることもある。

文法パターン3
  • attach a suffix to a base
  • a complex base
  • the base of a derived word。
コロケーション・構文例2

attach a suffix to a base

用途接尾辞を付ける対象を説明する。

例We attach the suffix -ness to the base happy to form happiness.

訳基体のhappyに接尾辞-nessを付けて、happinessを作る。

a complex base

用途内部構造を持つ基体を述べる。

例A complex base may already contain an affix.

訳複合的な基体は、すでに接辞を含んでいることがある。

語法・注意1
  • base を必ずそれ以上分けられない root と同一視しない。root は語根、stem は語幹という説明に使われるが、用語の範囲には分析上の差もある。上の例では綴りが happy から happi- に変わる点も区別する。
語義 25

【形容詞：主に限定】貴金属でない、品位の低い：base metal

頻度 4/10
金属・工業。純度の低さを表す用法は古い記述にも見られる。

金属について、貴金属ではないことを表す。また、古い記述などでは純度・品質が低い金属という意味でも用いる。人の道徳的評価ではなく、金属の価値・性質に関する系列である。

文法パターン3
  • base metals
  • a base metal
  • coins of base metal。
コロケーション・構文例2

base metals

用途貴金属ではない金属類を述べる。

例The chapter distinguishes precious metals from base metals.

訳その章は、貴金属と卑金属を区別している。

a base metal

用途金属の分類を示す。

例Copper is classified as a base metal rather than a precious metal.

訳銅は、貴金属ではなく卑金属に分類される。

語法・注意1
  • 卑金属という訳の卑は、人間への侮辱を意味しない。現代の分類で base metal と呼ばれるからといって、必ず不純物が多いわけではない。
語義 26

【名詞：可算】トランジスタのベース

頻度 3/10
電子工学。

バイポーラトランジスタで、エミッタ・コレクタと区別される部分や端子を指す専門語。

文法パターン3
  • the base of a transistor
  • the base terminal
  • base current。
コロケーション・構文例2

the base terminal

用途回路部品の端子を特定する。

例The diagram labels the base terminal with the letter B.

訳その図では、ベース端子にBという文字が付いている。

base current

用途ベースに関係する電流の名称を示す。

例The graph shows how the collector current changes with the base current.

訳そのグラフは、ベース電流に応じてコレクタ電流がどう変わるかを示している。

語法・注意1
  • 全ての種類のトランジスタに base という端子があるわけではない。ここでは部品の下側という一般義ではなく、部品構造における固有の名称として読む。
語義 27

【形容詞：based】人の目に左右されず、自分らしくある

頻度 3/10
英語圏の俗語・オンライン文化。

他人の評価を恐れず、自分の個性や信念を保っていることを好意的に述べる俗語。通常の based on の分詞とは別の語彙的な意味として読む。

文法パターン2
  • stay based
  • be based。
コロケーション・構文例1

stay based

用途自分らしさを保つことを、俗な言い方で勧める。

例Stay based—don't change your style just to please the crowd.

訳自分らしくいこう。みんなに気に入られようとして、自分のスタイルを変えないで。

語法・注意1
  • /beɪst/ と1音節で発音する。on 以下の根拠を省略しただけの形とは限らない。使用する集団や文脈に依存する評価語で、正式な人物評に一般化しない。次の語義28では、自分らしさよりも発言などへの賛同・称賛が前面に出る。
語義 28

【形容詞：based】いいね、支持できる、称賛に値する

頻度 5/10
インターネットの俗語・冗談を含む非常にくだけた表現。

意見・行動などを支持し、格好いい・よく言ったと評価するネット上の俗語。周囲に迎合しない意見への称賛にも使うが、客観的に正しいという認定ではない。

文法パターン3
  • that's based
  • a based take
  • be pretty based。
コロケーション・構文例2

that's based

用途相手の意見などを肯定的に評価する。

例You told them to give everyone a proper break? That's based.

訳みんなにちゃんと休憩を取らせるよう言ったの？ それはよく言ったね。

a based take

用途自分が支持する意見を俗な言い方で称賛する。

例Several commenters called her view on the redesign a based take.

訳コメントした何人かは、デザイン変更に関する彼女の意見を、支持できるいい意見だと評した。

語法・注意1
  • That's based. は That is based on evidence. と違い、根拠を示す on 以下を必要としない。限定用法では a based take のように使える。この俗語だけで話者の政治的立場を決めつけない一方、どの意見に賛同しているかは文脈で読む。丁寧な業務文書では避ける。
語義 29

【名詞句：単数・慣用的に無冠詞】キスに至る段階：first base

頻度 3/10
特に米国のくだけた会話・恋愛をスポーツにたとえる俗語。

恋愛的・性的な進展を野球の塁にたとえ、キスに至る段階を指す俗な表現。業務上の最初の進展を表す語義17とは対象が異なる。

文法パターン2
  • get to first base with someone
  • not get past first base。
コロケーション・構文例1

get to first base with someone

用途キスをする段階に進んだことを、俗な比喩で述べる。

例He said he'd got to first base with his date, meaning they had kissed.

訳彼は、デート相手とキスをしたという意味で、一塁まで進んだと言った。

語法・注意1
  • 相手を with の後ろに置く。この比喩の段階を普遍的な恋愛の手順や、相手の同意の有無の説明として扱わない。競技の点取りにたとえる言い方を不快に感じる人もいるため、相手や場面を選ぶ。
