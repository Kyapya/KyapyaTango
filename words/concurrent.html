ENGLISH–JAPANESE EXTRA

concurrent

主要語義 7更新 2026-10-10

発音記号

米: /kənˈkɜːr.ənt/｜英: /kənˈkʌr.ənt/。3音節で、第2音節に主強勢を置く。示した米英差は第2音節の母音で、米音では /ɜːr/、英音では /ʌr/。英音でも r の後に第3音節の母音が続くため、この位置の r は発音する。第1・第3音節の母音はどちらも /ə/。

コアイメージ

「複数のものが、共通する時間・対象・方向・地点で一緒になる」というイメージ。時間が重なるのか、権限の範囲や判断が重なるのか、線が一点で交わるのかを、修飾する名詞から読み分ける。

  • 一緒になる範囲が、出来事の進行期間 → 「同時に起こる・同じ時期に進む」（語義1）
  • 一緒になる範囲が、複数処理の進行期間 → 「並行して進行する」（語義2）
  • 一緒になる範囲が、複数機関の権限対象 → 「管轄・権限が競合・併存する」（語義3）
  • 一緒になる範囲が、結果へ向かう作用 → 「共同して作用する」（語義4）
  • 一緒になる範囲が、判断や意見の内容 → 「判断・意見などが一致する」（語義5）
  • 一緒になる範囲が、直線の通る一点 → 「共通の一点で交わる」（語義6）
  • 一緒になる範囲が、保険契約の補償対象 → 「同じ対象・リスクに補償が重なる」（語義7）

語源

  • ラテン語 concurrere「一緒に走る・集まる・同時に存在する」の現在分詞 concurrens に由来する。con-「一緒に」と currere「走る」がもとになっている。
  • concur「意見が一致する・同時に起こる」は同じ語族。current「流れ・現在の」と course「進路」も、歴史的に currere とつながる。ただし concurrent は current に con- を付けて「現在の何か」と機械的に訳す語ではない。

語形成

concurrently副詞「同時に・並行して」。The two projects run concurrently.「二つの事業は同時期に進む」のように動詞を修飾する。concurrently with another project で並行する相手を示す。
concurrency名詞「同時性・並行性」。特に情報技術で、複数の処理を並行して進める性質を表す。並列実行だけを意味するとは限らない。
concurrence名詞「意見の一致・同意」、または「同時発生」。法務での同意・一致などにも使う。concurrency と語族は共通するが、現代の定型的な使い道は同一でない。
concur動詞「同意する・意見が一致する」。I concur with your assessment.「あなたの評価に同意する」のように使う。通常の人物主語で I am concurrent with you. と置き換えない。

語義 1

【形容詞・限定／叙述】同時に起こる・同じ時期に進む

頻度 6/10
ややフォーマル。業務、日程、報道、法律。会話では at the same time もよく使う。

複数の出来事・活動・状態が、同じ時に存在する、または進行期間を重ねている。開始と終了が完全に一致することまでは必要としない。同時進行していること自体を述べ、因果関係や相互協力を必ずしも意味しない。

文法パターン4
  • concurrent 〈projects/events/sessions〉＝同時期に進む事業・行事・セッション
  • A + be concurrent with B＝AがBと同時期にある
  • concurrent with 〈出来事〉＝その出来事と並行して
  • concurrent sentences / terms＝同時に服する複数の刑期。
コロケーション・構文例5

concurrent projects

用途複数の事業が同じ期間に進んでいることを述べる。

例She is responsible for three concurrent projects with different deadlines.

訳彼女は、締め切りの異なる三つの事業を同時に担当している。

concurrent sessions

用途会議の複数のセッションが同時に行われることを示す。

例The conference offers four concurrent sessions each afternoon.

訳その学会では、毎日午後に四つのセッションが同時に行われる。

be concurrent with something

用途同時期に進む相手を with で示す。

例The staff training will be concurrent with the system upgrade.

訳スタッフ研修は、システム更新と並行して行われる。

concurrent with 〈出来事〉

用途文頭の形容詞句で、時期の重なりを説明する。

例Concurrent with the exhibition, a series of public lectures will take place.

訳展示会と並行して、連続公開講座が開催される。

concurrent sentences

用途複数の自由刑を同時に服することを表す法律用語。

例The judge imposed concurrent sentences of five years and three years.

訳裁判官は、同時に服する5年と3年の刑を言い渡した。

語法・注意1
  • concurrent は形容詞で、The projects are concurrent. または concurrent projects とする。動詞 run を副詞で修飾するなら The projects run concurrently. が基本。run concurrent も文脈によって補語として現れるが、単純な副詞のつもりで -ly を落とさない。with は並行する相手を示し、be concurrent with the audit とする。very concurrent は通常の程度表現として使わず、期間の重なりを強調するなら fully concurrent、partly concurrent などで関係を明示する。more concurrent projects は通常「同時進行する事業の数がより多い」で、個々の事業が「より同時」であるという意味ではない。consecutive「一つの後に次が続く」、continuous「途切れず続く」とは別の軸。concurrent sentences は刑期を単純に足す制度用語ではない。同時に始まる5年と3年の刑なら、通常は長い5年が基準となるが、実際の収容期間・開始日・控除などは判決と適用法による。
類義語3

simultaneous

頻度 6/10

定義同じ時に起こる、または存在する。

違い同一時点で起きることを強調しやすい。concurrent は期間の重なる業務や過程にもよく使い、開始・終了の一致を必要としない。simultaneous も文脈によって一定の期間を扱う。

例The audience heard simultaneous translations in three languages.

訳聴衆には3言語の同時通訳が提供された。

parallel

頻度 6/10

定義別々の活動が並行して進む。

違い時期の重なりに加え、活動が別立て・対応関係にあることを示しやすい。物理的な平行という意味とは区別する。

例The two agencies conducted parallel investigations.

訳二つの機関が並行して別々の調査を行った。

contemporaneous

頻度 3/10

定義同じ時期に存在・発生する。

違い歴史的な出来事や記録の時期を比較するフォーマルな語。concurrent より、現在進行中の複数業務を管理する文脈には使いにくい。

例The archive contains several contemporaneous accounts of the fire.

訳その記録保管所には、火災と同じ時期に書かれた記録がいくつもある。

反意語2

consecutive

頻度 6/10

定義途中に別のものを挟まず、順に続く。

違い活動や刑期を同時に進めるか、一つの後に次を置くかという時間配置の対立。

例The workshops were held on three consecutive days.

訳研修会は3日間連続で開催された。

sequential

頻度 4/10

定義一定の順序に従って、一つずつ続く。

違い同時進行か順次進行かの対立。consecutive より、工程や処理の順序に焦点を置きやすい。

例The plan divides the work into sequential stages.

訳その計画は、作業を順に進む段階に分けている。

語義 2

【形容詞・限定／叙述】並行して進行する

頻度 5/10
情報技術、システム仕様、ソフトウェアライセンス。一般の時間的同時性を、処理・利用の観点で区別する専門用法。

コンピューターで、複数の処理・要求などが、ある期間内に並行して進行していることを表す。各処理を短い間隔で切り替えて進める場合も含み、常に同じ瞬間に複数の命令を実行しているとは限らない。利用者・接続数については、同時に利用中・接続中であることを指す。

文法パターン4
  • concurrent execution / processing＝並行実行・並行処理
  • concurrent tasks / requests＝並行して進むタスク・要求
  • concurrent users / connections＝同時利用者・同時接続
  • 〈処理〉 + be concurrent＝処理が並行している。
コロケーション・構文例5

concurrent execution

用途実行を切り替えながら複数処理を進める場合も含むことを示す。

例Concurrent execution is possible on a single processor by switching between tasks.

訳タスクを切り替えることで、単一のプロセッサーでも並行実行が可能である。

concurrent requests

用途システムが同じ期間に処理する要求を数える。

例The server limits the number of concurrent requests to prevent overload.

訳サーバーは過負荷を防ぐため、同時処理する要求の数を制限している。

concurrent users

用途登録者総数ではなく、同時に使う人数を示す。

例The license allows up to fifty concurrent users.

訳そのライセンスでは、最大50人まで同時に利用できる。

concurrent connections

用途同時に有効な接続数を示す。

例The dashboard displays the current number of concurrent connections.

訳ダッシュボードには、現在の同時接続数が表示される。

be concurrent

用途複数処理の関係を叙述する。

例The two operations are concurrent, so their shared data requires careful coordination.

訳二つの処理は並行して進むため、共有データの扱いを慎重に調整する必要がある。

語法・注意1
  • 一般的な区別では concurrent は複数処理が進行中であること、parallel は複数の処理資源で同じ瞬間に実行することに焦点がある。並列実行は並行実行の一形態になり得るが、単一プロセッサーでの切り替え実行まで parallel と断定しない。分野・製品が独自に定義する場合はその説明に従う。concurrent users は利用時間が重なる人の数であり、登録済みユーザー総数やCPUが同一瞬間に実行する命令数ではない。asynchronous「非同期」は待ち合わせ・応答の扱いに関する別の性質で、concurrent の単純な同義語・反意語ではない。
類義語1

parallel

頻度 5/10

定義複数の処理を異なる処理資源で同時に実行する。

違いconcurrent と重なるが、一般的な専門上の区別では実際の同時実行を表す点で狭い。すべての並行処理を parallel と言い換えない。

例The calculation uses parallel processing across four cores.

訳その計算は、4コアにわたる並列処理を利用している。

反意語2

sequential

頻度 4/10

定義一つの処理を終えてから次へ進む。

違い複数の処理を並行して進めるか、順に進めるかという実行方式の対立。

例Sequential execution made it easier to reproduce the error.

訳順次実行にすると、エラーを再現しやすくなった。

serial

頻度 4/10

定義処理を一つずつ順に行う。

違いこの処理方式の意味では concurrent と対立する。ただし serial port など、データ伝送方式の用語まで同じ対立として扱わない。

例The tasks use serial execution because each depends on the previous result.

訳各タスクは前の結果に依存するため、順次実行される。

語義 3

【形容詞・主に限定用法】管轄・権限が競合・併存する

頻度 3/10
法律、行政、政治制度。

同じ種類の事件・事項・地域について、複数の裁判所や公的機関などが権限を持っていることを表す。権限の範囲が重なることが中心で、実際に二つの機関が同時に同じ事件を処理していることまでは意味しない。

文法パターン3
  • concurrent jurisdiction over 〈事件・事項〉＝その対象への競合的管轄権
  • have concurrent jurisdiction with 〈別の裁判所〉＝別の裁判所と管轄権を共有する
  • concurrent powers＝複数の政府・機関が併存して持つ権限。
コロケーション・構文例3

concurrent jurisdiction over something

用途管轄の重なる対象を示す。

例The statute gives both courts concurrent jurisdiction over this category of claims.

訳その法律は、この種の請求について両裁判所に競合的な管轄権を与えている。

have concurrent jurisdiction with 〈裁判所〉

用途権限が重なる別の裁判所を with で示す。

例For these claims, the local court has concurrent jurisdiction with the specialist tribunal.

訳これらの請求については、地方裁判所は専門審判機関と管轄権を共有している。

concurrent powers

用途複数の政府などに共通して認められる権限を表す。

例The chapter compares the exclusive and concurrent powers of the two levels of government.

訳その章は、二つの政府レベルの専属的権限と併存する権限を比較している。

語法・注意1
  • concurrent jurisdiction は「同時に開廷している裁判所」ではなく、判断する権限の重なりを表す。対象は over、権限を共有する相手は with で示す。have concurrent jurisdiction with another court と be concurrent with another event「別の行事と時期が重なる」は構造・意味が異なる。制度上、どちらへ提訴できるか、移送や優先順位がどうなるかは適用法による。「二つが共同で一つの判決を出さなければならない」とも限らない。叙述形として Their jurisdiction is concurrent. も可能だが、通常は jurisdiction / powers などの前で使い、程度比較はしない。
類義語2

shared

頻度 6/10

定義権限・責任などが複数の主体に共通して属する。

違い一般語で、法的な管轄の競合や独立の行使可能性まで精密に規定する語ではない。文脈を補えば concurrent の概念を説明できる。

例The agreement establishes shared responsibility for inspections.

訳その合意は、検査に関する責任を共同で負うと定めている。

overlapping

頻度 4/10

定義権限や担当範囲の一部が重なっている。

違い重なりの存在を一般的に述べ、正式な法的分類名ではない。重なりが全面的か部分的かも文脈による。

例The agencies have overlapping responsibilities for environmental monitoring.

訳各機関の環境監視に関する担当範囲は、一部重なっている。

反意語1

exclusive

頻度 4/10

定義ある権限・管轄が一つの機関などだけに属する。

違い同じ対象について権限を複数主体が持つか、一主体だけが持つかという配分の対立。

例The law grants that court exclusive jurisdiction over these disputes.

訳その法律は、これらの紛争について当該裁判所に専属的な管轄権を与えている。

語義 4

【形容詞・主に限定用法】共同して作用する

頻度 2/10
フォーマル。論説、因果関係の分析、法律。

複数の力、原因、活動などが一緒に働いて、一つの結果や目的に関わる。人が意図的に協力する場合にも、複数の原因が合わさる場合にも使う。

文法パターン2
  • the concurrent efforts of 〈複数の主体〉＝複数主体の共同の取り組み
  • concurrent causes of something＝ある結果に共同して作用した原因。
コロケーション・構文例2

the concurrent efforts of 〈複数の主体〉

用途複数の主体の働きが合わさることを表す。

例The rescue depended on the concurrent efforts of local crews and outside specialists.

訳救助は、地元の隊員と外部の専門家が力を合わせて初めて成り立った。

concurrent causes of something

用途複数の要因が同じ結果に寄与することを示す。

例The report identified corrosion and excessive load as concurrent causes of the collapse.

訳その報告書は、腐食と過大な荷重がともに崩壊の原因となったと指摘した。

語法・注意1
  • この用法では、同時刻に存在するというだけでなく、働きや効果が合わさることに焦点がある。concurrent causes は法務・保険にも現れるが、各原因が単独で結果を生む必要があるか、損害の補償対象になるかなどは、適用される法や契約を確認する。語だけから一律に決めない。原因には意思がないため、「共同して作用する」を必ず「協力しようとする」と読み替えない。通常は名詞の前で使い、very concurrent のような程度評価には向かない。
類義語2

joint

頻度 6/10

定義複数の主体が共同で行う、または共同で関わる。

違い共同の行為・責任・成果に広く使う。concurrent はそれぞれの作用が合わさることに焦点を置ける。

例The two organizations launched a joint effort to restore the river.

訳二つの団体は、川の再生に向けて共同の取り組みを始めた。

combined

頻度 6/10

定義複数の要素や働きを合わせた。

違い合わさった総体・効果に焦点を置く。concurrent のように同時性やそれぞれの並存を前面に出すとは限らない。

例The combined effects of heat and pressure damaged the seal.

訳熱と圧力が重なって作用し、密閉部を傷めた。

語義 5

【形容詞・主に限定用法】判断・意見などが一致する

頻度 2/10
フォーマル、法律、文語的な論述。日常なら agreeing や consistent などで説明することが多い。

複数の判断、意見、証言などが、内容や結論の点で一致している。同じ時刻に出されたという意味ではない。

文法パターン3
  • concurrent findings of 〈複数の裁判所など〉＝複数の判断主体による一致した認定
  • concurrent testimony＝内容の一致する証言
  • a concurrent resolution＝米国議会などで両院の合意を要する決議。
コロケーション・構文例3

concurrent findings of fact

用途異なる裁判所の事実認定が一致していることを述べる。

例The appeal challenged the concurrent findings of fact made by the two lower courts.

訳その上訴は、二つの下級裁判所による一致した事実認定に異議を唱えた。

concurrent testimony

用途別々の証言の内容が一致することを述べる。

例The witnesses' concurrent testimony placed the vehicle outside the warehouse before dawn.

訳証人たちの一致した証言によれば、その車両は夜明け前に倉庫の外にあった。

a concurrent resolution

用途米国議会の決議形式の一つを示す。

例Both chambers adopted a concurrent resolution setting the congressional budget framework.

訳両院は、議会の予算枠組みを定める両院一致決議を採択した。

語法・注意1
  • concurrent findings は内容の一致であり、二つの裁判所が同時に審理していることを示さない。concurrent jurisdiction（語義3）は権限の重なりで、判断内容の一致を保証しない。米国議会の concurrent resolution は両院で同一の形で可決する形式で、大統領の署名に付さず、法律としての効力を持つものではない。ただし予算枠組みや議会内部の運営などに使われるため、「何の実務的効果もない」とは言えない。joint resolution は別の形式なので、joint が類義的でも用語をそのまま置換しない。人の同意なら I concur. / I agree. が普通で、I am concurrent. を基本表現にはしない。
類義語2

consistent

頻度 6/10

定義複数の説明・判断などが互いに矛盾しない。

違いconcurrent の一致より弱く、細部まで同じでなくても矛盾しなければ consistent と言える。

例The witnesses gave consistent accounts of the sequence of events.

訳証人たちは出来事の順序について、互いに矛盾しない説明をした。

concordant

頻度 2/10

定義内容・結果・見解などが一致している。

違い学術的・専門的で、研究結果や検査結果の一致にも使う。concurrent の時間的な同時性の意味は通常含まない。

例The two independent analyses produced concordant results.

訳二つの独立した分析は、一致する結果を示した。

反意語2

conflicting

頻度 6/10

定義内容・結論などが互いに食い違う。

違い判断や証言の一致・不一致という同じ意味軸上で対立する。

例The inquiry received conflicting accounts of the incident.

訳調査には、その出来事について食い違う説明が寄せられた。

contradictory

頻度 4/10

定義互いに両立せず、一方が他方を否定する。

違い単なる差より強い論理的な矛盾を表す。一致する concurrent と、内容の整合性という軸で反対。

例The report contains contradictory conclusions about the cause.

訳その報告書には、原因について互いに矛盾する結論が含まれている。

語義 6

【形容詞・限定／叙述】共通の一点で交わる

頻度 2/10
数学・幾何。力学では、作用線が一点に集まる concurrent forces にも使う。

幾何で、複数の直線などが一つの共通点を通ることを表す。特に3本以上の直線に共通の交点があることを述べるときに学習価値が高い。時間的な「同時」ではない。

文法パターン3
  • concurrent lines＝一点で交わる直線
  • 〈複数の直線〉 + be concurrent at 〈点〉＝その点で交わる
  • concurrent forces＝作用線が共通の一点を通る力。
コロケーション・構文例3

concurrent lines

用途共通の交点を持つ複数の直線を表す。

例Draw three concurrent lines through point P.

訳点Pを共通の交点とする3本の直線を引きなさい。

be concurrent at 〈点〉

用途共通の交点を at で示す。

例The three medians of a triangle are concurrent at its centroid.

訳三角形の3本の中線は、その重心で交わる。

concurrent forces

用途力の作用線が一点で交わる関係を表す。

例In the diagram, the three concurrent forces have lines of action passing through point O.

訳図では、3つの力の作用線が点Oを通っている。

語法・注意1
  • 3本の直線が二つずつ交わるだけでは concurrent とは限らない。3本すべてが同じ一点で交わる必要がある。at point P が交点を示し、concurrent with an event の with が示す時間的な比較とは異なる。parallel「平行」は共通の交点を持たない関係だが、3本以上では「平行でない」だけで concurrent になるわけではないため、単純な二者択一として覚えない。concurrent はこの用法では通常、程度比較しない。
類義語1

intersecting

頻度 3/10

定義互いに交わっている。

違いconcurrent より条件が緩く、複数の交点で交わる場合にも使う。3本以上で一つの共通点があることを述べるには concurrent が正確。

例Three intersecting lines can form a triangle.

訳3本の交わる直線は、三角形を作ることがある。

語義 7

【形容詞・限定／叙述】同じ対象・リスクに補償が重なる

頻度 2/10
保険契約、リスク管理、損害査定。

保険で、複数の契約が同じ財産・リスクを補償し、対象や条件が所定の基準で一致・対応していることを表す。何が一致していれば concurrent と呼ぶかは保険分野・資料によって異なり、同じ時期に有効であることだけで決まる語ではない。

文法パターン3
  • concurrent policies＝補償対象・条件が対応する複数の保険契約
  • concurrent insurance＝同じ対象・リスクに重なる保険
  • 〈複数の保険契約〉 + be concurrent＝その基準で対象・条件が対応している。
コロケーション・構文例3

concurrent fire policies

用途同じ財産・危険を補償する契約の関係を示す。

例The broker confirmed that the concurrent fire policies covered the same factory against the same perils for the same period.

訳仲介業者は、それらの火災保険契約が、同じ期間に同じ工場の同じ危険を補償していると確認した。

concurrent insurance

用途複数の契約の補償内容・期間などを整合させる文脈を示す。

例The review checked whether the primary and excess policies provided concurrent insurance.

訳その見直しでは、第一次保険と超過損害を補償する保険の対象・期間などが整合しているかを確認した。

the policies + be concurrent

用途契約同士の関係を叙述する。

例For the contribution calculation, the policies were treated as concurrent because they insured exactly the same property.

訳保険者間の負担額の計算では、まったく同じ財産を補償していたため、それらの契約は補償対象が一致するものとして扱われた。

語法・注意1
  • policy はここでは方針ではなく「保険契約」。保険金の分担を論じる資料には、対象財産が同一なら concurrent、一部だけが共通なら non-concurrent と区別するものがある。一方、リスク管理の用語では、同じリスク、保険期間、補償が発動する契機の種類が一致することを重視する説明もある。したがって「すべての条件が必ず完全一致」「期間が少しでも重なればよい」のどちらにも一律に固定しない。保険金の分担割合、優先順位、受取額が倍になるかどうかは、この形容詞だけでは決まらず、契約と適用法を確認する。通常は分類・対応関係として使うため、very concurrent のような程度評価はしない。
類義語1

overlapping

頻度 3/10

定義補償範囲などが互いに重なっている。

違い一部の重なりにも使う一般的な表現。concurrent が同一対象・同一条件などの一致を要求する用語法では、overlapping と無条件に置き換えられない。

例The adviser identified overlapping coverage in the two policies.

訳助言担当者は、二つの保険契約で補償が重なっている部分を指摘した。

反意語1

non-concurrent

頻度 1/10

定義保険契約の対象・条件が、所定の基準では一致していない。

違い同じ分類基準における一致・不一致の対立。補償期間が別々であるという意味だけに限らない。

例The manual classifies policies covering only partly identical property as non-concurrent.

訳その手引きは、補償対象の財産が一部しか共通しない契約を、補償対象が一致しない契約に分類している。

該当する語義・用例がありません。
