ENGLISH–JAPANESE EXTRA

instruction

主要語義 6更新 2026-10-13

発音記号

米・英: /ɪnˈstrʌk.ʃən/

  • 3音節で、第2音節に主強勢を置く。第2音節の母音は /ʌ/、第3音節は弱い /ə/。複数形 instructions は末尾に /z/ を加え、/ɪnˈstrʌk.ʃənz/ となる。

コアイメージ

核は「何をどうするか、理解・行動のために教え示すこと」。示された内容を数える用法と、教える行為を不可算で述べる用法を分ける。

  • 実施方法を教え示す説明 → 「手順の説明、使用上の指示」（語義1）
  • すべき行動を教え示す内容 → 「指示、命令」（語義2）
  • 知識や技能を教え示す行為 → 「指導、教授、教育」（語義3）
  • 実施方法を教え示すための性質 → 「使用法・手順を説明するための」（語義4）
  • 計算機の処理を教え示す命令 → 「コンピューターの命令」（語義5）
  • 弁護士の対応を教え示す依頼内容 → 「弁護士への指示、依頼内容」（語義6）

語源

  • 中英語後期に、古フランス語を経て後期ラテン語 instructio に由来する形が入った。もとはラテン語 instruere「組み立てる、備える、教える」で、in- と struere「積み上げる、組み立てる」から成る。
  • structure「構造」と construct「組み立てる」も struere の系列に属する。教える意味を「知識を組み立てて与える」と結びつけるのは記憶の補助になるが、現在の instruction が必ず段階的な積み上げ学習を指すわけではない。

語形成

instruct他動詞。「指示する、教える」。instruct someone to do は行為の指示、instruct someone in a subject は分野の指導。
instructor可算名詞。「指導者、講師」。実技・技能の指導をする人にもよく使う。
instructional形容詞。「教育・指導用の」。instructional materials は教材。
instructive形容詞。「参考になる、学ぶところのある」。an instructive mistake は教訓になる失敗で、指示を与える失敗という意味ではない。
instructions個々の指示や手順の説明を表す複数形。不可算の「指導」を単純に複数化したものとは限らない。

語義 1

【名詞・通常複数形】手順の説明、使用上の指示

頻度 9/10
一般・製品説明・業務手順。

物を使う、組み立てる、手続きを進めるなどのために、どうすればよいかを示した説明。通常 instructions で一まとまりの手順を表す。印刷物だけでなく、画面・動画・口頭で伝えられる説明にも使う。

文法パターン8
  • instructions on how to do＝その行為の方法を示す説明
  • instructions for doing＝その作業をするための手順
  • instructions for use＝使用上の説明
  • follow the instructions＝説明どおりに行う
  • read the instructions＝説明を読む
  • according to the instructions＝説明に従って・説明によると
  • a set of instructions＝一まとまりの手順説明
  • step-by-step instructions＝段階を追った手順説明。
コロケーション・構文例8

instructions on how to do

用途何の方法を説明しているかを示す。

例The website provides instructions on how to reset the device.

訳そのウェブサイトには、機器をリセットする方法の説明がある。

instructions for doing

用途実施する作業を示す。

例The package contains instructions for assembling the shelf.

訳包装の中には、棚の組み立て方の説明が入っている。

instructions for use

用途製品の使用方法をまとめて指す。

例Keep the instructions for use with the equipment.

訳使用上の説明書は、機器と一緒に保管してください。

follow the instructions

用途示された方法どおりに作業することを述べる。

例Follow the instructions on the screen to complete the setup.

訳画面上の指示に従って、設定を完了してください。

read the instructions

用途作業前などに手順を読むことを述べる。

例I read the instructions twice before connecting the cables.

訳私はケーブルを接続する前に、説明を2回読んだ。

according to the instructions

用途説明を情報源または作業の基準として示す。

例According to the instructions, the filter can be washed with water.

訳説明によると、フィルターは水洗いできる。

a set of instructions

用途複数の手順を一まとまりとして数える。

例Each kit includes a complete set of instructions.

訳各キットには、一式の説明が付いている。

step-by-step instructions

用途順に進められる説明であることを示す。

例The guide offers step-by-step instructions for creating an account.

訳そのガイドには、アカウント作成の手順が順を追って説明されている。

語法・注意1
  • 一冊・一枚の説明書でも、その内容を指すなら the instructions が自然。These instructions are clear. と複数扱いにする。一つの操作・指示を取り出す an instruction は可能だが、説明書一冊を必ず an instruction と呼ぶわけではない。冊子そのものなら an instruction manual、a booklet of instructions などとする。on how to use the machine の on は説明内容、on the screen の on は表示場所で、同じ前置詞でも役割が異なる。instructions for use は名詞句、instructions to stop work は語義2の行為を命じる内容になりやすい。
類義語3

directions

頻度 8/10

定義何かを行うための方法・手順の説明。

違いこの意味では instructions と広く重なる。directions には道順という一般的な別義もある。

例The directions explain how to mix the powder with water.

訳その説明には、粉を水と混ぜる方法が書かれている。

guidelines

頻度 8/10

定義行動や作業の方針となる指針。

違い個々の操作手順より、判断・実施の基準を示しやすい。ただし、単語だけで拘束力の強弱が必ず決まるわけではない。

例The guidelines cover the safe storage of materials.

訳その指針は、資材の安全な保管について扱っている。

procedure

頻度 8/10

定義ある作業を進めるための定められた手順。

違い行う順序や方法そのものを指す。instructions は、その手順を人に伝える説明に焦点がある。

例The procedure involves checking each reference number.

訳その手順には、各参照番号を確認する作業が含まれる。

語義 2

【名詞・可算・通常複数形】指示、命令

頻度 8/10
一般・業務・組織内の連絡。

誰かが相手に、何をする・しないようにと伝えた指示。単なる提案より従うことが期待されるが、軍事的な強い命令や法的に拘束される指示だけに限らない。

文法パターン10
  • instructions to do＝その行為をするようにという指示
  • instructions not to do＝その行為をしないようにという指示
  • instructions that 〈主語〉 + 〈動詞の原形〉＝その内容を実行するよう求める指示
  • instructions that 〈主語〉 should do＝その内容を実行するよう求める指示
  • instructions from someone＝その人からの指示
  • instructions to someone＝その人に対する指示
  • be under instructions to do＝そうするよう指示を受けている
  • on someone's instructions＝その人の指示に基づいて
  • carry out someone's instructions＝その人の指示を実行する
  • await further instructions＝次の指示を待つ。
コロケーション・構文例10

instructions to do

用途指示された行為を不定詞で示す。

例We received instructions to suspend the inspection.

訳私たちは、検査を一時中断するよう指示を受けた。

instructions not to do

用途禁止された行為を示す。

例The staff had instructions not to disclose the access code.

訳職員は、アクセスコードを明かさないよう指示を受けていた。

instructions that 〈主語〉 + 〈動詞の原形〉

用途求める行為を that 節で明示する。

例The director left instructions that every visitor be registered.

訳責任者は、訪問者を全員登録するよう指示を残した。

instructions that 〈主語〉 should do

用途should を用いて指示の内容を示す。

例She gave instructions that the files should remain in the office.

訳彼女は、ファイルを事務所に置いたままにするよう指示した。

instructions from someone

用途指示を出した人を示す。

例The instructions from the supervisor were clear.

訳上司からの指示は明確だった。

instructions to someone

用途指示を受ける人を示す。

例His instructions to the drivers included a change of route.

訳運転手たちに対する彼の指示には、経路の変更が含まれていた。

be under instructions to do

用途すでに指示を受けた立場であることを述べる。

例I am under instructions to refer all questions to the coordinator.

訳私は、質問はすべて調整担当者に回すよう指示されている。

on someone's instructions

用途行動の根拠がその人の指示であることを示す。

例We closed the loading area on the manager's instructions.

訳私たちは、管理者の指示で荷積み区域を閉鎖した。

carry out someone's instructions

用途指示されたことを実際に行う。

例The team carried out her instructions to the letter.

訳チームは、彼女の指示を細部まで忠実に実行した。

await further instructions

用途続きの指示を待つことを述べる。

例The crew stopped work and awaited further instructions.

訳作業員たちは仕事を止め、次の指示を待った。

語法・注意1
  • 個々の指示は an instruction、複数は instructions。from は発信元、to someone は宛先、to do は内容で、an instruction from the manager to the staff to lock the door のように役割が異なる。命令・要求を表す that 節では原形や should を使い、be registered の be は過去時制へのそろえ忘れではない。原形は特に米語で一般的だが、英国でも使われる。under instructions to do は「するよう指示されて」、語義3の under instruction は「指導を受けて」。await は目的語を直接取り、await for instructions ではなく await instructions または wait for instructions とする。
類義語3

order

頻度 9/10

定義権限のある者が従うように出す命令。

違い命令としての強さや権限を前面に出しやすい。instruction は仕事上の具体的な指示にも広く使う。

例The officer gave an order to leave the building.

訳その将校は、建物から出るよう命令した。

directive

頻度 6/10

定義組織などが出す正式な指示・指令。

違い政策・管理上の正式さを帯びる。instruction は個人間の具体的な指示にも使える。

例The agency issued a directive on record retention.

訳その機関は、記録の保存に関する指令を出した。

command

頻度 7/10

定義従うことを強く求める命令。

違い権威や即時の服従を強調しやすい。instruction は実務的な指導・説明に近い指示も含む。

例The soldiers moved forward at the command.

訳兵士たちは、その命令で前進した。

語義 3

【名詞・不可算】指導、教授、教育

頻度 7/10
やや硬い・教育・講習・技能指導。

人に知識・技能を教える行為。学科・語学・実技などを対象とし、個人指導にも集団での授業にも使う。指示の項目を数えるのではなく、教える活動としてとらえる。

文法パターン7
  • instruction in 〈分野・技能〉＝その分野・技能の指導
  • instruction on doing＝その実施方法についての指導
  • receive instruction＝指導を受ける
  • give/provide instruction＝指導を行う
  • be under instruction＝指導を受けている
  • the language/medium of instruction＝授業・指導に使う言語・媒体
  • individual instruction＝個人指導。
コロケーション・構文例6

instruction in 〈分野・技能〉

用途教わる内容を示す。

例The studio offers instruction in ceramics.

訳その工房は陶芸の指導を行っている。

instruction on doing

用途行為の方法を教えることを示す。

例The course includes instruction on using a microscope.

訳その講座には、顕微鏡の使い方の指導が含まれる。

receive instruction

用途教える人から指導を受けることを述べる。

例Each apprentice receives instruction from an experienced craftsperson.

訳見習いはそれぞれ、経験豊かな職人から指導を受ける。

be under instruction

用途現在、指導される立場で学んでいることを示す。

例The driver was still under instruction when the route changed.

訳経路が変更されたとき、その運転手はまだ指導を受けている段階だった。

the language of instruction

用途授業を行う際に使う言語を述べる。

例English is the language of instruction for this course.

訳この講座では、授業で英語を使う。

individual instruction

用途一人ひとりを対象とした指導を指す。

例Individual instruction is available by appointment.

訳個人指導は予約で受けられる。

語法・注意1
  • some instruction、formal instruction とし、指導を何回か受けたからといって instructions と複数にすると、通常は「指示・説明内容」の意味になる。「3時間の指導」は three hours of instruction。under instruction「指導を受けて」と under instructions to wait「待つよう指示されて」を区別する。instruction in English は英語という科目の指導と、英語で行う指導の両方に解釈され得る。使用言語を明確にするには English is the language of instruction. のように言う。
類義語3

teaching

頻度 9/10

定義人に知識や技能を教えること。

違い広く一般的な語。instruction は授業や技能指導をやや正式に述べる場合に使いやすい。

例Good teaching encourages students to ask questions.

訳よい指導は、生徒が質問することを促す。

tuition

頻度 6/10

定義個人や少人数を対象とする指導・授業。

違いこの意味は特に英国英語で使う。米語では授業料の意味が一般的なので、instruction との置換には文脈が必要。

例She offers private tuition in mathematics.

訳彼女は数学の個人指導を行っている。

training

頻度 9/10

定義特定の活動に必要な技能・能力を身につける訓練。

違い学ぶ側の練習や実践も含む。instruction は教える行為自体に焦点を置く。

例The trainees completed a week of practical training.

訳研修生たちは、1週間の実地訓練を終えた。

語義 4

【名詞の前で使う形容詞的用法】使用法・手順を説明するための

頻度 7/10
一般・製品の説明資料。

manual、book、sheet などの前に置き、その物が使い方や手順を説明するものであることを示す。名詞の前の修飾として扱う辞書と、名詞前限定の形容詞として立てる辞書がある。

文法パターン3
  • an instruction manual＝使い方を説明するマニュアル
  • an instruction book/booklet＝使い方の説明書・小冊子
  • an instruction sheet＝手順を説明する用紙。
コロケーション・構文例3

an instruction manual

用途製品などの使い方を説明する手引きを指す。

例The instruction manual is available online.

訳取扱説明書はオンラインで閲覧できる。

an instruction booklet

用途小冊子になった説明書を指す。

例An instruction booklet comes with the sewing machine.

訳そのミシンには、使い方を説明する小冊子が付いている。

an instruction sheet

用途一枚などの用紙にまとめた手順説明を指す。

例Attach the instruction sheet to the front of the kit.

訳キットの前面に、手順の説明用紙を付けてください。

語法・注意1
  • instruction manual の instruction は動詞ではない。通常は単数形を前に置き、複数の説明書は instruction manuals とする。この用法は名詞の前に限られ、The manual is instruction. を「その説明書は説明用だ」の意味では使わない。instructional は教材全般にも使える形容詞、instructive は「ためになる」という評価で、an instructive book と an instruction book は意味が異なる。
語義 5

【名詞・可算】コンピューターの命令

頻度 5/10
計算機・プログラミング・ハードウェア。

コンピューターやプロセッサーに特定の処理を行わせる一つの命令。実行される処理単位を指し、人に操作方法を説明する文章とは区別する。

文法パターン4
  • execute an instruction＝命令を実行する
  • a machine instruction＝機械語の命令
  • an instruction set＝プロセッサーなどが扱う命令の集合
  • a sequence of instructions＝一連の命令。
コロケーション・構文例3

execute an instruction

用途プロセッサーが一つの命令を実行することを述べる。

例The processor executes the instruction and stores the result.

訳プロセッサーはその命令を実行し、結果を格納する。

an instruction set

用途対応する機械命令の集合を指す。

例The new processor supports the same instruction set.

訳新しいプロセッサーは、同じ命令セットに対応している。

a sequence of instructions

用途処理を実現する一連の命令を述べる。

例The compiler translates the expression into a sequence of machine instructions.

訳コンパイラーは、その式を一連の機械語命令に変換する。

語法・注意1
  • この意味は一つずつ数えられ、an instruction、multiple instructions とする。an instruction manual は人が読む説明書で、an instruction set は機械命令の集合。command は端末やソフトウェアへユーザーが与える指示にも使うが、CPUの一命令と常に一対一に対応するわけではない。命令の実行にかかる時間や処理数は機器によって異なる。
語義 6

【名詞・複数形】弁護士への指示、依頼内容

頻度 3/10
法律実務。特に英国などの英語圏で見られる。

代理・法律業務を依頼する側から、弁護士に伝える案件の事情や、どう対応してほしいかという指示・依頼内容。法律実務で使われる instructions の用法。

文法パターン3
  • take instructions from a client＝依頼人から事情や指示を聞く
  • act on a client's instructions＝依頼人の指示に基づいて対応する
  • seek further instructions from a client＝依頼人に追加の指示を求める。
コロケーション・構文例2

take instructions from a client

用途弁護士が案件について依頼人の話・意向を聞くことを述べる。

例The solicitor took instructions from the client about the proposed settlement.

訳そのソリシターは、提案された和解について依頼人の意向・指示を聞いた。

seek further instructions from a client

用途対応を決めるために依頼人の追加の意向を確認する。

例Counsel sought further instructions from the client before responding to the offer.

訳弁護士は、その申し出に返答する前に依頼人へ追加の指示を求めた。

語法・注意2
  • take instructions は、弁護士が一般的な「授業を受ける」という意味ではない。通常は複数形を使う。この語だけで契約の成立、弁護士の受任義務、代理権の範囲を判断できるわけではなく、具体的な制度や手続きは法域・案件による。
  • 語義2の一般的な「指示」とつながるが、法律実務では案件の事情や依頼内容を聞き取ることまで含むため、単純に「命令を受ける」と訳すと役割関係を取り違えやすい。
該当する語義・用例がありません。
