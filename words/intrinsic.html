ENGLISH–JAPANESE EXTRA

intrinsic

主要語義 4更新 2026-10-20

発音記号

米・英: /ɪnˈtrɪn.zɪk/ または /ɪnˈtrɪn.sɪk/

  • 3音節で、第2音節に強勢がある。二つの異形の違いは第3音節の頭の子音で、有声音 /z/ と無声音 /s/。この違いを米英に一律に割り当てるものではない。いずれも語尾の母音は /ɪ/。

コアイメージ

「対象そのものの内側に属する・内側に由来する」が核。性質や身体の構造、コンパイラーへの組込み、材料自体による電気的性質に具体化するが、各分野の詳しい定義や実装条件までこの核だけで決まるわけではない。

  • 対象の内側に属する性質や価値 → 「内在する・それ自体に備わった」（語義1）
  • 対象の内側に属する身体の構造 → 「器官・部位の内部に属する」（語義2）
  • 対象の内側に組み込まれた計算処理 → 「コンパイラー組込み関数・組込み操作」（語義3）
  • 対象の内側の材料特性に由来する状態 → 「真性の」（語義4）

語源

  • フランス語 intrinsèque や後期ラテン語 intrinsecus「内側の」に関係し、ラテン語で内側へという方向を表す語にさかのぼる。語頭の綴り in を否定の接頭辞と解釈しない。歴史的には「内側」を表すラテン語の語群に関係し、現代語を単純に in- と残部へ分けて作った語ではない。同じ内外の対照で使う語に extrinsic「外からの」がある。現代語では「中にある」という位置だけでなく、対象そのものの性質に属することもいう。

語形成

intrinsically副詞。「本質的に・それ自体として」。intrinsically valuable は「それ自体に価値がある」。綴りは intrinsicly ではなく intrinsically。
intrinsic value名詞句。一般には「それ自体の価値」。金融などでは専門的な定義が用いられるため、具体的な評価額を一般語義だけから決めない。
extrinsic形容詞。「外的な・外から生じる」。内在する性質や動機を表す intrinsic と対照になる。

語義 1

【形容詞】内在する・それ自体に備わった

頻度 6/10
やや硬い表現。学術・評論・ビジネス・心理学。頻度評点は学習上の目安で、コーパスによる実測値ではない。

物事の性質・価値・要素などが、その対象自体のあり方に属し、外からの報酬や周囲の評価などだけによるものではないこと。「重要な」「良い」と同義ではなく、価値の小ささや望ましくない性質についても使える。

文法パターン4
  • the intrinsic value of 〈対象〉＝対象それ自体の価値
  • an intrinsic part of 〈全体〉＝全体に内在する構成部分
  • 〈性質・要素〉 + be intrinsic to 〈対象〉＝対象に本来的に備わる
  • intrinsic motivation＝活動自体の面白さ・満足による内発的動機付け。
コロケーション・構文例5

the intrinsic value of 〈対象〉

用途他の目的の手段としてではない価値を論じる。

例The essay explores the intrinsic value of friendship, beyond its practical benefits.

訳その論考は、実際的な利益を超えた、友情それ自体の価値を探究している。

little intrinsic value

用途対象自体の価値が小さいことを述べる。

例The token has little intrinsic value, but collectors are willing to pay for its history.

訳そのトークン自体の価値はわずかだが、収集家はその歴史に対してお金を払おうとする。

an intrinsic part of 〈全体〉

用途活動や仕組みから切り離しにくい要素をいう。

例Uncertainty is an intrinsic part of scientific inquiry.

訳不確実性は科学的探究に本来的に含まれる要素だ。

be intrinsic to 〈対象〉

用途性質が何に内在するかを示す。

例These risks are intrinsic to the process, not caused by poor management.

訳これらのリスクはその工程に内在するもので、管理の不備が原因ではない。

intrinsic motivation

用途活動をすること自体の満足が動機になることをいう。

例She studied the subject out of intrinsic motivation, enjoying the questions themselves.

訳彼女は問いそのものを楽しみ、内発的な動機からその科目を学んだ。

語法・注意3
  • 名詞の前にも be の後にも使える。intrinsic to the activity の to は前置詞で、性質が属する対象を示す。the intrinsic value of the activity の of は value に結び付く。intrinsic of the activity を基本構文として使わない。形容詞の修飾なら intrinsically interesting と副詞にし、intrinsic interesting とはしない。
  • intrinsic は「生まれつきの」と必ずしも同義ではなく、生物以外の仕組み・活動にも使う。対象の性質に属するという見方であって、どの条件でも絶対に変えられないという主張ではない。no intrinsic merit、little intrinsic value のように否定・小さい程度とも両立する。
  • intrinsic motivation は活動自体がもたらす楽しさ・満足などによる動機で、頭の中に生じた動機ならすべて内発的という意味ではない。外的報酬への動機と共存する場合もある。一般語の intrinsic value と、金融上の特定の評価概念などは分けて読む。
類義語3

inherent

頻度 6/10

定義対象の性質に本来的に備わっている。

違い意味が非常に近い。intrinsic は対象それ自体と外的要因の対比を意識させやすいが、両語の境界は排他的ではない。

例The system has inherent limitations.

訳そのシステムには本来的な限界がある。

integral

頻度 6/10

定義全体を成り立たせる不可欠な部分である。

違い構成要素としての不可欠さに重点がある。intrinsic は価値や性質の由来を述べる場合にも使う。

例Feedback is an integral part of the learning process.

訳フィードバックは学習過程に不可欠な要素だ。

innate

頻度 5/10

定義生まれながらに備わっている。

違い人や生物の性質について出生・生得性に重点を置く。intrinsic は工程の性質などにも使い、生まれた時点を必ず意味しない。

例The species has an innate tendency to migrate.

訳その種には生まれつき移動する傾向がある。

反意語1

extrinsic

頻度 4/10

定義対象自体の性質ではなく、外部の要因による。

違い性質・価値・動機の由来という軸で直接の対照になる。

例The reward provided an extrinsic reason to complete the task.

訳その報酬は、課題を終える外的な動機を与えた。

語義 2

【形容詞】器官・部位の内部に属する

頻度 3/10
解剖学・生理学。

解剖学などで、筋などが対象となる器官・部位の内部にある、またはそこに起源を持つこと。対象それ自体の「重要さ」を評価するのではなく、どの部位に属するかを区別する専門用法。

文法パターン2
  • the intrinsic muscles of 〈部位〉＝その部位の内在筋
  • intrinsic 〈muscles/structures〉＝対象部位の内部に属する筋・構造。
コロケーション・構文例1

the intrinsic muscles of 〈部位〉

用途部位内に属する筋をいう。

例The diagram distinguishes the intrinsic muscles of the hand from the extrinsic muscles.

訳図は手の内在筋を外在筋と区別して示している。

語法・注意2
  • intrinsic muscles は「重要な筋肉」ではなく、対象部位への所属で区別される筋を指す。どの部位を基準に内在・外在を分けるかを確認する。一般的な身体内部というだけで、どの文脈でも intrinsic に分類されるわけではない。
  • extrinsic muscles はその部位の外部に起源を持つなどの対照を表す。この語彙上の区別だけで、疾患や治療法が決まるわけではない。
語義 3

【名詞・可算】コンパイラー組込み関数・組込み操作

頻度 2/10
プログラミング・コンパイラー。intrinsic function という表現も使う。

コンパイラーが特別に認識し、対応する処理として実装する関数や操作。特定の命令や最適化された処理に対応することがあるが、実装はコンパイラーや対象環境による。

文法パターン3
  • an intrinsic＝一つの組込み関数・操作
  • compiler intrinsics＝コンパイラーの組込み関数類
  • use an intrinsic＝組込み関数を使う。
コロケーション・構文例2

an intrinsic

用途組込み関数を通常の関数呼出しなどと区別する。

例The compiler recognizes this operation as an intrinsic.

訳コンパイラーはこの操作を組込み操作として認識する。

compiler intrinsics

用途特別に認識される関数群をいう。

例The library uses compiler intrinsics for some performance-critical operations.

訳そのライブラリは、性能が重要な一部の処理にコンパイラー組込み関数を使っている。

語法・注意2
  • この意味では名詞なので an intrinsic、several intrinsics と数えられる。一般形容詞の intrinsic を、そのまま「内在的な性質」という普通名詞にした用法ではない。intrinsic function は function が中心の名詞句で、intrinsic はそれを修飾している。
  • 組込み処理が常に一つの機械命令だけになる、必ずインライン展開される、通常の関数呼出しになることがない、といった制約を語の意味だけから断定しない。具体的なコード生成は対象のコンパイラーの仕様に従う。
語義 4

【形容詞】真性の

頻度 2/10
半導体・電子物性。

半導体で、電荷を運ぶ粒子の濃度が、添加された不純物の量ではなく、材料それ自体の性質によって決まる状態に関すること。一般の「内在する」という訳だけでなく、半導体の専門訳「真性の」で理解する。

文法パターン2
  • an intrinsic semiconductor＝真性半導体
  • intrinsic silicon＝真性シリコン。対象材料の種類・状態を前から分類する。
コロケーション・構文例2

an intrinsic semiconductor

用途不純物によるキャリアの寄与を中心としない半導体をいう。

例The lecture compared an intrinsic semiconductor with a doped semiconductor.

訳講義では真性半導体と不純物を添加した半導体を比較した。

intrinsic silicon

用途真性の状態にあるシリコンをいう。

例The model describes the electrical properties of intrinsic silicon.

訳そのモデルは真性シリコンの電気的性質を記述している。

語法・注意2
  • この専門義の extrinsic は、不純物の導入によるキャリアの影響を受ける不純物半導体の側を表す。単に半導体が装置の内側にあるか外側にあるかという位置の違いではない。また、intrinsic という語から、対象に不純物が一原子も存在しないという絶対条件を読み込まない。
  • ここでは種類・状態の分類なので、一般的な価値の大小を述べる語義1の intrinsic value と混ぜない。具体的な温度や濃度の数値は材料や測定条件の問題で、語の意味だけでは定まらない。
