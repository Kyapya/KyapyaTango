ENGLISH–JAPANESE EXTRA

compatibility

主要語義 5更新 2026-10-17

発音記号

米・英: /kəmˌpæt.əˈbɪl.ə.ti/。6音節で、第2音節に第二強勢、第4音節に主強勢がある。compatible /kəmˈpæt.ə.bəl/ と比べ、主強勢が -bility の /bɪl/ へ移る。

コアイメージ

組み合わせたもの同士が、互いを妨げずに共存・機能できること。似ているかどうかだけでなく、その組み合わせで支障が出ないかを見る。

  • 機器やソフトが支障なく機能する関係 → 「互換性」（語義1）
  • 人同士が支障なく関わり合える関係 → 「相性のよさ・うまくやっていけること」（語義2）
  • 考えや条件同士が支障なく成立する関係 → 「両立可能性・整合性」（語義3）
  • 生物の組み合わせが支障なく機能する関係 → 「生物学的な適合性・親和性」（語義4）
  • 物質の組み合わせが支障なく機能する関係 → 「化学的適合性・配合適合性」（語義5）

語源

  • compatible「共に存在・機能できる」の名詞形。compatible は中世ラテン語 compatibilis にさかのぼり、もとに「共に感じる・共に苦しむ」を表すラテン語系の compati がある。com-「共に」と pati「受ける・耐える」に関係する。同じ語族には compassion「思いやり」と patience「忍耐」があるが、現代の compatibility は苦痛を意味せず、「一緒でも支障がない」という適合関係を表す。

語形成

compatible形容詞。「互換性がある・相性がよい・両立する」。be compatible with something が基本。
incompatible形容詞。「互換性がない・相いれない」。incompatible with something のように相手を示す。
incompatibility名詞。「不適合・不一致・両立しないこと」。具体的な不一致点は可算にもなる。
compatibly副詞。「支障なく共存する形で」。実在するが、一般の説明では work well together などが使われることも多い。
backward-compatible複合形容詞。「以前の版や旧式のデータなどに対応できる」。a backward-compatible update のように使う。
biocompatibility複合名詞。「生体適合性」。材料などを体内・生体と接触させて使う際の適合性を指す専門語。

語義 1

【名詞・通常不可算】互換性

頻度 7/10
IT・製品仕様・機械・業務上の選定。日本語では「互換性」が多いが、相互に置き換えられることだけには限らない。

機器・ソフトウェア・ファイル形式・部品などを、指定された相手と組み合わせて使える性質。ソフトがあるOSで動くこと、旧形式のファイルを新しいアプリで開けること、部品同士が正しく連動することなどを指す。機能・版・条件ごとの適合を表すので、どんな使い方でも同じ性能を保証するわけではない。

文法パターン9
  • compatibility with 〈機器・ソフト・形式〉
  • compatibility between 〈A〉 and 〈B〉
  • check something for compatibility with something
  • ensure compatibility
  • compatibility issues
  • backward compatibility with 〈旧版〉
  • forward compatibility
  • compatibility mode
  • compatibility testing。
コロケーション・構文例8

compatibility with 〈OS〉

用途ソフトや機器が対応する動作環境を示す。

例Check the scanner's compatibility with your operating system before ordering it.

訳注文する前に、そのスキャナーが使用中のOSに対応しているか確認してください。

compatibility between 〈A〉 and 〈B〉

用途二つの製品や構成要素の組み合わせを評価する。

例The test confirmed compatibility between the new sensor and the existing controller.

訳試験により、新しいセンサーと既存の制御装置を組み合わせて使えることが確認されました。

check something for compatibility with something

用途部品が、使う相手と問題なく組み合わさるか確認する。

例The engineer checked the replacement sensor for compatibility with the control unit.

訳技術者は、交換用センサーを制御ユニットと組み合わせて使えるか確認しました。

ensure compatibility

用途連携して使えるように設計・選定する。

例The team agreed on a common file format to ensure compatibility across departments.

訳チームは、部署をまたいでファイルを使えるよう、共通のファイル形式に合意しました。

compatibility issues

用途組み合わせたときに生じる動作上の問題を述べる。

例The update caused compatibility issues with an older accounting package.

訳更新により、旧版の会計ソフトとの互換性に問題が生じました。

backward compatibility with 〈旧版〉

用途新しい製品や版が、以前の版や形式などを引き続き扱えると述べる。

例The new application maintains backward compatibility with files created by the previous version.

訳新しいアプリケーションは、前の版で作成されたファイルとの後方互換性を維持しています。

forward compatibility

用途既存の仕組みが、より新しい形式や拡張もある程度扱える設計を述べる。

例The format supports forward compatibility by allowing older readers to ignore unknown optional fields.

訳その形式は、古い読み取りプログラムが未知の任意フィールドを無視できるようにすることで、前方互換性を支えています。

compatibility mode

用途旧版向けの動作などを再現する設定を示す。

例The program runs correctly in compatibility mode on this computer.

訳このコンピューターでは、そのプログラムは互換モードで正常に動作します。

語法・注意1
  • 相手を一方から示すなら compatibility with、二つを並べるなら compatibility between A and B が基本。一般的な製品説明で compatibility to the device とするより compatibility with the device とする。形容詞では The adapter is compatible with the laptop.、名詞では The adapter's compatibility with the laptop has been tested.。「互換性がある」は、通常 The adapter is compatibility. とはいわない。compatibility は通常不可算で、a compatibility issue、several compatibility tests のように後続名詞を数える。compatibilities は適合の種類や関係を区別する専門的な文脈に限って現れる。backward compatibility の基準は新しい側から古い側を見ること、forward compatibility は古い側が新しい情報などに対応することだが、具体的な保証範囲は製品仕様による。backward compatibility と backwards compatibility の両形がある。interoperability は複数システムが情報をやり取りし連携して働くことに重点があり、interchangeability は相互に置き換えられることに重点がある。いずれも compatibility と完全には一致しない。

interoperability

頻度 5/10

定義異なる機器・システムなどが情報を交換し、連携して機能できること。

違い単に同じ環境で動くことより、相互にやり取りして使えることを重視する。材料の適合性など、compatibility のすべての用法を置き換えない。

例The standard improves interoperability between payment systems.

訳その規格は、決済システム間の相互運用性を高めます。

incompatibility

頻度 5/10

違い同じ機能・条件での併用可能性を否定する対立。具体的な不適合箇所を an incompatibility と数える場合もある。

例An incompatibility between the driver and the operating system prevented installation.

訳ドライバーとOSの間に互換性の問題があり、インストールできませんでした。

語義 2

【名詞・不可算】相性のよさ・うまくやっていけること

頻度 6/10
人間関係・恋愛・職場・共同生活。恋愛や結婚の文脈でよく使うが、対象は限定されない。

人同士が、性格、価値観、生活の仕方などの点で無理なく関わり合い、共に暮らしたり働いたりできること。恋愛関係だけでなく、同僚や共同生活の相手にも使う。意見や性格がすべて同じであること、口論がまったくないことまでは意味しない。

コロケーション・構文例6

compatibility between 〈人A〉 and 〈人B〉

用途二人がうまく関わり合えるかを述べる。

例Shared interests can help, but they do not guarantee compatibility between two people.

訳共通の趣味は役立つことがありますが、二人の相性のよさを保証するものではありません。

someone's compatibility with someone

用途ある人と特定の相手との相性を評価する。

例During the trial period, both roommates considered their compatibility with each other.

訳試しに共同生活をする期間中、二人の同居人は互いにうまくやっていけるか考えました。

emotional compatibility

用途感情の表し方や心の支え方などの相性を述べる。

例They value emotional compatibility more than having identical hobbies.

訳二人は、趣味がまったく同じであることより、感情面での相性を大切にしています。

sexual compatibility

用途性的な好みや期待などの相性を述べる。

例The couple discussed sexual compatibility openly and respectfully.

訳その二人は、互いを尊重しながら性的な相性について率直に話し合いました。

a lack of compatibility

用途関係を続けにくい原因として相性の不一致を述べる。

例They ended the partnership because of a lack of compatibility in their working styles.

訳二人は仕事の進め方の相性が合わず、共同事業を終えました。

a compatibility test

用途質問などを通じて相性を見るものを指す。

例They took an online compatibility test for fun.

訳二人は遊びでオンラインの相性診断を受けました。

語法・注意1
  • compatibility は関係の性質を表す不可算名詞。They have good compatibility. も意味は通るが、人について単に「相性がよい」と言うなら They are compatible.、They get along well. が直接的。someone's compatibility with someone と言うと、性格や生活の組み合わせを評価するやや分析的な響きがある。similarity「似ていること」と同じではなく、異なる性格が互いを補う場合もある。a compatibility test はそのような名称のテストを指すだけで、科学的な妥当性や関係の将来を保証しない。人の価値を格付けする語ではなく、特定の相手との組み合わせについて述べる。

頻度 6/10

違い現在の良好な関係や平穏さに重点がある。compatibility は、性格や生活の仕方の組み合わせが合うかを表す。

例The two departments now work together in harmony.

訳二つの部署は、今では協調して働いています。

rapport

頻度 6/10

定義互いに理解し合い、気軽に意思を通わせられる関係。

違い会話や交流で生まれる理解・親近感に焦点がある。compatibility は生活習慣や長期的な関係の適合も含めて使える。

例The interviewer quickly established a rapport with the guest.

訳インタビュアーは、すぐにゲストと打ち解けた関係を築きました。

incompatibility

頻度 5/10

定義性格・価値観・生活様式などの違いから、共に過ごしたり働いたりしにくいこと。

違い相性という同じ軸の反対。必ず一方に非があることや、強い敵意があることを意味しない。

例Their incompatibility became clear when they started living together.

語義 3

【名詞・通常不可算】両立可能性・整合性

頻度 5/10
議論・政策・学術・法令や規則の検討。やや硬い表現。

考え、目標、行動、規則、条件などが、互いに矛盾せず同時に成り立つこと。ある行動が原則と相いれることや、二つの目標を同時に追求できることを表す。必ず完全に同一であること、すべての要求を満たしていることを意味するわけではない。

文法パターン5
  • the compatibility of 〈方針・行動〉 with 〈原則・条件〉
  • compatibility between 〈目標A〉 and 〈目標B〉
  • assess the compatibility of something with something
  • question the compatibility of something with something
  • ensure compatibility with 〈規則・原則〉。
コロケーション・構文例5

the compatibility of 〈方針〉 with 〈原則〉

用途ある方針が掲げる原則と矛盾しないか検討する。

例The committee examined the compatibility of the proposal with the organisation's stated values.

訳委員会は、その提案が組織の掲げる価値観と両立するか検討しました。

compatibility between 〈目標A〉 and 〈目標B〉

用途二つの目標を同時に追えるか論じる。

例The study explores compatibility between economic growth and environmental protection.

訳その研究は、経済成長と環境保護の両立可能性を探っています。

assess the compatibility of something with something

用途規則や基準との整合性を確認する。

例Legal advisers will assess the compatibility of the new policy with the existing rules.

訳法律顧問は、新しい方針が既存の規則と整合するか評価します。

question the compatibility of something with something

用途行動と約束などが相いれるか疑問を呈する。

例Staff questioned the compatibility of the spending cuts with the promise to improve services.

訳職員は、支出削減がサービス改善の約束と両立するのか疑問を呈しました。

ensure compatibility with 〈原則〉

用途内容を調整して原則との矛盾を避ける。

例The authors revised the guidelines to ensure compatibility with the principles set out in the introduction.

訳執筆者は、序文に示した原則と整合するよう、指針を改訂しました。

語法・注意1
  • compatibility は「矛盾せず両立できること」で、agreement「意見や内容の一致」と必ずしも同じではない。別々の目標でも互いを妨げなければ compatible であり得る。compliance with a rule は「規則に従っていること」、compatibility with a rule は「規則と相いれること」に焦点がある。法的文書で両者の効果が同じとは限らない。compatibility with 〈法令〉 は検討の観点を示す一般的な名詞句で、この語だけから適法性を認定する手続きや権限が決まるわけではない。The policy is compatible with our goals. は形容詞、The policy's compatibility with our goals is unclear. は名詞を使う。the compatibility between the two goals と the compatibility of one goal with the other の対応を押さえる。

consistency

頻度 6/10

定義複数の考え・記述・行動などの間に矛盾がないこと。

違い内容や論理の筋が通っている点を強調する。compatibility は異なる目標や条件が共存できるかにも広く使える。

例The editor checked for consistency between the summary and the main report.

訳編集者は、要約と報告書本文の内容が矛盾していないか確認しました。

例The review considered the congruity of the design with the building's historic character.

訳審査では、その設計が建物の歴史的な特徴と調和するか検討されました。

例The decision is in accord with the policy adopted last year.

訳その決定は、昨年採用された方針と一致しています。

違い同じ条件下での両立可能性を否定する対立。単なる違いより強く、相いれない点があることを表す。

語義 4

【名詞・通常不可算】生物学的な適合性・親和性

頻度 3/10
医学・生物学・園芸。人間関係の相性とは区別する専門的な用法。

血液・組織・生体材料、または植物の組み合わせなどが、対象とする生物学的な働きを妨げずに成立する適合関係。輸血や移植では供与側と受容側の適合、植物では接ぎ木の接合や受精が成立する親和性などを指す。何を「適合」とするかは、検査や分野によって異なる。

文法パターン7
  • blood group compatibility
  • tissue compatibility
  • compatibility between 〈供与側〉 and 〈受容側〉
  • graft compatibility
  • pollen compatibility
  • self-compatibility
  • test for compatibility。
コロケーション・構文例5

blood group compatibility

用途輸血などで血液型の組み合わせの適合を指す。

例The laboratory checks blood group compatibility as part of the pre-transfusion assessment.

訳検査室は、輸血前の評価の一環として血液型の適合性を確認します。

tissue compatibility

用途移植を検討するときの組織の適合を指す。

例Tissue compatibility is one factor considered when evaluating a potential transplant donor.

訳組織適合性は、移植の提供候補者を評価するときに検討する要素の一つです。

graft compatibility

用途接ぎ木で、台木と穂木が適合するかを論じる。

例The nursery keeps records of graft compatibility between different rootstocks and scions.

訳その苗木園は、さまざまな台木と穂木の接ぎ木親和性を記録しています。

pollen compatibility

用途植物の受粉・受精に関わる組み合わせの適合を示す。

例The grower consulted a pollen compatibility chart before choosing the second plum variety.

訳栽培者は、2品種目のプラムを選ぶ前に、花粉の親和性を示す表を確認しました。

self-compatibility

用途植物が自身の花粉で受精できる性質を指す。

例The experiment tested the variety's self-compatibility by applying pollen from the same plant.

訳その実験では、同じ植物の花粉を付けることで、その品種の自家和合性を調べました。

語法・注意1
  • この用法の compatibility は、すべての性質が同一であることを意味しない。血液型などの適合と、治療全体の安全性や成功は別の評価であり、適合の確認だけで結果を保証するわけではない。crossmatching は適合性を調べる検査・手順で、compatibility という性質そのものの同義語ではない。植物の graft compatibility「接ぎ木親和性」と pollen compatibility「花粉の親和性」は異なる働きについての適合なので、片方からもう片方を推定しない。self-compatibility は自家受精が可能な性質であり、受粉の手助けや他の生育条件が不要だという意味ではない。self- は「自分自身との」という意味を加え、互いに異なる個体同士の適合とは区別する。
類義語2

biocompatibility

頻度 3/10

定義材料・医療機器などを、目的とする生体との接触条件で適切に使える性質。

違い生体材料などについての compatibility に重なるが、人同士の相性や、植物の受粉の適合を広く指す語ではない。

例The researchers evaluated the biocompatibility of the coating before further implant studies.

訳研究者は、インプラントの追加研究に進む前に、そのコーティングの生体適合性を評価しました。

histocompatibility

頻度 2/10

定義移植などで、組織同士が免疫学的に適合すること。

違いtissue compatibility に対応する狭い専門語。一般の compatibility が示す機器・人間関係・植物などには使わない。

例The laboratory specialises in histocompatibility testing for transplant programmes.

訳その検査室は、移植プログラムのための組織適合性検査を専門としています。

反意語1

incompatibility

頻度 3/10

定義生物学的な組み合わせが、対象とする働きを成立させない、または問題を生じさせる不適合。

違い指定した生物学的な適合の軸で反対を表す。何の不適合かは blood group、graft などの修飾語で限定する。

例Graft incompatibility can cause the rootstock and scion to separate at the union.

訳接ぎ木の不親和によって、台木と穂木が接合部で分離することがあります。

語義 5

【名詞・通常不可算】化学的適合性・配合適合性

頻度 3/10
化学・材料・製品開発・薬学。専門的な用途ごとの適合を表す。

物質・材料・薬剤などを接触、混合、併用したとき、意図しない反応、分離、劣化、作用への有害な干渉などによって用途が損なわれない適合関係。材料と薬品の組み合わせでは耐薬品性、混合物では均一さや安定性、薬剤では配合・併用の可否など、何を評価するかを限定して使う。

文法パターン6
  • chemical compatibility
  • compatibility with 〈物質・材料〉
  • compatibility between 〈物質A〉 and 〈物質B〉
  • a compatibility chart
  • drug compatibility
  • assess compatibility。
コロケーション・構文例4

chemical compatibility

用途化学物質と材料などの組み合わせが用途上の問題を起こさないか述べる。

例The laboratory assessed chemical compatibility before selecting a container for the solution.

訳研究所は、その溶液を入れる容器を選ぶ前に、化学的な適合性を評価しました。

compatibility with 〈物質〉

用途特定の物質に接触させても材料の機能が損なわれないかを述べる。

例The tubing's compatibility with the solvent depends on temperature and exposure time.

訳そのチューブをその溶媒に使えるかは、温度と接触時間によって変わります。

a compatibility chart

用途物質と材料などの適合関係を示す一覧を指す。

例The manufacturer provides a compatibility chart for the bottle materials and common laboratory chemicals.

訳メーカーは、ボトルの材料と一般的な実験用薬品との適合表を提供しています。

drug compatibility

用途薬剤の配合・併用に支障がないかという専門的な確認を指す。

例The pharmacist consulted a specialist reference to check drug compatibility.

訳薬剤師は、薬剤の配合・併用適合性を確認するために専門資料を参照しました。

語法・注意1
  • 機器の動作互換性という語義1とは、調べる対象と結果が異なる。chemical compatibility は「混ざること」だけではなく、接触しても容器が劣化しないことなども含む。miscibility「混和性」は混ざり合って一つの相を作れる性質であり、それだけで保存、材料の耐久性、薬剤の使用上の適切さまで保証しない。薬剤の文脈では、物理的・化学的な配合適合性と、患者に対する治療上の適切さを同一視しない。compatibility chart の判断は温度、濃度、接触時間などの条件に依存することがあり、「適合」と書かれているだけであらゆる使い方に適すると解釈しない。
類義語1

miscibility

頻度 2/10

定義物質同士が混ざり合い、均一な一つの相を作れる性質。

違い均一な混合物を作るという限定された意味では compatibility と重なる。材料の耐薬品性や、薬剤の併用による作用の干渉まで含む語ではない。

例The study measured the miscibility of the two liquids at different temperatures.

訳その研究は、異なる温度で二つの液体の混和性を測定しました。

反意語1

incompatibility

頻度 3/10

定義物質や材料を接触・混合・併用すると、目的に合わない反応や変化などが起こる不適合。

違い指定した条件での物理的・化学的な適合という同じ軸の反対。人の相性やソフトの動作不良とは文脈を区別する。

例The test revealed an incompatibility between the solvent and the container lining.

訳試験で、その溶媒と容器の内張りとの間に不適合があると分かりました。

該当する語義・用例がありません。
