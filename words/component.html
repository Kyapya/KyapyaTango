発音記号

米: /kəmˈpoʊnənt/｜英: /kəmˈpəʊnənt/。3音節で第2音節に主強勢がある。英米差は第2音節の二重母音で、米 /oʊ/、英 /əʊ/。第1・第3音節の母音は弱い /ə/。名詞と形容詞で基本的な発音は変わらない。複数形 components では語末に /s/ が加わり、音節数と強勢位置は変わらない。

  • componential analysis は米: /kɑːmpəˌnenʃl əˈnæləsɪs/｜英: /kɒmpəˌnenʃl əˈnæləsɪs/。この表記では全体で8音節、第6音節に主強勢、第3音節に副強勢がある。英米差は第1音節の米 /ɑː/ と英 /ɒ/。componential の語末の /l/ が音節の中心になる読みを含む。

コアイメージ

全体を組み立てる、区別可能な構成単位という捉え方。機器・ソフトウェア・数学・意味の分析で、何を一つの全体とし、どの単位に分けるかが変わる。

  • 全体を組み立てる区別可能な部分 → 「構成要素、部品」（語義1）
  • ソフトウェアを組み立てる機能単位 → 「ソフトウェアの構成単位、UI部品」（語義2）
  • 全体の構成部分であるという関係 → 「全体を構成する」（語義3）
  • 合成して全体のベクトルを作る部分 → 「ベクトルを構成する方向別のベクトル成分」（語義4）
  • 座標表現を組み立てる個々の数値 → 「座標値、数値としての成分」（語義5）
  • 映像情報を構成成分に分けて扱う方式 → 「信号を成分別に分けた、コンポーネント方式の」（語義6）
  • 語の意味を成す特徴を調べる分析 → 「意味の成分分析」（語義7）

語源

  • ラテン語 componere（組み合わせる）の現在分詞 componens の語幹 component- に由来する。com- は一緒に、ponere は置くという要素で、全体を組み立てる部分という意味につながる。compose と語源を共有するが、現代英語で compose に規則的な接尾辞を付けただけの形ではない。

語形成

componential構成要素に関わるという形容詞。componential analysis は、語の意味を特徴に分けて扱う言語学の用語。

語義 1

【名詞：可算】構成要素、部品

頻度 8/10
一般・技術・仕事・分析。

機械・仕組み・計画などの全体を構成する、区別できる一つの部分。物理的な部品だけでなく、成分・機能・抽象的な要因にも使う。

文法パターン7
  • a component of something
  • a component in something
  • a component for something
  • a key component
  • electronic components
  • component failure
  • stereo components。
コロケーション・構文例7

a component of something

用途部分が属する全体を示す。

例Training is an important component of the new programme.

訳研修は、新しい計画の重要な構成要素である。

a component in something

用途ある仕組みや関係の中で働く要素を示す。

例Mutual trust is a key component in a successful partnership.

訳相互の信頼は、協力関係を成功させる重要な要素である。

a component for something

用途部品の用途・組込み先を示す。

例The factory produces components for electric vehicles.

訳その工場は、電気自動車向けの部品を製造している。

a key component

用途特に重要な構成部分を述べる。

例The proposal is missing a key component: a realistic budget.

訳その提案には、現実的な予算という重要な要素が欠けている。

electronic components

用途電子機器の部品をまとめて述べる。

例The supplier sells electronic components to small manufacturers.

訳その供給業者は、小規模な製造業者に電子部品を販売している。

component failure

用途構成部品の故障を名詞を重ねて述べる。

例The investigation traced the problem to a component failure.

訳調査の結果、問題の原因は部品の故障にあると分かった。

stereo components

用途音響システムを構成する個々の機器を述べる。

例The amplifier and tuner are separate stereo components.

訳アンプとチューナーは、別々の音響構成機器である。

語法・注意1
  • of は全体との所属関係、in は仕組みの中での関わり、for は用途を示しやすい。component 自体が常に不可欠という意味とは限らず、essential component や optional component と修飾できる。component supplier／component failure の component は、部品のという関係を示す名詞の修飾用法として捉えられる。
類義語3

part

頻度 10/10

定義全体の一部分。

違いpart は最も広い一般語で、場所の一部や時間の一部にも使う。component は、組み立てや働きに関わる区別可能な構成単位を捉えやすい。

例Only part of the document was available.

訳文書の一部しか利用できなかった。

element

頻度 9/10

定義全体を形作る部分・要因。

違いelement は性質や基本要因にも広く使う。component は、全体を構成する単位としての区別が意識されやすいが、抽象的な文脈では両者が重なる。

例There is an element of uncertainty in every forecast.

訳どの予測にも、不確実な部分がある。

constituent

頻度 5/10

定義全体を構成する要素・成分。

違いconstituent は、何から成るかという構成や成分に重点を置く改まった語。component は機器の部品から抽象的な機能まで広く使う。

例The analysis identified the main constituents of the mixture.

訳分析によって、その混合物の主な成分が特定された。

語義 2

【名詞：可算】ソフトウェアの構成単位、UI部品

頻度 6/10
ソフトウェア開発・UI設計。

ソフトウェアや画面を、役割ごとの単位として組み立てる際の部分。UIではボタンから画面全体まで、表示や振る舞いをまとめた部品として使われる。

文法パターン4
  • a software component
  • a reusable component
  • a parent component
  • a child component。
コロケーション・構文例4

a software component

用途システムを構成するソフトウェア上の単位を述べる。

例The update replaces one software component without changing the whole system.

訳その更新は、システム全体を変えずに、一つのソフトウェア部品を置き換える。

a reusable component

用途複数箇所で利用できるよう作られた部品を述べる。

例The team built a reusable component for displaying customer details.

訳チームは、顧客情報を表示するための再利用可能な部品を作った。

a parent component

用途UIの階層で、下位の部品を組み込む側を述べる。

例The parent component displays several smaller controls.

訳親コンポーネントは、複数の小さな操作部品を表示する。

a child component

用途親に組み込まれる部品を述べる。

例The child component shows the selected item's name.

訳子コンポーネントは、選択された項目の名前を表示する。

語法・注意1
  • component は、具体的な実装方法まで全ての技術で共通する名称ではない。Reactのように部品を組み合わせる仕組みでも、一度しか使わない component はあり、再利用可能という設計と、実際に複数回使われることを区別する。全てのソフトウェア部品を一律にJavaScriptの関数だと説明しない。
語義 3

【形容詞】全体を構成する

頻度 5/10
改まった説明・技術・分析。

ある全体を成り立たせる部分であることを述べる。名詞の前に置き、その部分が全体の構成単位だと示す。

文法パターン2
  • component parts
  • component elements。
コロケーション・構文例2

component parts

用途全体を作る各部分を述べる。

例The machine was separated into its component parts for inspection.

訳検査のために、その機械は構成部品に分解された。

component elements

用途全体の構成要素であることを明示する。

例The chapter examines the component elements of the argument.

訳その章は、議論を成り立たせる各要素を検討している。

語法・注意1
  • この形容詞用法は名詞前で使い、通常 The part is component. や very component のような叙述・程度表現にはしない。a component は名詞、component parts の component は構成するという形容詞で、形が同じでも働きが異なる。
語義 4

【名詞：可算】ベクトルを構成する方向別のベクトル成分

頻度 4/10
数学・物理。

一つのベクトルを、指定された方向に沿う複数のベクトルの和として捉えるときの各ベクトル。成分そのものを向きと大きさを持つ量として述べる用法。

文法パターン3
  • a component of a vector
  • a horizontal component
  • a vertical component。
コロケーション・構文例3

a component of a vector

用途合成されて全体を成す方向別のベクトルを述べる。

例Each component of the vector points along one of the chosen axes.

訳そのベクトルの各ベクトル成分は、選んだ軸の一つに沿う向きを持つ。

a horizontal component

用途水平方向に沿うベクトル部分を述べる。

例The diagram shows the horizontal component as an arrow pointing to the right.

訳図では、水平方向のベクトル成分が、右向きの矢印で示されている。

a vertical component

用途鉛直方向に沿うベクトル部分を述べる。

例The vertical component is drawn as an upward arrow.

訳鉛直方向のベクトル成分は、上向きの矢印で描かれている。

語法・注意1
  • ここでは component 自体をベクトルとして捉える。方向別の大きさを表す数値も component と呼ばれるため、矢印・ベクトルとして述べているか、座標値として述べているかを確認する。成分が必ず水平・鉛直の二つだけだと一般化しない。
語義 5

【名詞：可算】座標値、数値としての成分

頻度 4/10
数学・物理・計算。

ベクトルや、数値を要素とする順序対などを表す、各座標位置の数値。方向ごとの量を、選んだ座標系における数で示す。

文法パターン3
  • the first component
  • the x component
  • a component equal to zero。
コロケーション・構文例3

the first component

用途順序のある成分の最初の値を述べる。

例The first component of the ordered pair is three.

訳その順序対の第一成分は三である。

the x component

用途x軸方向に対応する数値を述べる。

例The x component of the vector is negative in this coordinate system.

訳この座標系では、そのベクトルのx成分は負である。

a component equal to zero

用途ある位置の成分がゼロだと述べる。

例The calculation gives a vector with one component equal to zero.

訳その計算では、一つの成分がゼロであるベクトルが得られる。

語法・注意1
  • 順序対の構成要素は一般には数値に限られないが、この語義では数値である場合を扱う。数値としての component は、選んだ座標系や単位などの条件に依存する。ベクトル成分を向きのある矢印で表す用法と、ここでの数値を同一の種類の対象として混同しない。
語義 6

【形容詞：映像信号】信号を成分別に分けた、コンポーネント方式の

頻度 3/10
映像機器・信号方式。

映像に関する情報を複数の信号・チャンネルに分けて扱う方式を表す。全ての情報を一つの信号にまとめる方式と区別するために使われる。

文法パターン3
  • component video
  • a component input
  • a component signal。
コロケーション・構文例3

component video

用途映像情報を分けて伝える方式を述べる。

例The manual lists component video among the supported connection types.

訳取扱説明書は、対応する接続方式の一つとしてコンポーネント映像を挙げている。

a component input

用途その方式の信号を受ける入力を述べる。

例The monitor has a component input for compatible equipment.

訳そのモニターには、対応機器用のコンポーネント入力がある。

a component signal

用途成分を分けた映像信号を述べる。

例The converter accepts a component signal from the source device.

訳その変換器は、出力元の機器からコンポーネント信号を受け取る。

語法・注意1
  • 一般的な部品という名詞義ではなく、映像信号の方式を区別する語。名称だけから、端子の形・信号の仕様・機器同士の互換性まで判断しない。具体的な接続条件は機器の説明で確認する。
語義 7

【名詞句：不可算・可算・componential analysis】意味の成分分析

頻度 2/10
言語学・意味論。

言語学で、語の意味を、共通する意味特徴や他の語と区別する意味特徴の組合せとして分析する方法。綴りや発音を小さく切り分けることそのものではない。

文法パターン2
  • use componential analysis
  • a componential analysis of something。
コロケーション・構文例2

use componential analysis

用途語の意味を特徴に分けて分析する方法を用いる。

例The researcher used componential analysis to compare the meanings of several related verbs.

訳研究者は、意味の成分分析を用いて、関連する複数の動詞の意味を比較した。

a componential analysis of something

用途特定の語群についての一つの分析を述べる。

例The chapter presents a componential analysis of words describing movement.

訳その章は、移動を表す語の意味についての成分分析を提示している。

語法・注意1
  • 方法一般としては不可算だが、特定の対象について行った一つの分析なら analysis を可算として扱える。componential の component は意味を成す特徴に関わる。接頭辞や接尾辞などを分ける語形成・形態の分析と、同じ作業だと考えない。
該当する語義・用例がありません。
